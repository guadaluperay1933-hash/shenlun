# 申论自造句清单（按功能）

“自造”指在材料里找不到出处、靠改写也改不出来的句子和词。改写出来的那些在《改写手册》里，这里不重复。

## 先看样本有多大

- 一共五篇，两位作者。Fable 三篇：省考新质生产力、选调海洋、策论制造业，下面记作 F1、F2、F3。培训机构的参考答案两篇：省考新质生产力、2023 制造业，记作 R1、R2。
- 没有一篇是带真实分数的考场卷，所以下面每条都标了证据：**两位作者都有**，**只有 Fable 有**，**只出现一次**。只有 Fable 有的，可能只是它的习惯，不一定是这类文章的规矩。
- 有些地方我用了自己对这类文体的了解来补，都标了“我补的”，不算样本结论。

自造的总量很小：每篇一百字上下，占全文一成。

每条按三类处理：

- **A 类**：有低成本写法，直接用低成本的。
- **B 类**：成本高，但句子通用，可以背下来套到别的题目。
- **C 类**：要先理解再生成。我给出该问自己的问题，以及答不上来时的退路。

## 总表

| 位置 | 自造的东西 | 类 | 证据 |
|---|---|---|---|

## 标题

**样本**

- F1：以创新为笔　写好新质生产力的广东答卷
- F2：向海图强　以海洋强省建设打造海上新广东
- F3：把制造业家当做优做强　挺起广东现代化“脊梁”
- R1：创新驱动，引领广东高质量发展
- R2：推动制造业高质量发展　挺起现代化建设“脊梁”

**怎么来的**：F1 是顺着题干的“大文章”往下接，文章要用笔写，写完是答卷。这要求题干里正好有一个能接的比喻。其余四篇都是两个动宾，词全部来自题干和材料一。

**你怎么写**（A 类）：默认写两个动宾。前一个抄题干的主题，后一个抄材料一里那个带引号的比喻（脊梁、蓝色动力）。题干里要是正好有“文章、答卷、考题”这类词，才考虑“以 X 为笔　写好 Y 的广东答卷”。

## 开头

### “有基础、有责任”

**样本**：作为经济大省、制造业大省，广东**有基础、有责任**抓住创新这个“牛鼻子”（F1）

**怎么来的**：“有基础”四个字概括了整则讲成绩的材料，“有责任”概括了总书记对广东的期望。它的作用是把高帽直接变成任务，中间不需要缺点。

**你怎么写**（B 类，背）：作为［材料里的大省称号］，广东有基础、有责任［题干要求做的事］。

套到海洋那题就是：作为海洋大省，广东有基础、有责任在海洋强国建设中走在前列。挑不出毛病的题目用它最合适。

### 总论点的句框

五篇的开头最后一句都是总论点，都有一个固定的框，框是自造的，里面的词是题干的。

| 句框 | 出处 | 什么时候用 |
|---|---|---|
| ［目标］，就是要…… | F2 | 最通用 |
| ［目标］，既要守住［甲］的根本，更要在［乙、丙、丁］上再进一步 | F3 | 分论点里有一个是老本行、其余是新突破的时候 |
| ——这是［目标甲］的必由之路，也是［目标乙］的使命担当 | F1 | 开头没写缺点的时候 |
| ［做这件事］，更是广东……走在前列的关键所在 | R1 | 同上 |
| 要［目标］，就要…… | R2 | 策论 |

**你怎么写**（B 类，背）：背“就是要”和“必由之路、使命担当”两个就够。F2 的“把这五股力量拧成……‘蓝色动力’”是在“就是要”后面加了一个比喻，成本高。平的写法是：［目标］，就是要在［甲、乙、丙、丁］上同时发力。

“既要守住……更要……”需要一点判断：哪个分论点算根本。F3 选的是质量品牌，因为材料四自己说了它是广东制造的“优良传统”。材料没给这种提示，就不用这个框。

### 用题干的比喻给成绩定性

**样本**：八个万亿级产业集群**是厚实家底**（F3）

**怎么来的**：题干说“厚实家当”，它就把成绩叫“家底”。

**你怎么写**（A 类）：可以不写，直接摆排名就行。要写的话只做一件事：题干用了什么比喻，你就用同一个比喻给成绩起个名。

## 中间段：标签句

### 后半句的“角色名词”

**样本**

- F1：筑牢新质生产力的技术**根基**；擦亮新质生产力的生态**底色**
- R1：点燃高质量发展的澎湃**引擎**；夯实高质量发展的坚实**根基**；打造高质量发展的鲜明**底色**；形成高质量发展的独特**优势**
- F3：擦亮广东制造金字**招牌**；厚植制造业**沃土**

**怎么来的**：先定这一段对总目标来说是什么角色，角色定了名词就定了，名词定了动词就定了。名词有一半是材料给的：底色来自引语，澎湃引擎、金字招牌是材料原词，沃土来自材料的“好土壤”。

两位作者用的角色加起来就五种：

| 这一段对总目标是什么 | 名词 | 动词 | 样本 |
|---|---|---|---|
| 发动机 | 引擎、动力、动能 | 点燃、增强、激活 | R1 |
| 地基 | 根基、基础、支撑 | 夯实、筑牢 | F1、R1，材料里也有“重要支撑” |
| 底色 | 底色、成色 | 擦亮、打造、厚植 | F1、R1、F2 |
| 保障 | 保障、沃土、环境 | 提供、厚植、营造 | F3、R2 |
| 招牌、优势 | 招牌、优势、名片 | 擦亮、形成、打造 | F3、R1 |

**你怎么写**（B＋C 类）：要理解的只有一步，就是在五个角色里选一个。

1. 先看材料有没有现成的名词，有就用它。
2. 没有就按上表选。一般科技和人才是发动机，产业和质量是地基，生态是底色，制度和环境是保障，品牌和文化是招牌。
3. 实在选不出，后半句写成“为［目标］提供有力支撑”，哪一段都能用。

### “以 A 动、以 B 动，动宾”

**样本**：以质量立身、以品牌塑魂，擦亮广东制造金字招牌（F3）

**怎么来的**：每段要装两则材料，所以标签里有两个“以”。立身来自材料的“立身之本”，塑魂来自“品牌是企业的灵魂”，都是把材料里的名词改成了动词。

**你怎么写**（A 类）：这个改法成本高。R2 同样的内容写的是“坚持‘质量第一’，强化品牌建设”，两个动宾，词全来自材料。用 R2 的写法。

## 中间段：道理句（重点）

先看数。五篇一共二十个中间段：

- 照抄或轻改材料里的判断句：十段
- 干脆不写道理句：六段
- 自己写的：四段

所以自己写道理句是少数情况。默认动作是抄材料首句，抄不到就不写，段落照样成立。策论那篇四段里有三段没有道理句。

自己写的那几句，加上参考答案里的，一共五种写法。

### 一、“A 是 B 的［角色名词］”

**样本**：海洋生态是海洋强省的底色（F2）。材料里没有这句，材料里的“底色”说的是海洋文化。

**怎么来的**：套用了通行的说法“绿色是高质量发展的底色”。材料自己也满是这种句子：发达的海洋经济是……重要支撑；制造业当家，质量是基础；科技创新是……核心要素。

**你怎么写**（B＋C 类）：和标签句用同一张角色表，选一个角色填进“A 是 B 的 X”。这是五种里最便宜的。

### 二、纠偏式

**样本**

- 绿色不是发展的约束条件，而是先进生产力的内在品质。（F1，接在引语“新质生产力本身就是绿色生产力”后面）
- 海洋强省不是海边的事，而是全省的事。（F2，接在“陆海统筹、山海互济”后面）

**怎么来的**：抓住引语里的一个词（本身；陆、山），想这个词在排除什么，把被排除的那种狭隘看法说出来再否定。

**要问自己的问题**：人们常把这件事想窄成什么？

样本里见到的窄法有两种，把结尾那句“没有句号”也算上是三种。后两种是我补的。

| 窄法 | 句式 | 例子 |
|---|---|---|
| 当成负担、约束 | A 不是 B 的负担，而是 B 的…… | 绿色不是发展的约束条件（F1） |
| 当成少数人、少数地方的事 | A 不是某某的事，而是大家的事 | 不是海边的事，而是全省的事（F2） |
| 当成一次性的事 | A 没有句号，只有…… | 创新这篇大文章没有句号（F1） |
| 当成一家的事（我补的） | A 不是政府一家的事，而是全社会的事 | |
| 当成只能二选一（我补的） | A 和 B 不是单选题，可以相互成就 | |

**你怎么写**（C 类）：想不出窄法就不写。这一句在五篇里只有 Fable 用过，参考答案一处都没有。

### 三、前提式

**样本**：“构建支持全面创新体制机制”，是让创新从零星迸发变为系统涌现的制度前提。（F1）

**怎么来的**：先想没有这套体制机制会怎样，答案是创新只能零星冒出来；再把“没有时”和“有了时”写成“从……变为……”。

**要问自己的问题**：没有它会怎样？

**你怎么写**（C 类，有平的版本）：平的版本不需要“从……变为……”，只写“A 是 B 的前提／保障／关键”，例如：体制机制是创新持续涌现的制度保障。这就退回到第一种了。

### 四、反面式

**样本**：过去，粗放型的发展方式支撑了经济的高速增长，但也带来了资源浪费、生态破坏、环境污染等严重问题。为实现经济的可持续发展，必须促进全面绿色转型。（R1）

**怎么来的**：句框是“过去［旧做法］带来了［问题］。为［目标］，必须［新做法］”。框可以背，但“过去出过什么问题”需要你知道。

**要问自己的问题**：以前不这样做，出过什么问题？

这三套材料自己就交代过五个“以前的问题”，都是广东题里反复出现的，可以记下来：

| 以前的问题 | 材料出处 |
|---|---|
| 粗放发展，拿资源环境换增长 | R1 参考答案 |
| 大而不强，总量第一但层次不高 | 选调材料一、二；2023 材料二“制造大省”向“制造强省” |
| 关键技术受制于人 | 2023 材料二；省考材料三“卡脖子” |
| 科研和产业脱节，成果停在论文里 | 省考材料五 |
| 区域不平衡，产业转移只是搬“老家具” | 2023 材料八；省考材料八粤东西北 |

**你怎么写**（C 类）：材料里标成“问题”的句子就是现成的原料。当场材料里没有问题句，上面五条里又没有对得上的，就不写。

### 五、依据式（策论适用）

**样本**

- 数据表明，新兴产业集群是广东制造业逆势上升的“压舱石”，**因此要**抓住全球产业变革机遇……（R2）
- 产品质量是企业安身立命之本，**为此**广东**应**主动作为……（R2）

**怎么来的**：前半句抄材料的一个数据或一个判断，后面接“因此要”“为此应”，再接对策。

**你怎么写**（B 类，背）：［材料里的判断或数据］，因此要［对策］。成本很低，而且把“为什么”和“怎么办”接上了。策论的道理句用这个就够。

## 中间段：组织和连接

| 自造的框 | 出处 | 用途 | 处理 |
|---|---|---|---|
| 一手抓［甲］，一手抓［乙］ | F1 | 一段里装两则材料 | B 类，背 |
| 既要……又要……，以此…… | R2 | 策论里并列两条对策 | B 类，背 |
| 此外，还要……／不但如此，……也应…… | R2 | 策论里追加一条对策 | B 类，背 |
| 要……；要……；要…… | F3 | 策论里并列几条对策 | 最便宜，默认用这个 |
| 让企业当创新主角 | F1 | 把判断句改成使令句 | A 类，抄材料的判断句：企业是科技创新的主体 |

## 中间段：收束句

### 比喻收束

**样本**：让创新的源头活水源源不断流向新质生产力（F1）；创新的雨林生态才能枝繁叶茂（F1）；绘好……的产业版图（F3）

**怎么来的**：都是顺着材料里的一个词往下接：源头创新接出活水，三棵树接出雨林，星级地图接出版图。

**你怎么写**（A 类）：三处都出自 Fable，参考答案里一处都没有，很可能只是它的习惯，不用学。低成本的收束有三种，都在《改写手册》里：抄材料末句；“补齐……短板，……才能……”；“A，正……”。

### 跨段依赖

**样本**：守住生态，才有可持续的“蓝色粮仓”和海洋旅游。（F2）

**怎么来的**：“蓝色粮仓”和“海洋旅游”是第一段产业里的东西。这句话的意思是：生态这一段要是守不住，产业那一段就落空。几个并列的段落靠它挂上了先后关系。

**要问自己的问题**：这一段要是没做好，前面哪一段会落空？

**你怎么写**（C 类，可选）：句框是“守住［本段主题］，才有［前面某段的成果］”。答得上来就写，一篇写一处就够。答不上来，就用题干目标收：……，［题干目标］才能实现。

## 结尾

### 起兴短句

**样本**：“岭南春来早，人勤地生宝。”（F1，材料原话）；制造业当家的号角已经吹响（F3，材料原话）；岭南春早，奋楫扬帆（R2，自造的四字对）；珠江潮涌千帆竞……（R1，自造的四句诗）

**你怎么写**（A＋B 类）：自己写诗成本最高，不学。材料一末段和最后一则材料的末句里通常就有现成的，先去那里找。找不到，就用下面这个库。它们全是这三套卷子的材料里出现过的句子，等于命题人认可的说法，广东题基本通用：

| 句子 | 出处 | 适合的题目 |
|---|---|---|
| 岭南春来早，人勤地生宝 | 省考材料一 | 通用 |
| 岭南处处是春天，广东时时无闲人 | 2023 材料一 | 通用 |
| 风好正是扬帆时，策马扬鞭再奋蹄 | 省考材料六 | 通用，适合结尾 |
| 大潮起珠江，发展看南粤 | 省考材料二 | 通用，适合开头 |
| 东西南北中，发展到广东 | 省考材料二 | 人才、营商环境 |
| 一枝独秀不是春，百花齐放春满园 | 2023 材料三 | 区域协调、带动中小企业 |
| 水积而鱼聚，木茂而鸟集 | 省考材料六 | 营商环境、产业生态 |
| 济济多士，乃成大业；人才蔚起，国运方兴 | 2023 材料七 | 人才 |
| 没有好土壤，就长不出好庄稼 | 2023 材料九 | 营商环境、体制机制 |
| 产业兴则经济兴，产业强则国家强 | 省考材料六 | 产业 |

### 说大一圈

**样本**：创新这篇大文章没有句号，只有连续不断的新起点（F1）；海洋强省不是海边的事，而是全省的事（F2）

**怎么来的**：就是道理句里的纠偏式，用在了结尾。前一句压的是题干里的“继续”，往时间上说大；后一句压的是引语里的“陆”和“山”，往范围上说大。

**你怎么写**（B＋C 类）：“［主题］没有句号，只有连续不断的新起点”可以整句背，题干里有“继续、持续、不断”的时候就能用。范围那一种要现想，想不出就不写。参考答案两篇都没有这一拍，F3 也没有。

### 点名时配角色词

**样本**：同频共振（F1）；筑基、赋能、守底、拓路、铸魂（F2）；之本、之势、之源、之土（F3）

**怎么来的**：F2 的五个词，有四个是从各段判断句的名词压出来的（重要支撑压成基，底色压成底，大通道压成路，思想源泉压成魂），“赋能”是材料原词。

**你怎么写**（B 类）：参考答案两篇都没有点名，所以这是可选的。分三个层次：

1. 最便宜：只点名不配词。坚持［甲、乙、丙、丁］，广东就能……
2. 加一个词：让［甲、乙、丙、丁］同频共振。
3. 要配角色词，背下面这张对应表。它是我从 F2、F3 往外推的，只有这两篇的证据，当成一副能套的模子用就好：

| 分论点讲的是 | 配的动词（F2 式） | 配的名词（F3 式） |
|---|---|---|
| 产业、经济 | 筑基 | 之基 |
| 科技、数字、人才 | 赋能 | 之源 |
| 生态、质量、安全、民生 | 守底 | 之本 |
| 改革、开放、区域协同 | 拓路 | 之势 |
| 文化、精神 | 铸魂 | 之魂 |
| 制度、环境 | 护航 | 之土 |

**样本**：在推进中国式现代化建设中继续走在前列（F1）；在新征程上走在全国前列（F2）；谱写中国式现代化广东实践的新篇章（F3）；续写南粤高质量发展的锦绣华章（R1）；当好中国高质量发展“排头兵”（R2）

## “理解”到底指什么

所有要理解才能写的句子，归根结底是在回答三个问题：

1. **它对总目标是什么角色？** 发动机、地基、底色、保障，还是招牌。答案用在标签句后半句、“A 是 B 的 X”和结尾的角色词上。
2. **没有它，或者以前没有它，出过什么问题？** 答案用在前提式、反面式和“才能”式的收束句上。
3. **人们常把它想窄成什么？** 答案用在纠偏式和结尾的说大一圈上。

答案从哪来：先看材料里标成“问题”的句子，再看上面那张“以前的问题”表，最后才靠考前储备。

答不上来的退路永远是同一个：抄一句材料里的判断句，往下写。二十个中间段里有十六段就是这么过的。

## 可以直接背的东西

- 作为［称号］，广东有基础、有责任［做某事］。
- ［目标］，就是要在［甲、乙、丙、丁］上同时发力。
- 这是［甲］的必由之路，也是［乙］的使命担当。
- ［甲］是［乙］的根基／引擎／底色／保障／招牌。
- ［材料里的判断或数据］，因此要［对策］。
- 一手抓［甲］，一手抓［乙］。
- 过去［旧做法］带来了［问题］。为［目标］，必须［新做法］。
- ［主题］没有句号，只有连续不断的新起点。
- 让［甲、乙、丙、丁］同频共振。
- ……，广东就能……，在新征程上走在全国前列。
- 起兴句库十条。

## 哪些地方最可能是过拟合

- 比喻收束、点名配角色词、说大一圈、纠偏式，都只在 Fable 的三篇里出现。它们写得好看，但我没有证据说阅卷看重它们，全部按“可选”处理了。
