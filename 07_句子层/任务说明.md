# 07_句子层 · 给 Claude Code（Opus）的任务说明

## 这件事是为了什么

这个仓库已经有一套完整的申论做题法（`广东申论备考包/01_方法/申论做题法_原理程序信号版.md`：四条原理、小题四问、作文五问），以及按这套方法写出来的十四套真题定稿答案。这些定稿经过两轮、多次对照真人 90 分卷的校准，**在这项任务里它们就是目标写法**，是委托人要模仿的东西。

那套方法在“边界”一节里写明了它不管的东西，其中两项是**作文语言**和**词汇**。委托人的写作底子弱，他现在的难处正落在这两项上：知道一段该写什么，也在材料里找到了句子，但写不成定稿里的那句话。

所以要补一层句子级的规则：定稿里的每一句，是怎么从材料原句变出来的；哪些地方必须自己出词，出的是什么词。前期已经手工对过三篇定稿，得到三个初步结论：

1. 定稿的句子九成来自材料，靠删、搬、加一两个固定的字得到；自己写的部分每篇只有一百字上下。
2. 材料句的样子大致可以归成十二种情况，每种有一个固定的改法。
3. 全文需要自己出词的位置是固定的七处。

你的任务是把**全部定稿**逐句对回材料，拟合这三条：十二种情况够不够用、七个位置全不全、每个位置上定稿实际用了哪些句框和词。

你之后还有一步人工汇总，最终要并进 `01_方法/SOP之外_能力差与训练清单与词库.md` 的第 4.6 节（作文的句子模板和原料），再压成一页纸给人背。所以这项工作要的是**覆盖和收敛**：规则越少、每条用得越多越好。一个新类别，只有现有类别确实装不下、并且在三套以上卷子的定稿里出现，才值得提出来。

**样本只用定稿。** `21-26广东申论高分答案合集.pdf`（真人卷）和各年机构参考答案在这项任务里都不用读，也不要拿来对照。

开工前先读：

- `广东申论备考包/01_方法/申论做题法_原理程序信号版.md` 的第 4 节（作文五问）和“边界”
- `广东申论备考包/01_方法/SOP之外_能力差与训练清单与词库.md` 的第 4 节（词库），重点是 4.6
- `07_句子层/参考/` 里的两份手册（句子层前期的完整结论，编号和本说明不一致的地方以本说明为准）

备考包如果还没解压，它在仓库根目录的 `files (10).zip` 里面的 `广东申论备考包.zip`，解压到仓库根目录。

## 分类口径

用词和仓库的方法保持一致。

### 位置（slot）

| 值 | 方法里的叫法 | 含义 |
|---|---|---|
| 标题 | 标题 | |
| 引语 | 开头·引语 | 首段引用领导人、文件或题干的话 |
| 解题 | 开头·解题 | 解释题干里的比喻或口号 |
| 家底 | 开头·家底 | 摆成绩、摆地位 |
| 靶子 | 开头·靶子 | 点出短板或不足 |
| 预告 | 开头·预告 | 首段最后的总论点，点明后面几件事 |
| 观点 | 观点句 | 中间段第一句，分论点 |
| 道理 | 道理句 | 讲“为什么”的句子，通常是判断句或引语 |
| 数据 | — | 用一个数字当论据的独立句子 |
| 总括 | — | 概括本段做法、后面带出若干分句的那句 |
| 证据 | 证据句 | 列举具体做法或例子的分句 |
| 收束 | 收束句 | 中间段最后一句 |
| 意象 | 结尾·材料原句或意象 | 末段起头的那句 |
| 点名 | 结尾·各段一个短语 | 末段回收各分论点 |
| 落点 | 结尾·上层目标 | 末段最后落到的目标 |
| 其他 | | 以上都不是，`note` 里说明 |

### 十二种情况（case）

按“材料原句长什么样”来分。成品由哪种原句变来，就标哪一种。

| 编号 | 材料句的样子 | 改法 | 成品的样子 |
|---|---|---|---|
| C1 | 首句、末句、判断句、已经很像成品的评价句 | 照抄，只删虚词和修饰 | 基本原样 |
| C2 | 领导人或文件的引语 | 截半句，或改成转述 | 总书记强调，“……”／要求广东…… |
| C3 | 某地出台、上线、组建了 X，效果 Y | 删掉“某地”和动词，X 当主语 | X 让 Y／X＋Y |
| C4 | 通过、随着、依托、得益于 X，Y…… | 把 X 拎出来当主语 | X 让 Y |
| C5 | 一段话讲一个或几个具体项目，有细节、人物、数字 | 只留项目名和材料对它的那半句评价 | 名字＋让＋评价 |
| C6 | 从 A 到 B、由 A 向 B 转变 | 整段照搬，或套进“从 A 走到 B” | 基本原样 |
| C7 | 以 X 为代表的 N，或者一个典型例子 | 用例子指代一类 | X 等 N／“X”式的 N／X 这样的 N／像 X 那样 |
| C8 | 一句讲手段，另一句讲效果 | 两句并成一句 | 以 A［动词］B／用 A 帮 B…… |
| C9 | 一串数字 | 只留排名和份额，百分数改“几成” | 稳居全国第一／四成 |
| C10 | 很长的并列项，或很长的专名 | 并列项留两三项，名字缩短 | ……、……等 |
| C11 | 问题、不足 | 包进“……的短板／问题”，或翻成一个动作 | 补齐……的短板／延伸产业链 |
| C12 | （策论和对策题）材料讲已经做了什么 | 前面加“要”和一个转换动词 | 要推广……的做法，让…… |

另外四个标记：

- **F**：句子的骨架是一个固定句框（“……，才能……”“……，就是要……”“坚持……，广东就能……”），里面填的词来自材料或题干。
- **Z**：自造。材料和题干里找不到出处，靠上面的改法也得不到。
- **W**：材料外的例子或引语。方法允许每篇补一句联系实际，这里单独数出来。
- **O**：其他。有出处，但十二种情况都装不下。必须在 `note` 里用一句话说明它是怎么变的。

一个分句同时用了两种，写成 `C7+C12`，主要的放前面。“删修饰”（删时间、副词、数量、说话人）是每种情况都带着做的底色，不单独标。

### 需要自己出词的七个位置

1. 标题
2. 开头里把家底接到任务上的那半句，以及预告句的句框
3. 观点句的后半句
4. 道理句（只在材料里抄不到的时候）
5. 证据句里的连接词和转换动词
6. 收束句的句框
7. 结尾点名的句框、落点词，以及可选的“说大一圈”

检验的方式：所有标成 Z 的文字和所有 `self_made_part`，看它们是不是都落在这七处。落在别处的单独列出来。

### 开头的推法

首段用什么理由推出“广东还要接着做”。可选值：缺口（成绩之后点出不足，也就是靶子）、职责帽（因为是排头兵所以有责任）、形势（外部竞争或新一轮变革）、换阶段（从大到强、从有到优）、自己的目标（省委自己提出的口号）、重要性（只说这件事重要）、其他。可以多选，每个都要附上依据的原句。

## 每个样本的产出

### 1. card.json（思路卡，十二篇都做）

每一项判断都附上文章里的原句。字段可以为空，不要编：

```json
{
  "id": "2026省市",
  "genre": "议论", "字数": 988,
  "题干": {"A": "……", "B": "……", "近目标": "……", "上层目标": "……", "题干里的比喻或口号": "……"},
  "标题": {"原文": "……", "形式": "两个动宾／比喻式／四字＋以A打造B／其他", "落点": "近目标／上层目标"},
  "段落": [
    {"段": 2, "观点句原文": "……", "观点句来源": "材料判断句／题干落点／材料里现成的一组标签／自造句框", "出处": "……", "用到的材料": ["三", "四"]}
  ],
  "开头": {
    "句子": [{"原句": "……", "slot": "引语／解题／家底／靶子／预告／其他"}],
    "推法": [{"类型": "缺口", "依据": "……"}]
  },
  "中间段": [
    {"段": 2, "句数": 4, "句长": [17, 18, 115, 31], "slot序列": ["观点", "道理", "证据", "收束"],
     "道理句": "抄／改／造／无", "证据个数": 3, "数字个数": 1, "材料外例子个数": 0,
     "收束类型": "补短板才能／正……／抄材料末句／比喻／让……／回到B／无"}
  ],
  "结尾": {"句数": 2, "意象": "抄材料／自造／无", "说大一圈": "原句或空", "点名": "配角色词／不配词／无", "落点词": "走在全国前列"},
  "问题的写法": [{"原句": "……", "主语是不是广东": false, "缺点做定语还是谓语": "定语"}],
  "材料露脸": {"用到": ["一", "三", "四"], "没用到": ["八"]},
  "小题与大作文": [{"小题": "问题一", "要点": "……", "进了大作文的哪一段": 2}]
}
```

句长含标点。

### 2. clauses.jsonl（分句匹配，十二篇都做）

把大作文切成分句，一行一个 JSON。切法：先按句号、问号、叹号切成句；长句再按分号切；一截里面如果明显由两个不同出处拼成、且情况不同，再在逗号处切开。不要切得比这更碎。

```json
{"para": 2, "sent": 3, "seg": 1, "text": "湛江依托重大临港项目谋划大型产业集聚区，打造绿色钢铁等临港产业集群", "slot": "证据", "case": "C10", "sources": [{"material": "二", "quote": "打造绿色钢铁等13个现代临港产业集群"}], "glue": "", "self_made_part": "", "note": ""}
```

- `quote` 必须是 material.txt 里一字不差的原文，取能证明出处的最短一段，八到四十个字，不要跨自然段。
- 一个分句有两处出处，就放两个 `sources`。
- `glue` 填把材料的词粘成这一句的那一两个字：连接词（让、把、用、以、才能、就能、正）、转换动词（推广、用好、深化、支持、壮大）、补进去的动词（实现、成为、得到）。没有就空着。
- `self_made_part` 填这个分句里材料和题干都没有、又不只是 glue 的那几个字。整句自造就把 `case` 标成 Z。
- 动词被换成近义词的（解决→破解），在 `note` 里写“动词：解决→破解”。
- 来自题干的文字，`material` 写“题干”。

### 3. q12.jsonl（小题匹配）

每个要点一行：

```json
{"q": 1, "point": 1, "label": "增强企业话语权", "label_source": "自己概括／材料原词／材料的总结句或目的句", "label_form": "动宾／名词＋坏词／主体＋作用／名词＋判断", "body": [{"text": "召开座谈会听取企业建议", "case": "C10", "sources": [{"material": "四", "quote": "……"}], "glue": "", "self_made_part": ""}]}
```

要回答的问题：十二种情况用在小题上够不够；小题多出来的动作是不是只有“起标签”这一种（方法里叫第三问“名字从哪来”）；对策题里 C11 和 C12 各占多少。

## 核对

每个样本做完分句匹配，运行：

```
python 07_句子层/tools/check_quotes.py --material 07_句子层/samples/<id>/material.txt --clauses 07_句子层/out/<id>/clauses.jsonl
```

- 有任何一条 `quote` 在材料里找不到，脚本会指出来，并给出材料里最长能对上的片段。回去重新找出处；确实找不到，就改标 Z、W 或 O。改到全部通过为止。
- 脚本会列出“标成自造、但和材料重合六个字以上”的地方。逐条看：如果其实有出处，改标；如果重合的只是题干里的主题词，保留 Z，在 `note` 里写一句。
- 小题的 `q12.jsonl` 也用同一个脚本查，`--clauses` 直接指向它就行，脚本会自动把每个 `body` 元素摊开。

## 先做校准

`gold/` 里有三份校准集，对应 `samples/` 里现成的三个样本，共五十二条，出处都用脚本核对过。先只做这三个样本的分句匹配，然后：

```
python 07_句子层/tools/check_quotes.py --material …/material.txt --clauses …/clauses.jsonl --gold 07_句子层/gold/<样本id>.jsonl
```

目标是来源对上九成以上，情况标对八成以上。达不到就先调整做法，不要往下跑。校准集里“属于哪种情况”是人工判断，可能有错；你认为它标错的地方，单独列出来并说明理由，不要为了凑数去迁就它。（校准集里的 slot 用的是旧叫法：标签＝观点，长句＝证据，开头和结尾没有细分。比对只看来源和 case，不看 slot。）

## 工作顺序

1. 校准：三个现成样本的分句匹配，过线。
2. 建其余九个作文样本，十二篇的思路卡。
3. 十二篇的分句匹配，逐篇核对通过。
4. 第一批小题匹配；按规则决定做不做第二批。
5. 写汇总。

## 汇总

全部做完后写 `07_句子层/out/汇总.md`，控制在三百行以内，因为它会被整份贴给下一位汇总的人。只放表和结论，不放逐句明细。包含：

1. **校准结果**：三个样本的两项一致率，以及你对校准集的异议。
2. **覆盖率**：各 case 的分句数和占比，议论和策论分列，再按十二篇逐篇列一行；落在 C1 到 C12 加 F 里的总占比；Z 和 W 各占多少字。O 类逐条列出（最多三十条），每条一句话说明，并指出哪些其实可以并进现有情况。
3. **哪几种情况最值得先学**：按分句数排序，给出累计占比（前几种合起来覆盖了多少）。
4. **槽位统计**（来自十二张思路卡）：每个位置上定稿用了哪几种写法、各出现在几篇里。包括标题形式；开头各 slot 的出现比例、顺序和推法；观点句的来源和句框；道理句是抄、改、造还是无；每段句数、句长范围、证据个数、数字个数；收束类型；结尾有没有说大一圈、有没有点名、点名配不配词、落点词；材料露脸的完整度；问题是怎么写的。议论和策论分列。
5. **自造清单**：所有 Z 和 `self_made_part`，按七个位置归类、去重、计数，标出每条出现在几篇里。落在七个位置之外的单独列。
6. **词表原料**，每组都带出现次数，只列出现两次以上的：
   - `glue` 里的连接词
   - 策论和对策题里“要”后面的转换动词，连同它后面跟的是哪类东西（战略改革／某地的做法／平台基金／企业人才／原则机制）
   - 观点句后半句的“动词＋角色名词”对（筑牢……根基、擦亮……底色）
   - 被换过的动词对（解决→破解）
   - 写问题时用的软化说法（同样存在、尚未、亟待、有待、补齐……短板）
   - 结尾的落点词和点名用的词
7. **四个待定的写法**：比喻式的收束句、结尾点名时给每项配一个角色词、结尾说大一圈、引语后面接“不是……而是……”。分别数它们在十二篇里出现了几次、在哪几篇，给出原句。出现在三篇以上的才会进最后那一页纸。
8. **新候选**：三套以上卷子的定稿里出现、现有口径装不下的改法或句框。没有就写没有。
9. **小题**：十二种情况在小题上的覆盖率；标签的来源和形式分布；小题特有的动作。

## 容易出错的地方

- **编出处**。定稿的句子读起来像材料，很容易凭印象写一个出处。所有出处都要回到 material.txt 里复制，再交给脚本核对。
- **跨材料的拼接**。一个分句的前半和后半可能来自不同材料、不同段落，校准集里有好几例。找不到完整出处时，先试试把分句拆成两半分别找。
- **材料里的原话被挪了位置**。比如某则材料的末句被用在文章开头，某则材料的例子被放进另一段。出处以文字为准，不以位置为准。
- **硬塞**。为了让覆盖率好看把勉强的分句塞进某个 case，会毁掉这项拟合的意义。拿不准就标 O 并写清楚。
- **把题干当材料外**。题干里的主题词、目标短语、比喻，都算有出处。
- **C3、C4、C5 容易混**。三种的成品长得一样（名字让评价），区别在材料原句：原句是“某地做了 X”标 C3，原句以“通过、随着、依托”起头标 C4，原句是一段带细节的叙述标 C5。分不清时标 C5。

## 不要做的事

- 不要改写、润色或评价任何一篇定稿，也不要给写作建议。这项工作只做匹配和统计。
- 不要读真人卷合集和机构参考答案，也不要把定稿和它们比较。
- 不要新增字段或改动上面的结构，汇总的人会按这个结构读。确实需要补充，放在 `note` 里。
