# 规则账本

前面几套攒下来的改写经验。不是规矩：照做不照做由你定，不照做在老实话里说一句为什么，那就是这条规则的反例。

**分层**：G 通用改写（句子怎么改，跟题型无关，将来搬到大作文）｜X 小题动作（一道小题怎么组织）｜T-xx 题型层（按 questions.json 的 qtype 分节）｜E 大文专属（只收猜想）。

**等级**：猜想（1 套）→ 候选（≥2 套支持、无反例）→ 稳（≥3 套、无反例、至少 1 套真人卷 n≥4）；只在零真人卷套里出现的题型，≥3 套叫「稳·无真分」。一个带真人卷证据的反例降一级；两个废止（留在底部，写原因）。规则错了才降级；when 写窄了只改 when。

**一条规则的写法**：情况 → 动作 → 为什么。「为什么」优先回到批卷的机制：挤占 / 越界 / 并到看不见；本批新提一种「越轴」（猜想，见 X-02）：主语对、也在指定的材料里，但答的是题干没问的那一类（问做法，答了成效）。

**现状**（第一遍批一合并后：2026省市、2025县镇，两套真人卷 n 都 ≥4）：共 12 条。G 4 条、X 3 条（G+X 合计 7，上限 40）、T-问对 4 条、E 1 条。候选 5 条，猜想 7 条，稳 0 条，废止 0 条。

**先看哪几条**：候选的五条下一套建议照做：G-01、X-01、X-02、T-问对-01、T-问对-02。

## G 通用改写层

**G-01　从题干关键词和材料原词里拼标签，标签只说“这一面是什么”，采分词放进正文**
- 为什么：标签一般不单独给分，自造的标签只花字数。标签结构一样（同一个题干词加不同的对象名），每一面各自独立、好认，两面不会并到看不见。材料里给下一段定性的那句话（比如“在附加值上要效益”）放进标签，不占正文的字，还顺带交代了为什么要做这件事。
- 什么时候用：做法、表现、分类、归纳类小题，答案按“标签 + 正文”分条。
- 怎么做：先试“题干关键词 + 材料里的对象名”，比如绿色 + 景观 / 能源 / 产品 / 办公 / 原材料，自造 0 字。拼不通就用材料里的定性句或原词做标签，比如提升附加值。原来写在标签里的采分词挪进正文，正文只写“做了什么、做出了什么”。
- 边界与反例：拼出来的词在现实里说不通时（比如“绿色人才”）不要硬拼，改用材料原词。
- 证据：支持 2026省市 Q1.v2 五个标签（上一版标签自造 27 字，这一版 0 字）；支持 2025县镇 Q1.要点4（定性句挪到标签，正文腾出字写加工产品，4/7 的卷写了产品）。反对：无。
- 等级：候选

**G-02　同一句里既有“多少”又有“什么、怎么”，删掉数量，留下种类和方式**
- 为什么：批卷人找的是做法。规模数字在报道里是渲染，写进答案就是挤占：株数 0/10，树种 7/10。
- 什么时候用：一句材料里同时有数量词和种类词（或方式词）。
- 怎么做：删株数、面积、次数，留树种、方式。
- 边界与反例：题干问成效，或者数字本身就是指标（比如把绿电自供比例当达标线）时，数字要留。
- 证据：支持 2026省市 Q1.要点1。反对：无。
- 等级：猜想

**G-03　材料先说总的、再举例子或列清单时，写总的那句，删掉例子和清单**
- 为什么：同一件事写两遍，批卷人只勾一次，多出的字挤占别的点。2025县镇 的数字：监测加指导的总括句 7/7，同一段里的设备例句各 1/7；“缺乏标准化”6/7，它的细化清单（多种药材、多个环节）1/7；“关键装备缺乏”7/7，它的细化（靠人工剥皮）0/7。
- 什么时候用：字数紧；一段里先有一句总的，后面跟着“谁用什么工具干了什么”的例句，或者“具体是指……”的清单。
- 怎么做：留总括句。删例句时，保留把两件事连起来的那一环（本套是平台“发出预警”，它连着监测和指导）。空出来的字给另一件独立的事（本套用来补“无法形成全自动化生产线”）。
- 边界与反例：
  - 例子自己占一整段（夜市、风情园各占一段，都是 7/7）：它就是一件独立的事，按 X-01 单写。
  - 例子是那一段唯一能被认出来的具体内容（加工产品，4/7）：保留。
  - 清单里藏着另一件事（“没有国家级标准”说的是标准的等级，不是数量）：保留，但把握低，这一点问题侧 0/7。
  - 列的是不同的人分别点了名的不同对象，这不算清单，按 T-问对-03 写全。
- 证据：支持 2025县镇 Q1.要点2、Q2.问题1、Q2.问题4。反对：无。
- 等级：猜想

**G-04　技术名词后面补一句材料原话，说清它和题干关键词是怎么接上的**
- 为什么：只写技术名，读者和批卷人都看不出它为什么属于这一面。补上这一环，这一条才落到采分的“面”上。
- 什么时候用：答案里出现“开发某种涂层 / 某种系统”这类技术名词。
- 怎么做：纳米涂层后面接“维修不用整体更换”，用材料原话，自造 0 字。
- 边界与反例：字数极紧、技术名本身已经带着关键词时（比如“节能灯”），不补。
- 证据：支持 2026省市 Q1.要点3（4/10，是可选点，把握低）。相关但不计票：2025县镇 Q1.要点2 补回的“发出预警”也是一个连接环（见 G-03 的“怎么做”）。反对：无。
- 等级：猜想

## X 小题动作层

**X-01　按“一段一件事、一个对象一条”定条数**
- 为什么：批卷人的要点表看起来是按段抽动作句的；管的对象一换，采分点也跟着换。两件事写在一条里，批卷人只勾一次（并到看不见）。
- 什么时候用：摘做法、摘表现、摘问题的题，材料是一段讲一件事的报道体或调研体。
- 怎么做：每段问两句话：这段做了什么动作？这句管的是谁？一段一件动作，给一条或一个独立分句。段内出现“还将……延伸至”“此外”这类换话头的词，管的对象又变了（员工 → 供应商），就另起一条。判断看现实里这是谁的事，不看语法角色：“让员工养成习惯”语法上像目的状语，现实里是人的行为变了，是独立的一件事。
- 边界与反例：一个动作同时作用于两个对象（一条规定既管员工又管供应商）不拆。两段讲的对象属于同一类、市里的解法也是同一套（柚子深加工人才和中药研发人才，都是加工研发类技术人才）时，可以并成一条，但对象名要写全；如果一边是技术人才、一边是经营管理人才，就要分开。
- 证据：支持 2026省市 Q1.要点4–5（真人卷 10/10 分开写）；支持 2025县镇 Q1（必答点和动作段一一对应，夜市、风情园各占一段，都是 7/7）、Q2.问题5（同类对象并条的边界）。只记观察、不计票：2025县镇 顶底差里，最低两份都把两种不同的问题装进了同一条。反对：无。
- 等级：候选

**X-02　做法类的题只写动作段；成效、背景、道理段不单写，把握低又在轴外的条目也不写**
- 为什么：问做法、问表现的题，批卷人的要点表按做法列。成效段（产值、订单，“××越高××越足”式的总结）主语没错，答的却是题干没问的东西，这就是“越轴”，效果等于挤占。2026省市 v1 写了一条成效，真人卷 0/10，白占约 30 字，挤掉了两个必答细点（乡土阔叶树种、员工的绿色办公习惯）；同套的理念段也没有一份卷把它当成一面单写。2025县镇 的背景段（古语）、成效段（产值）、道理段，都没有一份卷单写。
- 什么时候用：题干问“主要做法 / 体现在哪些方面 / 有哪些表现”，材料里夹着背景段、成效段、道理段。
- 怎么做：扫料时给每段标上“动作 / 背景 / 成效 / 道理”，只有动作段进正文。写的时候觉得“这条在轴外、把握低，但怕漏”，就不写，把字留给同一面里的必答细点。材料里的身份词（比如“试点企业”）是身份不是做法，同样不进。
- 边界与反例：题干问“成效”“意义”，或者问“做法和成效”时不适用。道理段在给下一段定性时，可以拿来当标签（见 G-01），不占正文。
- 证据：支持 2026省市 Q1.v1 要点六（0/10）、三-p6 理念段（0/10 单列）；支持 2025县镇 Q1（背景、成效、道理段 0 份单写）。反对：无。
- 等级：候选

**X-03　问题句里有地域或范围的限定词，对策照抄这个词**
- 为什么：“有针对性”是对策题的明文要求。一个限定词，就能把对策钉回它要解决的那个问题上。
- 什么时候用：问题句里有“当地 / 本市 / 部分园区”这类限定。
- 怎么做：问题是当地专业公司少，对策就写“培育当地……服务商”。
- 边界与反例：限定词说的是现状的原因、不是对策的作用范围时，不抄。
- 证据：支持 2026省市 Q2.对策五（只有一处证据，把握低）。反对：无。
- 等级：猜想

## T 题型层

### T-做法 / T-表现

本批没有只属于这两种题型的规则。原来记在 T-表现 下的“删成效段”已经和 2025县镇 的“按段找点”合并成 X-02。做这两类题先用 X-01、X-02、G-01、G-02、G-03。

### T-问对

**T-问对-01　把材料里“建议 / 应当 / 需要”的话照抄成对策，只放对策栏，不反推成问题**
- 为什么：问题点来自现象句（谁遇到了什么事）。把“应当细化政策”反推成“政策不细”，问题侧就多占了一条没人给分的（0/9）。反过来，材料自带的解法正是批卷人最先找的对策：2025县镇 的两句建议（机械化设备研发推广、政企学合作推进标准化）都是 7/7。
- 什么时候用：问题加对策题，材料是调研体，里面有专家或当事人发言，先讲现象，再讲“应当 / 需要 / 建议”。
- 怎么做：给每句标上“现象”或“应当”。现象句进问题栏；应当句圈出来，一句配一个问题，写进对策栏。
- 边界与反例：
  - 材料用现象句写出了政策缺位的后果（比如“因为政策不明确，园区不敢建”），这时可以写进问题。
  - 建议只是某一方的一面之词，执行的主体和题目的主语对不上（比如企业要政府给自己补贴）：改主语，或者不用。
- 证据：支持 2026省市 Q2.问题六 / 对策六（写进问题侧 0/9，预登记第 2 条落空）；支持 2025县镇 Q2.对策1、对策4（7/7）。反对：无。
- 等级：候选

**T-问对-02　材料只说缺、没给解法的问题，先写反过来的最短动作，再按现实分层补第二个动作**
- 为什么：题干要求对策具体明确，只反写一遍是把问题翻了个面，还不是解法。真人卷分歧最大的正是这几条，高分卷肯花的自造字又集中在同几个动作上：人才写引进加本地培养（2025县镇 7/7、6/7；2026省市 培养 8/9），资金写补贴加非财政资金（2026省市 6/9），观念写宣传加培训（2025县镇 宣传 6/7）。现实里：复合型人才各地都缺，只能自己培养；补贴不够是普遍的，财政兜不住，只能引市场的钱；一群人不用新东西，要先分清是不相信还是不会用，一层原因对一个动作。
- 什么时候用：问题加对策题，材料只描述了缺口或抵触，没有给出做法。以后遇到 T-对策 题可以试用，还没验证过。
- 怎么做：
  1. 反写用材料里出现过的动词或常用的动词壳（加强、完善、放宽），自造压到 2 字以内。
  2. 问自己：现实里这件事有几层原因、几条路？人才：引进 + 培养；资金：补贴 + 社会资本；观念：宣传（管信不信）+ 培训（管会不会）。
  3. 第二个动作限 6 字以内，而且要在材料里找到它行得通的依据（比如各地都在建、不少园区都面临），把依据写进过程记录。
- 边界与反例：材料已经给了解法的，用材料的解法（T-问对-01），不另造。材料明说只有一层原因的（比如只说买不起），只写那一层。
- 证据：支持 2026省市 Q2.对策一、对策四；支持 2025县镇 Q2.对策2、对策3、对策5。反对：无。
- 等级：候选

**T-问对-03　问题侧把材料点了名的对象都写出来，不用一个泛称顶替**
- 为什么：问题侧和对策侧各自给分。用一个泛称，会把两个采分点并到看不见（两类人才在问题侧各 7/9）。对策侧写全了，也不能替问题侧拿分。
- 什么时候用：材料里不同的人各点了一类对象（比如园区负责人说缺运营管理人员，专家说缺复合型技术人员）。
- 怎么做：写“A、B 缺乏”，不写“人才缺乏”。对策侧写全了，问题侧也照样写全。
- 边界与反例：材料明说两类对象其实是同一批人时，只写一个。两类同属一类、解法是同一套时，可以并成一条，但名字写全（见 X-01）。如果只是上位句的细化清单，而不是不同的人分别点了名的对象，按 G-03 只留上位句。
- 证据：支持 2026省市 Q2.问题一。反对：无。
- 等级：猜想

**T-问对-04　问题条只写表现和材料给的直接原因词；人口画像不进问题，留着用来挑对策**
- 为什么：写画像是挤占。年纪、教育 1/7，传统观念 3/7，热情不高 7/7。调研报告的“存在问题”写的是市里要面对的事，年纪、学历这类改不了的背景，配不上对策。
- 什么时候用：材料在一个问题后面补了一段“这些人大多……”的画像。
- 怎么做：用画像判断对策该是培训、宣传还是补贴（接 T-问对-02），问题条只留材料里那个原因词。
- 边界与反例：题目本身就问原因（“分析原因”题）时，画像要写。
- 证据：支持 2025县镇 Q2.问题3。反对：无。
- 等级：猜想

## E 大文专属层（猜想）

**E-01　写产业类大作文时，一正一反地用材料：做成了的那条产业链当正面骨架，另一则材料里的卡点当“还差什么”**
- 为什么：这两则材料在现实里是同一件事的两面，一个是做成了的样子，一个是还卡在哪里。一正一反，比单列几个案例更有论证力。
- 什么时候用：本套大作文，或同一主题的大作文。
- 怎么做：正面按产业链的环节排（品种、种植科技、保鲜、加工、农文旅），反面按卡点排（装备、准入、观念、标准、人才），每个卡点配一个现实里能做的动作。
- 边界与反例：大作文题目只问一面（比如只问经验）时，反面只用一两句。
- 证据：2025县镇 材料三、材料四。只记观察、不计票：2026省市 的材料三（做成了的绿色工厂）和材料五（零碳园区卡在哪里）也是一正一反，这套的大作文可以拿来验证。
- 等级：猜想
