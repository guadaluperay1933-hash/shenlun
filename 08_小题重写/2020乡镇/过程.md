### 问题一

**落在哪几则**：一、二、三、四、五、六（主料一二三四）。

**答案 v1**（/home/user/shenlun/08_小题重写/2020乡镇/答案/Q1.v1.txt，199 字）

```
一、内容繁杂、涉及面广：镇村卫生、疫情防控、就业培训、柚子产业、脱贫攻坚都要管。
二、面对群众：逐家逐户排查、宣传，释疑解惑，送物资，协调各方解决问题。
三、任务急、责任重：疫情就是命令，取消休假第一时间赶赴岗位，排查限时汇总。
四、承上启下：吃透县里文件做好安排，向县里反映情况。
五、条件艰苦：防控物资稀缺，一天一个口罩；缺专业人才，信号不好。
六、党建引领、党员带头：靠前安排，冲锋在前，动员组织群众。
```

**要点说明**

- 要点一「内容繁杂、涉及面广」：标签是自造的（特点题得提概念，材料没有现成的定性句）。现实里，小温一年之内做了卫生检查（材料一）、疫情排查宣传（材料二）、办培训班（材料三）、看柚子复工和滞销（材料四）、参加扶贫座谈（材料五）——一个人五个领域，这就是乡镇「上面千条线、下面一根针」的样子。五件事并在一条里是因为它们证明的是同一个性质（面广），不是五个特点；反例：如果题目问「小温做了哪些工作」，就要一件一条。这一条按 G-03 本该只留总括，但特点题的总括是我造的词，批卷人认的是后面的领域名，所以领域清单留着当证据（偏离 G-03，理由见账本使用）。
- 要点二「面对群众」：标签从「逐家逐户」「群众的贴心人」（二-p7、p12）里抽。现实里乡镇干部是政府和农民之间最后一环：自己开车挨家发资料、接群众电话释疑、给隔离户买菜、协调各方——服务对象是具体的人。四个动作并成一条，因为都是「干部对群众」这一个方向；反例：如果其中一个动作是对上级汇报，就要归到承上启下那条。
- 要点三「任务急、责任重」：标签自造，正文用材料原句「疫情就是命令」（二-p4-2a）、「第一时间赶赴工作岗位」（二-p4-3c）、「中午 12 点前」（二-p5-1h，写成「限时」）。现实里是应急状态：休假说取消就取消，一天之内排查完一百多人。两句并一条，因为都是节奏（急）；「责任重」写在标签里由「命令」「责任」撑着。反例：如果材料只写日常按部就班，这一条就不存在。
- 要点四「承上启下」：标签自造，正文全是材料原词：「县里的文件要吃透，做好安排」（三-p16-2a）、「跟县里反映」（四-p12-1a）。现实里乡镇是政策落地的执行层，上面来文件要转成安排，下面的困难要往上报——两个方向合起来才是「承上启下」，所以两句并一条。反例：如果只写「吃透文件」，那是政策性强，不是位置。
- 要点五「条件艰苦」：标签自造，正文用「防控物资稀缺」（二-p12-5a）、「一天就一个口罩」（二-p6-6d）、「缺乏专业的电商人才」（四-p21-3c）、「信号也不好」（四-p16-2a）。现实里乡镇资源比城里少：防疫物资、专业人才、网络基础都缺，工作得在这种条件下做。并成一条因为都是「手里有什么」；反例：如果口罩稀缺是全国都缺，那不是乡镇的特点——但材料明说「一线镇村干部难以得到有效保护」，是乡镇一线的处境。
- 要点六「党建引领、党员带头」：标签用材料原词「以党建为引领」（六-p4-1b）、「党员、干部靠前安排」（二-p6-5d）。现实里乡镇干部多数是党员，防疫卡点、卫生大扫除都是党员干部带头、再动员群众。正文三个短语（靠前、冲锋在前、动员组织群众）都是「党员干部怎么带」的一件事，所以并成一条；反例：如果「动员群众」是通过村委会行政通知而不是党员带头，就不能并进党建。

### 新提案

1. **T-特点｜特点题先找材料里人物自述「最难的是……第一、第二、第三」的那一段，每个「难」各给一条或一个分句，再从别的材料段补事例。**
   - why：这种段是作者替出题人写好的特点清单，两参照的挑战多、风险高、群众引导三条都从二-p12 来；v1 只取了一难，漏了一面。批卷机制：漏面。
   - when：特点题 / 性质题，材料是叙事体，里面有人回头总结「最难 / 最大的困难 / 几个特点」。
   - how：先把那段的每个「第 N」抄成一个分句，配上前文的具体事（取消休假、限时汇总、一天一个口罩），再看别的材料段能不能再出一面（承上启下、面广）。标签只能自造，但每个标签下必须有材料里的一件事。
   - counter：自述段说的是某一件具体工作的难（只管疫情），题干问的是整个岗位的特点时，自述段只出一两面，别的面从其他材料段来。
   - 例：2020乡镇/Q1.要点5。

2. **T-要点｜对话体材料里，对方问的每一个问题就是筹备清单的一项，按问句列条，一问一项。**
   - why：机构六条正好对应小张的每一问（时间、谁教、接不接、器具、饭钱、地点设备、电视台、口罩、报名）；批卷人的要点表最省事的做法也是按问句列。v1 按「方案—报名—师资场地—安全后勤—宣传就业」自己排，多写了两个材料没问到的常识动作（报批、经费）。批卷机制：挤占。
   - when：题干问「前期准备 / 工作要点 / 需要做哪些安排」，材料是一段问答。
   - how：把每个问句反过来写成一项准备（「你们去接吗」→ 安排接送；「会发口罩吧」→ 备口罩），答句里的具体词照抄（广州佛山大厨、音响投影、管饭）；「对接 / 落实」后面必须跟能看见的内容（告知时间地点）；常识的行政动作只在材料有线索时补。
   - counter：材料只有一方陈述、没有问答时，按 X-01 一段一件事。
   - 例：2020乡镇/Q2.要点3、要点1。

3. **T-对策｜综合建议题按材料自带的框架词（几个总要求、几个方面）数面，每一面一条；材料点了名却没有动作的面，用材料里那一面的名词补「用好 / 完善 + 名词」，不跳过。**
   - why：两参照都按材料六 p4 的五个总要求排，乡风文明这一面两参照都单列，v1 按「有动作才写」丢了整面。批卷人按框架设面时，缺一面就少一面的分。批卷机制：漏面。
   - when：题干问「提出建议 / 对策」且范围是「持续推进 X」这种综合面，材料里有领导讲话或采访列出了几个方面。
   - how：先抄框架词当标签（G-01），每面从全套材料找动作；找不到动作的面，找材料里属于这一面的名词（农家书屋、文化广场）配一个「用好」。前面小题已经专门问过的面（防返贫）压到一句。
   - counter：题干把范围限定在某一面（只问产业）时不用数面。
   - 例：2020乡镇/Q5.要点5。

4. **T-对策｜防返贫 / 增收类对策题，面从「这些人的钱从哪来」倒推，材料里别处的产业和销路段（滞销、消费扶贫）也算这题的措施。**
   - why：两参照都有销路 / 产业帮扶一面，v1 漏了；现实里脱贫户的收入挂在养蜂、柚子上，滞销就是返贫的路。批卷机制：漏面。
   - when：题干问防返贫、稳增收、巩固脱贫成果。
   - how：列出材料里每个脱贫户靠什么挣钱，那个产业在别的材料里出了什么事（滞销）、谁已经做了什么（县里消费扶贫、对接电商），抄成一条产业帮扶。
   - counter：题干把对象限定在座谈会点名的几户、并且没有「新致贫」时，产业面可以只在某一户下面提。
   - 例：2020乡镇/Q4.要点6。
