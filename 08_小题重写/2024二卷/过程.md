答案 v1（200 字，见 答案/Q1.v1.txt）：

一、视人才为珍宝。引进培养两手抓，携手港澳建人才高地，赋予科研人员成果转化更大受益权。

要点说明：
- 要点一（人才）：标签用 p4 首句原话。现实里是省里对人才做两件事：一头把人弄来、育出来（引进 + 培养 + 港澳人才高地），一头让人来了有用（成果转化受益权，方案已出台）。这两件事并成一条，因为对象同是人才、都由省里人才政策管；反例：如果一边是引才、一边是给企业减税，就不能并。人才工程、高等教育“冲一流”是“培养”的展开（G-03，留总的删清单）；“打通价值实现通道”是受益权那句的上位句，字紧时留具体的受益权。
- 要点二（企业）：标签用 p5 原话。现实里是两件事：p5 让企业当主体去攻关键技术（资源集聚、政产学研协同），p6 让企业升级自己的生产（技改、数字化转型，带动产业升级）。并成一条的理由：对象都是企业，省里对企业的支持是同一套；犹豫点是 p5、p6 各占一段，X-01 说一段一条。我把 p6 作为独立分句写在同一条里，赌的是批卷人按“企业”一面勾两个细点；反例：如果 p6 讲的是高校，就必须分开。9000 家、9200 家的数字按 G-02 删，留“技术改造、数字化转型”两种方式。“撒手锏”“根技术”是“卡脖子”的并列修辞，留一个。
- 要点三（市场）：标签用 p7“把超大规模市场这一独特优势切实转化为……优势”里的“转化”。现实里是省里拿市场当创新的试验场：科研题目从市场需求里来，新技术先在广东市场用起来（应用场景），再把资金、技术、数据这些要素也做成市场。三件事都是“用市场”，并成一条；反例：如果应用场景是政府采购指令，就不属于市场这一面。“吸聚创新资源”“兑现创新价值”是同一句的排比，留第一项。
- 要点四（体制）：标签用 p8 原话。现实里是省里改自己：科技管理机构改革（改部门），新型举国体制（政府和市场怎么配合搞攻关），有组织的科研和转化（科研不再散着做）。同段同类，并成一条；反例：如果新型举国体制那句说的是国家部委的事，就是越界，不写。
- 要点五（环境）：标签用 p9“营造有利于创新的政策和制度环境”缩成。现实里是给创新松绑：监管包容审慎（新业态先让它长）、保护知识产权（创新有收益）、开放合作（不关门搞创新）。三件事都是环境而不是动作对象，并成一条；反例：如果“以开放促创新”展开成具体的国际合作项目，就该单列。
- 没写的：p3 目标句（总纲）、p5 家底、p7 道理句、p8 致谢、p9 判断句、各段寄语，按 X-02 都在轴外。

## §5 本套触发

### 规则提案

1. **层 X（或 T-做法）：讲话体材料按“要……”领起句定条数，一个领起句一条，后面几段的动作都归它。** 为什么：讲话的段落不是一段一件事，而是一面几段（人才占 p4 一段，企业占 p5、p6 两段，改革 + 环境占 p8、p9 两段）；批卷人的要点表按面列，6/6 真人卷都是 4 条，p5/p6、p8/p9 无一拆开。当：材料是领导讲话实录或会议报道，段首有“要……”“我们将……”这类领起句。怎么做：先把领起句抄出来当标签（G-01），再把它后面直到下一个领起句之间的动作句挂进去。反例：报道体、调研体一段一件事的材料仍按 X-01。例子：2024二卷/Q1（四条）。这是 X-01 的 when 写窄了，不是 X-01 错。
2. **层 G：一句里“要 A、B、C，让 / 更好实现 D”，A B C 是动作，D 是目的，D 不写。** 为什么：目的从句是动作的效果，批卷人勾动作；本套 p4-2h–k、p5-2g、p8-4d–f、p9-1d–e 四处目的从句 0/6。当：做法题，句子以“让……”“更好……”“实现……”收尾。怎么做：切到第一个“让 / 更好 / 实现”为止。反例：题干问意义、目的时要写；目的从句里藏着一个新对象（比如“让企业……”后面接了企业要做的另一件事）时留。例子：2024二卷/Q1.要点4（删有组织科研转化）。
3. **层 G：材料“总句 + 省里已出台 / 今年将推的具体方案（带数字或名目）”，留总句，方案只在有余字时补。** 为什么：要点表按讲话的“要……”句抽，方案句是它的例证；本套通道 5/6 对受益权 2/6，转型升级 4/6 对技改 / 数字化 2/6，数字 0/6。当：讲话体或政策文里，一句原则后面跟“已出台 / 将推出 / 推动 N 家……”。怎么做：总句必写；方案的名目（不带数字）作它的手段写在前面（“以 X 带动 Y”）。反例：题干问“具体举措 / 具体安排”时方案句优先。例子：2024二卷/Q1.要点1、要点2。这是 G-03 的一个子情形，和 G-02 撞时总句 > 种类 > 数字。
4. **层 G：冠了名的工程 / 计划 / 方案是独立举措，不是它前面那句原则的清单项。** 为什么：现实里有名目的工程就是一项政策工具（有经费、有名额），批卷人认名目；本套人才工程 4/6，而它的“原则句”两手抓只有 2/6。当：材料里出现“实施 XX 工程 / 计划 / 行动”。怎么做：保留“实施 XX 工程”，删它后面的口号式展开（冲一流、补短板 0/6）。反例：工程名只是前一句的同义重复时不留。例子：2024二卷/Q1.要点1。这是 G-03 的 when 写宽了。
5. **层 G：一个主体后面并列的几个缺点（或几个属性），每个都是一个采分词，不是清单，不删。** 为什么：现实里规模、抗风险、带动是三件事，真人卷各 6–7/7；删一个丢一个。当：问题题里“X 规模偏小、抗风险不强、带动有限”这类并列。怎么做：全写，形容词可缩（不强 → 弱）但名词不能少。反例：并列的是同一属性的同义重复（“乱摆乱卖、随意摆摊”）时只留一个。例子：2024二卷/Q2.问题3。
6. **层 T-问对：材料主语说自己“需要 / 希望 X”时，问题侧写“缺 X”，对策侧再写“给 X”；第三方“应当 / 建议”句只进对策。** 为什么：主语自述的“需要”是它的能力缺口，是现象（缺指导问题侧 5/7、对策侧 6/7）；第三方的建议才是纯解法（2026省市 应当细化政策问题侧 0/9）。当：问对题，材料里有“需要上级……”“希望……”。怎么做：标句子时多问一句“这句是谁在说谁的事”。反例：企业向政府要补贴这类一面之词，两边都不写或改主语。例子：2024二卷/Q2.问题4、对策4。这是 T-问对-01 的 when 写窄了。
7. **层 T-问对：材料里的正面样本，对策里抄它做的动作，不写它的名字。** 为什么：批卷人在对策栏找动作，案例名不说明做什么；本套园墨村经验 0/7，它做的动作“开发利用”7/7。当：问对题材料里有一个已做成的村 / 企业当样本。怎么做：把样本段的动作句（成立文化公司开发运营）原话搬进对策，替换“推广 XX 经验”。反例：题干明问“推广经验”时写名字。例子：2024二卷/Q2.对策5。
8. **层 X：汇报要点题两节用“问题：/ 对策建议：”冒号节头，不写标题、抬头、结尾。** 为什么：5/7 用冒号节头，1/7 写标题；省下的 6–40 字全给必答点。当：题干说“汇报主要内容 / 要点”，字数 ≤300。反例：题干要求“格式完整”时写标题和落款。例子：2024二卷/Q2。把握低，只有一套证据。

### 现实词典新词

- **新型举国体制**：省里把政府组织动员的力量和市场竞争的力量合起来攻关键核心技术——政府定题目、集中资源，企业和高校分工做、按贡献分收益，为的是攻下卡脖子技术。（2024二卷 材料二第8段）
- **有组织的科研 / 有组织的转化**：科研题目由政府或平台按产业需要定下来，组织高校、院所、企业分工去做、做完接着转化，不是各家凭兴趣申课题。（2024二卷 材料二第8段）
- **包容审慎监管**：对新技术新业态，监管部门先让它做、留观察期，出了问题再管，为的是不把新东西一开始就管死。（2024二卷 材料二第9段）
- **应用场景**：政府拿出实际的用武之地（某条路、某个园区、某项政务），让新技术新产品先在这里用起来，为的是在使用中改进并打开市场。（2024二卷 材料二第7段）
- **创新要素市场**：把资金（科技金融）、技术、数据这些创新需要的东西做成能买卖流通的市场，为的是企业买得到、卖得出。（2024二卷 材料二第7段）
- **科技成果转化受益权**：事业单位科研人员把成果卖给企业或入股后能分到更大比例的收益，为的是让人愿意把成果拿出来用。（2024二卷 材料二第4段）
- **政产学研协同**：政府出政策和钱、企业出题目和产线、高校院所出研究，一起攻一项技术。（2024二卷 材料二第5段）
- **卡脖子技术**：被别国掌握、我们买不到或随时可能被断供的关键技术。（2024二卷 材料二第5段）
- **圩镇 / 美丽圩镇**：圩镇是广东乡镇的街市区；美丽圩镇是省里对镇街面的整治标准，要求无占道、无违建、干净有序。（2024二卷 材料五第2段）
- **现代农业产业园**：县镇圈一块地把种植基地、储备仓库、加工企业集中起来，由最大的企业带动周边农户。（2024二卷 材料五第4段）
- **规划专项资金**：上级专门给村里请人编村庄规划的钱；村规划定了土地、道路、产业怎么摆，旧了什么都动不了。（2024二卷 材料五第7段）
- **乡村振兴示范带**：沿一条线把几个村连起来集中建设当样板；上级给专项资金，村里要配套，配不出就有缺口。（2024二卷 材料五第10段）
- **村集体经济**：村集体自己的产业和资产收入，用来给建设配套；不发达就配不出钱。（2024二卷 材料五第10段）
