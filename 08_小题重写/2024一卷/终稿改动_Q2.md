# 2024一卷 问题二 终稿改动（v2 → 终稿）

一行一处：原来 → 改成 → 为什么。

1. 对策一「政府加大力度吸引上下游企业落户，形成产业聚集」 → 「政府加大力度吸引上下游企业落户」 → 「形成产业聚集」是跟在动作后面的结果句，而且重复了问题句里的标签词「产业聚集」，字数到顶时按次序第一个该砍的就是它（G-07：重复标签的结果句先砍）；「吸引上下游企业落户」本身已经对着「上下游企业少」和「聚集度不高」两句。省下 7 字给第二条的限定词。
2. 对策二「提升硕博培养占比」 → 「提升人工智能硕博培养占比」 → 问题句带了「人工智能」，对策照抄限定词（X-03），对策才钉回它要解决的那个专业，不然「提升硕博占比」读起来像全市高校的事。加 4 字。
3. 字数 299 → 296；cost 自造 18 → 14。自造的减少不是改词改出来的：这一版「提升」后面接的是材料原词「人工智能」，cost 把「提升」记成动词壳、「硕博」记成缩写，v2 里「提升硕博」连在一起被记成 4 字自造。实际用词和 v2 一样。
4. 问题三 供应商那句的「不愿共享」 → 「不共享」 → 查重报 v2 这一串（供应商 + 不愿共享 + 端口）和材料外的文字重合；「不愿」是态度，「不共享」是事实，问题栏写事实，少 1 字。
5. 对策四「纳入绩效考核」 → 「纳入考核」 → 同样是查重报重合（转化 + 纳入 + 绩效考核 连写）；「绩效」是修饰，删掉后和问题句「考核以项目论文为主」用的是同一个「考核」，配对更直接，少 2 字。
6. 对策五「联动金融服务体系」 → 「联动的金融服务支撑体系」 → 同样是查重报重合（股贷债保 + 联动 + 金融服务 连写、不带「的」）；改回材料第 10 段第 3 句原样（只去引号顿号），多 3 字，自造不变。三处合计字数不变，仍 296。
7. 其余三条和 v2 一字不改。第三条对策仍不给「省市对接需求重复」单配一句：「疏通跨系统数据渠道」里的「跨系统」本来就包括省级市级两个系统，一句管两个源头；单配要多 9 字、自造 2–4 字，换的是只有一份卷写过的点。第六条「加快新产品推广」仍留：材料原话 7 字，把握低但不亏字。
