# 申论做题 SOP（人话版）

> 这份文档只回答一件事：拿到题以后，手先干什么、再干什么、脑子里想什么、什么时候停。
> 用法：考前把第 1 节和第 7 节背下来；练题时按第 2–4 节走，练完按第 6 节对答案；考场上出事翻第 8 节。
> 前提：广东申论通常 120 分钟（以当年通知为准）；答题卡通常每行 25 格（拿到卡先数一下）。

---

## 1. 四条铁律（背下来）

**一、字数用行数管，不数字。**
限 200 字 = 8 行，写 7 行。限 300 字 = 12 行，写 10–11 行。"1000 字左右" = 写 38–41 行（950–1020）；"800–1000 字" = 写 34–38 行。
落到每个点上：**一点一行半**。写到第二行一半就收尾，写满第二行就是超了。
作文格子是有限的，超出格子的字不算分，宁少勿超。小题写到目标行数就停，多出来的余量只用来补关键词，不用来补句子。
**字数只能数，不能估。** 校对时把十一套定稿全用程序重数了一遍：头脑估的作文字数普遍偏少 15–30%，六篇 800–1000 的作文实际全超 1000。人在考场上靠数格子（一行 25 格，标点也占格），写完每段数一次；我出的答案一律程序核数，标注"含标点，程序核数"。

**二、草稿只写骨架，不写句子。**
骨架 = 每点一个 4–8 字的标签，后面跟几个两三字的缩写。整句只在答题卡上写一遍。

**三、超了砍尾巴，不砍点。**
砍的顺序：先砍数字和例子 → 再砍最长那一点的最后一个分句 → 永远不删整个点。写少了，往最短的点里补一个材料原词。

**四、拿不准就往安全的一边倒。**
不确定算不算一个点 → 写。不确定该不该合并 → 不合。不确定例子留不留 → 压成词留着。
道理：多写一条浪费十几个字，漏一条丢两分。

## 2. 小题通用流程（概括、对策都走这七步）

### 第 1 步　审题（30 秒–1 分钟）

**手**：在题干上圈三样东西——
1. 中心词：做法 / 举措 / 经验 / 问题 / 对策 / 特点 / 原因 / 影响
2. 主体和身份："S 市""如果你是科技局工作人员"
3. 字数，以及要求里的关键词：全面、准确、有条理、紧扣材料、具体明确

**脑子**：
- 中心词决定我要找什么样的句子。做法 = "谁做了什么"；问题 = "什么不足、什么缺、什么脱节"；特点 = "什么怎么样"。**不是这种句子的，一律不是点。**
- 主体决定谁的动作算数。题目问 S 市的做法，企业自己干的事只能当证据。
- 身份决定对策的动词。我是科技局，能"推动、督促、指导、搭建、培养、宣传"，不能替高校"改评价体系"。
- 字数换成行数，写在题干旁边：目标 7 行。

### 第 2 步　扫段落（1 分钟，不读内容）

**手**：数段，每段只看第一句和最后一句。在段旁标掉三种不用读的段：背景段、数据段、评论段。

**脑子**：
- 估点数：正文段数上下浮动一个。
- 每点行数 = 目标行数 ÷ 点数。这个数字定了，后面每点写多长就有数。
- 看段落是**按内容分的**还是**按人、按时间分的**。按内容分的（一段一个做法），段落就是分组；按人分的（六个人发言），读完要重新归堆。

### 第 3 步　第一遍读（占这题 40% 的时间）

**手**：
- 做法题：圈"动词 + 名词"的短语（召开座谈会、建立机制）。问题题：圈"名词 + 坏词"（人才不足、成果脱节）。
- 每段读完，段旁写一个字母加两三个字（B 话语权、C 投入）。
- 看到总结句、目的句（"为了……""旨在……"）、需求句（"迫切需要……"）、领导原话，划波浪线，标"名"——这是将来起名字用的。

**脑子**：
- **只判断类型，不判断价值。** 这句是不是一个动作/一个坏状态？是就圈。重不重要不管，重要性到分字数的时候再说。
- 类型不对的当场跳过：人名、数字、故事、情绪、背景。
- **不起名、不合并、不评价。** 这三件事第二遍再做，现在做会被前面读到的东西带偏。
- 看到一段写得特别长，念头只能是"这点值多给几个字"，不能是"这点更重要"或"这点是大点"。篇幅只管字数。

### 第 4 步　搭骨架（2 分钟）

**手**：草稿纸上一行一个点：字母、标签位置空着、后面缩写。

```
1 [ ]  座谈/征求意见       名：话语权（段尾）
2 [ ]  多元体系/企业为主/三并举/号召投入
3 [ ]  全周期机制/接力/研发融资
4 [ ]  企业为主体体系·发榜/出题遴选揭榜
5 [ ]  企业主导·专项政策/搭平台/院所解题   名：成果转化（目的句）
```

**脑子**：先用字母占位，名字空着。早填的名字会粘住，后面舍不得改。

### 第 5 步　第二遍，在骨架上做（3 分钟，不回材料）

按顺序做四件事：

**① 归堆。** 段落按内容分的，一段一堆。按人分的，按"谁做的 × 哪一环"归：同一个主体、同一件事的，归一堆；不同主体的，分开。
**先看对象有没有官方分量**——不只作用题，做法题、建议题、对策题都一样：对象是"乡村振兴"就按"产业兴旺、生态宜居、乡风文明、治理有效、生活富裕"分，对象是"政府管理与服务"就按管理、服务分。分量常常写在总述材料或领导讲话的第一句里。有分量按分量，没分量再按段落或主体。
**堆数跟材料走，不跟预算走**：一级要点数 = 材料里互不重复的问题/做法数，通常 4–6 个。只有"同一件事说了两遍"才合（六个人里三个人都说"不了解需求"，合一堆）；两件不同的事不能为了省标签而合（"产业集聚度低"和"硕博培养少"是两件事，合了对策就对不上）。**预算不够就把每条写短——类名 + 一个表现词——不减条数。** 材料点了名的类别，它的词必须出现在答案里。

**② 定父子。** 一堆里谁是标签、谁是内容？判据只有一条：**能装下所有兄弟的才是父。** 装不下的就是兄弟，哪怕它那段写了一整页。

**③ 合并。** 只合"一件事说了两遍"的（企业发榜 / 高校揭榜，是一件事的两头）。以下情况不合：主体不同（市政府 / 银行）；能被一个大词罩住（投入体系罩得住金融服务，不是合并理由）；拿不准。
注意"合并"和"塞进去"是两回事：合并是把两件事写成一件，会丢词；塞进去是两件事都写、只共用一个标签，不丢词。①里说的是后者。

**④ 起名。** 见第 5 节手册。顺序永远是：抄材料 > 五个动词里选 > 自己造。

然后分字数：每点一行半；例子和数据是三层，行数不够先砍它们。

### 第 6 步　写（占这题 40% 的时间）

**手**：序号 + 标签 + 句号 + 几个短句用逗号隔开。不写总括句——**除非材料自己有结构性的总结句**（"以文兴村，农文旅一体化，游养买一条龙"，它本身概括了分点），有就抄成总句放最前面，那是材料原话，是采分点。只是感叹的（"整个镇年轻了"）不算，不抄。问题和对策各一段，段内不分行（分行浪费格子）。每写完一点看一眼行数。
**小题不搞二级结构**："环境绿 + 理念绿（下套①②③④）"这种父级套子项，在 200 字里既费字又乱条理，真人考卷里这么写的那份是同题最低分。几个方面就平铺几条。
**拿到卷子先数格子**：2026 省市卷的答题纸是 220 / 320 / 1220 格，比题干限字多一截。目标行数按格子的九成留。

**脑子**：写到第二行一半就找地方收句号。标签本身很长的（材料给的原句），后面只放两个短句。

### 第 7 步　检查（1 分钟）

- 每个点有动词吗？（做法题）每个点是"名词 + 坏词"吗？（问题题）
- 标签 8 字以内？
- 有没有哪个点其实是另一个点的儿子？
- 材料里那几个少见的专有词在不在？（接力式、发榜、特派员）
- 行数在目标内？

## 3. 分题型补充

### 概括做法 / 举措 / 经验
- 找"谁做了什么"，主语必须是题目指定的主体。**主语要精确到"县里 vs 县里的农户"**：农户响应县里做的事（收到预警后浇水、打药），要写成县里的动作（"平台预警指导荔农精准浇灌"），不写成农户的动作。
- **题干引号里的每个词都要在答案里出现。** 题干说"追求质量、打造品牌"，材料重心在品牌，"提升产品质量"这句就容易被砍，砍了就丢一个题干关键词。
- **主语、平台名用材料原词**：材料写"供应链服务公司"就写"供应链平台"，别自己换成"联盟"。
- 目的句、效果句不当点、不当标签内容，可以当**标签的名字来源**，也可以跟在动作后面当尾巴（"建立指导站，打造一站式平台""气调集装箱延长食用期"）。行数够就带一个。
- **总结句和例名都要写。** 材料的总结句（"丰富文旅产品供给"）是清单最可能用的措辞，例名（夜市、风情园）是低频词保险。形式："总结句 + 例名、例名"。例名留两个最具体的，不写成句子。人名、数字、故事不留。
- 材料自己给了总结句的（"构建起以企业为主体的科研组织体系"），直接抄当标签。
- **排比整抄。** 材料里三个并列的四字短语（"凝练科研问题、吸聚创新资源、兑现创新价值"）是清单的骨架，整体抄进去，别只抄一个——每个四字，便宜。材料用"××就是生命"这种强调句引出的动作（提质增效），是必踩点。

### 概括问题
- 找"什么不足 / 缺 / 脱节 / 滞后"，写成"名词 + 坏词"。
- 总括性的问题写出来，小毛病跟在后面当展开；副作用（"经费打了水漂"）不写。
- **别从建议反推问题。** 材料里有人说"要搭平台"，不等于材料说了"缺平台"。
- **对话里的随口抱怨也是问题证据**（"果园这里手机信号也不好"），不只看陈述句。从规划反推的问题（"正在筹备协会"→缺协会）把握中等，放尾巴。

### 对策
- 先按上面找问题（或者找材料里已经有的做法）。
- 对策的名字 = 问题的名字反过来：脱节 → 对接，不足 → 强化，短板 → 补齐，滞后 → 推动落地。不用另想。
- 一条对策 = 目的 + 办法（+ 谁来做）。只有目的（"要了解企业需求"）不算。
- **问题侧和对策侧分工**：问题侧写"表现"——类名 + 一两个表现词（人工剥皮、林道不畅），不写句子；对策侧写"手段"——类名取反（短）+ 怎么做。两侧只共用类名，类名各出现一次是给阅卷人对针对性用的，省不得。出现"X 不畅 / 完善 X"这种镜像，说明对策那格缺手段：要么给真手段（修建机耕道），要么把它降级，只留在问题侧当关键词。
- 办法从哪来，按顺序：材料明说的办法 > 从"以前怎么做错的"反过来 > 自己补标准办法（培训、平台、机制、认证）。**自补每堆至多一条，只在材料的办法用完之后，永远不替代材料的办法。**
- **反推的第二种来源**：材料里"全镇只有一家愿意""还在摸索""不知道怎么办"这类句子，反推成激励（试种补贴）或培训（电商技能培训）。它们不是问题句，容易漏。
- **"材料明说"包括同一套卷子里的其他材料。** 本题材料只说了"经费缺口大"，别的材料里有"社会资金流向乡村""集体经济强起来"，拿来当手段，比自补"鼓励村民捐款"强得多。
- 问题和对策一一对应编号，一是对一是。**真分数的证据**：2026 省市卷两份问题梳理相同的考卷，六问六策、手段来自材料的那份 84.5 分，六问九策、手段大半自补（座谈会、专班、集采、基金）的那份 77 分。
- **"针对性"= 一类风险一条**：材料里每一户、每一个案例都要有对应的措施，漏一户就是漏一条（参考答案曾整户漏掉因残致贫的老刘家）。
- **"具体明确"= 写到工具**：无人机巡山、古树数字档案、先抢救后补手续、发传单办讲座、招专业人士。2026 县镇卷三份 90 分卷的对策全是这种能直接执行的东西；"运用科技手段""加强宣传"这种动词级写法拿不到这个分。反推时多问一句"用什么工具做"。
- 对策条数可以比问题多（90 分卷四问六策），前提是每条都能对回某个问题、都是材料来的具体工具；会扣分的是自补的泛话，不是条数。
- 材料里点了名的问题类别（"现在主要是政策落地的问题""传统观念"），**它的词必须出现在答案里**。条数跟材料走：互不重复的问题有几个就写几条（4–6 条都正常），条数多就每条写短——问题一句、对策一句。

### 大作文
- **找 A 和 B。** 题干的判断句"A 是 B 的关键 / 大文章 / 头号工程"：A 是要拆的（创新），B 是每段最后要落到的（新质生产力）。
- **标题必须同时含 A 和 B。** 题干给了口号句的（"站在新起点，迈向新征程"），标题要把口号里的词带上；参考答案常把口号丢了，只写"实现高质量发展"，立意就不贴。
- B 再往上的目标（高质量发展、中国式现代化）只在开头结尾升华，**不进分论点**。分论点全落到远目标上就是跑题。
- **题干给了两个落点的（"关系 A 和 B""既……又……"）**：分论点要么就是这两个落点各一大段，要么分四段但每段观点句必须点明属于哪个落点。2026 县镇卷三份 90 分卷的分论点逐字重复题干："绿美广东生态建设是为广东长远发展奠定坚实基础的重要工程 / 是为民生福祉注入绿色动能的重要工程"。开头末句把两个落点都点一遍，结尾再点一遍。
- **先定拆哪边。** 题干是"做好 A 这篇大文章 / 如何 A"，材料给的是 A 的做法 → 按 A 拆（省市卷：科技 / 产业 / 绿色 / 体制创新）。题干是"B 关键在 A / A 是 B 的根本"，材料给的是 B 需要什么 → 按 B 拆（县镇卷：产业给乡村带来富、才、美、文）。判法就一句：材料在拆哪边，你就拆哪边。
- 分论点 3–5 个。按 A 拆：来源是每份材料顶上那个词 + 领导讲话对 A 的分类。按 B 拆：来源是 B 的官方分解（五个振兴、三个层面）+ 领导讲话里"没有 A 就没有 ××"那句。
- **按 B 拆时，B 的官方分解每个分量的词都要出现。** 段数不够就两两合并（文化 + 组织写一段），不能整个漏掉一个。
- **按 A 拆时，题干引语里 A 的每个分量都要有一段或至少一句。** 题干引了"强化企业主体地位、四链融合、成果转化"，文章里就不能没有企业转化那一段。
- **每份材料至少在某一段露一次脸。**
- **分论点和材料要对位。** 题干或材料给了"强县促镇带村"这种分层结构时，每一层用讲那一层的材料（镇→讲镇的那份），别拿别的层的材料顶。
- **问题类材料在作文里取反用。** 把它的问题写成"要……"，放进对应的分论点——既是联系材料，又给了 how。别只拿它当一句"联系实际"。
- **观点句优先用材料各面开头的判断句。** 材料 4、6、7、8 每份第一段常常就是一句判断（"绿色发展作为生产方式的变革已成为新增长点""生态环境是根基""推动绿色发展是满足人民需要的必然要求"），两份 84.5 分的真人考卷直接拿它们当分论点。自己的对仗观点句可以保留，但这几句必须出现在段里当道理句——阅卷人认的"与材料联系紧密"就是它们。
- **写完核一遍案例**：每个案例的地名、人名、做法三样对不对得上（番薯节是 K 镇，股权改革是南紫村）。串了就是"论据确凿"这一项的硬伤。
- **再核一遍"最、首位、入选、全覆盖"这类判断词**：每个都要能指回材料原句。校对 2026 县镇卷时发现两处自己加码的——材料只说"省内多个海湾入选"，我写成"Z 市海湾入选"；材料只说"绿色工厂数量首位"，我写成"绿色工厂、绿色供应链企业数量首位"。加码一个字，论据就不确凿了。
- **题干含"经验 / 实效和经验"的**：经验做观点句，写成可迁移的规律句（"基础设施先行、规则衔接跟上"），收束句用"经验是：……"；实效仍然每段做证据。参考答案常为了写规律把论据全丢，那是它失分最多的地方，不学。
- 每段固定四句：观点句（四段对仗）→ 道理句（这种创新是**怎么**导致那个结果的，不是"很重要"）→ 广东证据（三个项目名 / 地名 / 工程名，数字每段至多一个）→ 收束回 B。
- 行数：开头 6 行，每段 8 行，结尾 4 行。
- 结尾用材料里的原句或意象收，不自己编对联。

### 作用 / 意义 / 重要性题（"分析说明 X 对 Y 的作用"）
- 找的是"主体让对象得到了什么"。每条 = 标签 + 动作串 + **效果词**。
- **分组的钥匙看对象**：对象有官方分量的（乡村振兴→治理/产业/文化/收入/生态），按对象分量分，标签是"改善基层治理"这种领域词；对象没有现成分量、材料按主体排的（青年对制造业），按主体分，标签是"主体 + 作用"（青年企业家引领发展）。
- **分量常常写在第一份总述材料里**（"五个振兴、农业高质高效、乡村宜居宜业、农民富裕富足"），题干指定的那篇材料里没有，容易漏看。审作用题先翻总述。
- **例子不砍，砍的是人名和数字；例子后面的效果词是采分点，一个不能丢。** "远销 80 多国"砍成"拓宽市场"，"呆账降到极低"砍成"降低风险"。这是它和概括题最大的不同：概括题的例子是三层，作用题的例子里长着二层的词。
- **群众的反应也是效果词**："回去讲给孙子听"→群众自发传播，"果树不长虫了"→学以致用。这类句子最容易被当成感想砍掉。
- **反面评论句反过来也是效果词**："如果没有信息化手段，要耗费大量人力物力、拖累发展节奏"→节约人力物力、稳住发展节奏。

### 成效 / 效果题（"分析说明……取得的成效"）
- 元素是"某方面 + 好起来了"，标签是"名词 + 变好的动词"（经济复苏、外贸回稳、负担减轻、服务提速、活力增强）。
- **结果词是主力，数字是保险**：转正、回稳、第一、减负、量质齐升这些词一定要在；数字每条至多一个（总量、惠及面），两家参考答案都不写数字。
- 材料里的做法（减免社保、专机返岗）写成效时当主语、结果当谓语："减免社保费惠及 29 万家"。
- 宏观指标里"市场主体增长"是经济复苏的表现之一，并进复苏；同一材料里的两件事（商事秒批、知识产权保护）各自一条。

### 理解题（"谈谈你对'密码 / 秘诀 / 关键'的理解"）
- 比喻词先用一句话解开（"密码"是 G 市加强科技创新的一系列做法），再分条。分条的形状和做法题一样：标签 + 材料做法 + 一个比例数字或效果词。
- **材料里讲做法的段落每段一条，写成效的段落（无人工厂效率提升）也算一条**——它既是证据，也是一个独立的做法（企业应用创新）。别把它当纯证据砍掉。
- 材料按人物走的，人物后面那句评论（教授说、专家说、当事人总结）就是这条的父名，比例子值钱。
- 同一主体层的（企业家和职业经理人）可以合成一条，用分号隔两层。
- 题干有"观点鲜明"的，开头一句总观点，用材料里的习语原词拼，14 字以内；只要求"概括"的，不写。

### 策论文（"围绕……撰写一篇策论文"）
- 分论点全是对策，动词一律"要"。和议论文的区别：议论文的证据是"广东做过什么"，策论文的证据是"要推广广东已经做对的什么"。
- **开头要有靶子**：把材料里的短板句、问题句抄进去（"关键核心技术受制于人""要素配置协同亟待优化"），对策冲着它们去。
- 每段：对策观点句（对仗）→ 一句道理 → 三个"要"，**每个"要"带一两个材料里的具体做法名**（产品医院、技术流、信任筹建）→ 收束。没有专有名的对策段是泛话，参考答案常犯这个毛病。
- 对策只从材料的正面做法里来，不自己编；七八份材料两两合并成四段。

### 优势 / 有利条件 / 特点题（"分析 X 的优势"）
- 元素是"名词 + 判断"（文化同源、地理相近、遗产丰富、产业雄厚），标签和内容都是"怎么样"，不是"做了什么"。
- **特点题的标签越短越像特点**：三字"名词 + 形容词"（任务急、任务重、挑战多、责任大、风险高）。当事人自己总结的"最难的几点"是特点的直接来源；当事人的个人经历（城里长大第一次见过年）不是工作特点。
- 做过的事（联合申遗、合作办展）不是优势，但它证明"已有合作基础"这种优势——事实留，动作词不当标签。
- 材料自己的总述句（"文化同源、血脉相通，是重要基础"）就是第一条。
- 每条 = 标签 + 事实 + 半句意义（"所以合作有天然纽带"）。题干"分析透彻"要的就是那半句。
- **材料用"最、核心、宝贵、关键"强调的元素单列一条**（孙中山足迹"宝贵而核心的共同财富"）。强调词是出题人在给采分点画线，所有题型通用。
- **跨篇的条件是保险**：讲对象的那篇是主材料，别篇里的条件（另一篇的产业基础、网红渠道）压成最后一条写短，不和主材料的条件平分字数。

### 启示题（"这件事 / 这次会议对你有什么启示"）
- 每条 = 标签 + **认识句（抄材料里的原话或道理）** + 做法句。"认识深刻"靠抄原话最省力："安全重于泰山""每慢一分钟就多十分危害"。
- 材料是会议对话的，每个发言人的话题就是一条；别人被指出的错（预案疏漏、出动慢）反过来就是做法；**直接对"我"说的那句话必须是一条**。
- **"理解深刻"的做法：每个难题多问一句"它为什么会出现"。** 挖掘机难请，是因为全县同时复耕——启示就从"善于借力"（怎么解决的）变成"增强预见性、提前协调资源"（为什么会遇到）。动作层一条，深一层再一条。
- **多人物的启示题按人写**：一人一条，品质当标签（"以民为先，迎难而上"），这个人的做法收全，末尾一句深一层的启示；品质相同的人合一条。按品质跨人写会为了归类丢掉一半做法。
- 不写"我"没权限做的事（定处罚标准、加强队伍建设是领导的话；镇一级写"人工增雨"是气象部门的事）。

### 发言提纲 / 汇报提纲
- 格式：标题（关于……的发言提纲）→ 开头一句总述 → 主体分条 → 结尾一句（用材料里领导的总结句）。提纲是条目不是稿子：每条标签 + 一句做法 + 半句例证，不寒暄。
- **材料按村 / 单位走的，提纲就按村写**，做法标签放在村名后面（"一、百岭村：盘活闲置资产，发展旅游服务。1.……2.……"）。按村写不用冒归错组的风险，也和听众的预期一致。
- 材料按主题走的，按主题写。

### 原因 / 影响 / 应用文（简）
- 原因往上游找："为什么会这样"问出来的就是。影响往下游找："导致了什么"问出来的就是。
- 应用文 = 同一套找点 + 一个格式框（标题、称呼、落款）。格式另背，找点不变。

## 4. 做题前顺手做的一件事

翻材料做问题一、二的时候，**给每份材料顶上写一个词**：理论 / 家底 / 科技 / 产业 / 绿色 / 体制。只看第一段和最后一段就能写。写大作文时分论点直接从这几个词里挑，不用再翻。

## 5. 起名手册

**名字从哪来（按顺序）**
1. 材料的总结句、段首句、目的句（"为了……"）、需求句（"迫切需要……"）、领导原话 → **抄**。
2. 没有的话：五个动词 **增强、健全、优化、构建、推动** + 这段里反复出现的名词（服务、平台、机制、体系）。
3. 问题题：名词 + **不足 / 缺乏 / 脱节 / 滞后 / 短板**。
4. 对策题：把问题的名字反过来。

**名字长什么样**
- 4–8 字，动词 + 名词："优化金融服务""增强企业话语权"。
- 材料给的长名字（"以企业为主体的科研组织体系"）放在标签后面的第一句，别硬塞进标签。
- 名字和内容的词性要配：内容是动作，名字也得是动作（"优化金融服务"），不能是结果（"金融服务体系完善"）；内容是特点，名字也是特点。
- 检查法：把名字和内容用冒号连起来读，内容应该读成"名字的一个例子"，读成"名字的原因"或"名字的结果"就是错了。

**考前准备**：五个动词和常用名词表（机制、平台、体系、链条、要素、人才、资金、技术、品牌、服务、基础设施）背熟。考场上不现想新词。

## 6. 平时练题的对答案方法

**写答案之前**：把没把握的地方先写下来——哪个点不确定算不算，哪个名字是自己造的，哪两个点不确定该不该合。

**对照时，差异分四类，各修各的：**

| 差异 | 修什么 |
|---|---|
| 我漏了一个点 / 多写了一个点 | 看第 3 步的圈法，是不是类型判断错了 |
| 我当大点的，答案当小点（或反过来） | 看"装得下所有兄弟"用没用对 |
| 点对了，名字不一样 | **不改规则**，记下来攒样本，攒五道以上再看有没有系统性偏差 |
| 答案带了我砍的例子，或没带我留的 | 两家答案一致才改 |

**参考答案不是满分。** 先推它扣在哪，再决定学不学它：
- 材料里的低频专有词它漏了几个？
- 材料自己起了名的类别它合掉了没？
- 它自补的东西有没有挤掉材料里明说的？
- 作文标题和观点句落在题干的直接目标上没有？
- 每份材料都用到了没？字数够不够？

**改规则的门槛**：能说清楚为什么（机制），而且能写一句对下一道题的预测。预测两次落空，撤回。

**参考答案的固定风格（三卷九题总结）**，知道它是风格，别当标准：
- 学它的：标签 4–6 字；效果尾巴带一个；对策和问题一一对应；材料里各说各的就一人一条。
- 不学它的：标签泛化、内容只抄总结句不写例名（丢低频词）；问题侧只有类名没有表现词；对策爱自补泛话（优化营商环境、加强交流合作、建立激励机制），有时挤掉材料明说的办法；作文说理为主、证据薄、材料用不全、字数常常不够（2024 一卷范文约 780 字）。

**已确认的预测**（三卷都命中）：标签 ≤ 8 字；问题侧无反推条目；材料只给目的时参考答案会自补标准手段；范文近零数据、有材料外说理；观点句尾巴统一、落在题干目标上。
**作为写法保留、不再用来预测参考答案的**：不同主体的动作分开写（一落空一命中）。
**已撤回的**："堆数 4–5 个"——2024 一卷参考答案 6 + 6。条数跟材料走。

## 8. 出事了怎么办

- **写超了**：小题砍最长那条的最后一个分句；作文砍最后一个证据。一条横线划掉一个分句，别涂整行。
- **想不出名字**：看这段第一句和最后一句有没有总结句，有就抄。没有就"五个动词 + 反复出现的名词"。三十秒想不出，先写"一、"空四格写内容，最后回来填。
- **材料读不完**：大作文只要每份材料的第一段、最后一段和顶上那个词。中间段是证据仓库，写到哪段翻哪段。
- **不确定算不算一个点**：写。
- **不确定该不该合并**：不合。
- **不确定这段的主体是谁**：主体不同就分开写，宁可多一条。
- **作文时间不够**：先写结尾，三行。没结尾会被当成结构不完整，比少半段分论点亏得多。
- **发现前面写错了一个点**：不涂。在后面点里把正确的关键词带上，阅卷人踩点，看到关键词就给分。
