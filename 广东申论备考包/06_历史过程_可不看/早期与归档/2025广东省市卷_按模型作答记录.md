# 2025 年广东省考申论（省市卷）· 按统一模型作答记录

> **用途**：三道题全部按《统一结构模型》的流水线作答，每题先写思路、再给答案，并**预先登记我没把握的节点**。交叉验证时，请把机构答案的差异先按第 0 节分类，再决定改不改规则。
>
> **字数**：答案按答题卡计数（标点占格）。问题一 ≈192 字（限 200），问题二 ≈298 字（限 300），问题三 ≈1060 字（要求 1000 左右）。

## 0. 交叉验证的操作约定（先读这个）

拿到机构答案后，把每一处差异归入四类，不同类修不同东西：

| 差异类型 | 含义 | 修什么 | 修的门槛 |
|---|---|---|---|
| 元素级 | 我漏了一个采分点，或写了一个答案上没有的 | 投影规则、独立性判据 | 一家一致即值得看 |
| 层级 | 我当父节点的，答案当孩子；或反之 | 装得下测试、因果窗口 | 一家一致即值得看 |
| 命名 | 点对了，词不对 | **原则上不改规则**，只积累样本 | 攒五道以上再看有无系统偏移 |
| 取舍 | 答案带了我砍的例子/数据，或没带我留的 | 层序概率假设、例证保险规则 | 两家以上一致才改 |

两条防线：
1. **机构答案不是官方答案**。多家互不一致的点，标为"模糊点"，不用来修规则；只有多家一致而我不一致的点，才动根。
2. 每题末尾有"预登记的不确定点"。差异落在预登记范围内的，是预期内的，不构成规则失效的证据；**差异落在我标"高把握"的节点上，才是真信号。**

## 问题一　概括 S 市强化企业科技创新主体地位的主要做法（20 分，≤200 字）

### 思路

**审题（投影与限定）**
- 中心语"做法" → 投影 = 动作，元素的最小单位是动宾短语。
- 施动者限定 = **S 市**（政府侧）。企业自己做的事（车企投 1000 亿）不是元素，只是证据；除非材料写成政府动作（"响应政府号召"里的"号召"）。
- 对象限定 = "强化企业科技创新主体地位"。凡不指向"让企业当主体"的动作，即使是做法也不进树。

**预算前置**
- 材料 4 共 8 段。首段是四个 90% 的结果数据（背景），末段是刘教授的评论（定义句），中间 6 段是做法。扫段首句估 4 组 → 每组约 45–50 字，总括句可省。

**第一遍：段落挂位置（只做类型判断，字母占位，不起名）**

| 段 | 内容 | 类型判断 | 处理 |
|---|---|---|---|
| A | 四个 90% | 结果数据，非动作 | 不进树（不确定点 c） |
| B | 座谈会请企业建言；制定科技政策征求企业意见是"规定动作"；"让听得见炮声的人有话语权" | 两个动作 + 一句框架句 | 元素 ×2；框架句作父名来源 |
| C | 健全以企业投入为主、财政/信贷/个人并举的多元化投入体系；93.3% | 总结句 + 数据 | 元素 ×1（本身就是父名级）；数据砍 |
| D | 车企"梦想日"、响应号召再投 1000 亿 | 企业侧动作 + 数据 | 归 C 的三层例证；政府侧只剩"号召/引导" |
| E | 银行：全生命周期金融服务机制、接力式服务、研发融资 | 动作（信贷渠道） | C 的孩子 |
| F | 企业发榜模式（三个"由市场"）；"企业出题、研究院遴选、高校揭榜"；"构建起以企业为主体的科研组织体系" | 两个机制 + 总结句 | 元素 ×2；总结句作父名 |
| G | 产学研专项政策（企业为主体）；政府搭平台聚合需求；高校院所针对性解决问题；目的句"让成果从实验室走向车间" | 动作 ×3 + 目的句 | 元素 ×3；目的句作父名来源 |
| H | 刘教授："企业主导产学研深度融合" | 定义/评论句 | 不新增元素；给 G 供名 |

**第二遍：在骨架上做全局操作**
- 分组：B ｜ C+D+E ｜ F ｜ G+H → 4 组，与段落默认分组一致，无需重组。
- 装得下测试：C 装得下 E（信贷融资是投入渠道之一）✓；G 装得下"搭平台"✓；B 内两个动作互为兄弟，父节点需合成。
- 命名依据与把握度：
  1. 保障企业话语权 —— **合成**（材料只给"让…有话语权"这句框架句）→ 中
  2. 健全多元化科技创新投入体系 —— 材料原句 → 高
  3. 构建以企业为主体的科研组织体系 —— 材料原句 → 高
  4. 推动企业主导产学研深度融合 —— 材料原词（H 段） → 高
- 取舍（层序）：三层全砍（90%、93.3%、2236 亿、1000 亿、300 课题、数百人）；二层保留机制名（全生命周期金融服务、发榜、出题—遴选—揭榜、专项政策、搭平台）；"让企业掌握转化主动权"是余总的态度句 → 目的/效果，预算不够，砍。
- 词性检查：四个父节点均为"动词+名词类名"，孩子均为动宾短语，冒号连读全部为实例关系 ✓。

### 答案（≈192 字）

一、保障企业话语权。召开座谈会听取企业建议，制定科技政策必征求企业意见。
二、健全以企业为主、财政信贷个人并举的多元投入体系，建立企业全生命周期金融服务机制，提供研发融资。
三、构建企业为主体的科研组织体系。推行企业"发榜"模式，建立"企业出题、研究院遴选、高校揭榜"机制。
四、推动企业主导产学研融合。出台企业为主体的产学研专项政策，搭建平台聚合企业需求，引导高校院所针对性解决企业难题。

### 预登记的不确定点
- (a) **点一是否独立成点**。机构可能把它写成总括句"尊重企业主体地位"，或并入其他点。我判独立，理由：它是唯一的"决策环节"动作，其他三点都是"执行环节"。把握：中。
- (b) **"引导企业加大研发投入"是否该显式写出**。D 段整段是车企例子，详略权重不小，但政府侧动作只有"号召"。我用"以企业为主"覆盖它。把握：中低。
- (c) **四个 90% 是否进总括句**。我判为结果数据，不写。把握：中。
- (d) 点三与点四是否会被机构合并为"产学研/科研组织"一组。我判分开：一个是科研组织方式（谁出题），一个是转化路径（怎么落地），施动者与环节都不同。把握：中高。
- 命名：点一的"保障企业话语权"是合成名，机构可能用"尊重企业意见""让企业参与决策""赋予企业话语权"，属命名差异，不修规则。

## 问题二　梳理 G 市科研成果转化中存在的问题，并提出对策建议（30 分，≤300 字）

### 思路

**审题**
- 两个中心语："问题"（投影 = 负面状态，"名词 + 负面谓词"）和"对策"（映射 = 取反 + 补手段）。
- 身份限定 = **G 市科技局工作人员** → 对策的施动者是科技局/政府，动词只能用推动、督促、指导、搭建、培养、宣传、鼓励；不能替高校直接改评价体系，只能"推动高校改"。
- 预算 300 → 问题 ≈150、对策 ≈150。
- 结构判断：材料 5 的"段"是**发言人**，而发言人之间互相重复（叶/苗/王都说"不了解需求"），所以**默认分组（按段）在本题失效，必须按问题类别重组**。这是与问题一最大的差别。

**第一遍：按发言人归位**

| 发言人 | 负面状态（元素） | 材料明示的对策（手段来源①） |
|---|---|---|
| 叶（农科院） | 不了解产业现状与企业需求；成果与产业发展脱节；(a) 以前直接找企业转化碰壁 | 经验：与市场需求、产业发展对接 |
| 廖（社科院） | 科研人员重论文、有潜力的成果不转化；评价体系未纳入转化或权重低；转化收益比例过低、限制条件多 | — |
| 张（记者） | 技术经理人数量不足、素质不高；（缺）企业与科研机构沟通平台 | 培养高水平技术经理人；搭建沟通平台 |
| 苗（青年学者） | 评价"指挥棒"以论文、纵向项目为主；缺市场意识、产业意识，不了解需求；缺机构辅导；转化风险大、有顾虑 | （隐含）机构辅导 |
| 王（企业） | 科研重技术先进性、轻性价比和市场前景 | 评价体系加入转化要素、权重合理；科技特派员深入企业 |
| 李（科技局） | 政策落地问题：部分高校院所未出台具体实施办法 | 督促指导；高校结合实际出台制度；加大宣传解疑；用活激励与保障；校企共建创新联合体；建统一交易平台 |

**因果链定位**
- B（题干所问）= 科研成果转化不畅、与产业脱节。
- A（总括性原因）= 供需不对接、评价导向偏差、激励保障不足、转化服务短板、政策落地滞后。
- a（过程性细节）= 直接找企业碰壁、只发论文、收益比例低、限制条件多、技术经理人少、担心失败。
- b（副作用）= "经费智力人力打水漂" → 不写。
- 问题题取 A 层写，a 层作 A 的展开内嵌；对策的前置词 = A 取反，手段来自材料明示（张/王/李）+ 少量 a 反推。

**第二遍：重组与命名**
- 合并规则：同一负面状态多人重复 → 合并（叶/苗/王 → 供需脱节；廖/苗/王 → 评价导向）。
- 一处存疑的合并：**收益低（廖）与风险大（苗）**是两个不同原因，按"拿不准不合并"本应分开；但李处长那句"把激励机制和保障措施用活用好，消除后顾之忧"把两者并列在同一句里，视为材料给出的默认分组 → 合并为"激励保障不足"，并列写出两个关键词作保险。
- 命名：问题父名以"X + 负面谓词"合成（供需脱节 / 导向偏差 / 保障不足 / 服务短板 / 落地滞后），中等把握；对策父名一律取反（对接 / 改革 / 强化 / 补齐 / 抓落地），与问题一一对应。
- 手段来源核对：全部来自材料明示（特派员、创新联合体、评价加权、技术经理人、沟通平台、交易平台、督促指导、宣传解疑），无自补。
- 砍掉的：张记者的"三元素"是分析框架不是问题；"学术成果质量"无人说它有问题；"打水漂"是副作用。

### 答案（≈298 字）

问题：一是供需脱节，科研人员缺乏市场意识，不了解产业需求，重技术轻市场。二是评价导向偏差，高校院所重论文课题，转化未纳入评价或权重低。三是激励保障不足，收益比例低、限制多、风险大，科研人员有顾虑。四是转化服务短板，技术经理人量少质弱，缺校企沟通平台。五是政策落地滞后，部分单位未出台实施办法。

对策：一是推动供需对接，推行科技特派员制度，组织科研人员进企业，鼓励共建创新联合体。二是改革评价导向，推动转化纳入评价、权重合理。三是强化激励保障，推动提高收益比例、减少限制，用活保障措施，消除顾虑。四是补齐服务短板，培养技术经理人，搭建校企沟通和成果交易平台。五是抓政策落地，督促指导高校院所出台实施办法。

### 预登记的不确定点
- (a) **风险顾虑是否独立成一条问题**（第六条）。我按材料默认合并进"激励保障"。把握：中。若多家分开，修的是"默认分组"的优先级，不是合并判据。
- (b) **"科研人员重论文不转化"是否作为独立问题**。我判为评价导向的行为表现（a 层），内嵌。把握：中高。
- (c) **"缺机构辅导"归哪一组**。我归供需脱节的对策侧（特派员/辅导），未在问题侧单列。把握：中。
- (d) **对策与问题是否必须一一对应编号**。我做了对应。题干"有针对性"支持这么做。把握：高。
- (e) 机构可能把张记者的"三元素"写进问题（"转化链条要素不全"）。我判不写。把握：中高。
- (f) 施动者用词：机构答案可能不受"科技局身份"约束，直接写"高校要…"。若机构这么写而我不这么写，属身份处理差异，先不改。

## 问题三　围绕广东"继续做好创新这篇大文章"撰写议论文（50 分，1000 字左右）

### 思路

**命题定位**
- 题干判断句："新质生产力的显著特点是创新"，"做好创新这篇大文章，推动新质生产力加快发展"。
- A = 创新（继续做好创新这篇大文章）；B = 新质生产力（加快发展）。
- 柄：新质生产力 → 高质量发展 → 中国式现代化（广东"走在前列"）。材料 1 末段与材料 8 末段把这条链明说了。
- **星心 = 新质生产力**（离 A 最近的目标），不是中国式现代化。

**拆哪一边**
- 材料按领域给出广东的做法：3 科技创新、4–5 企业主体与成果转化、6 产业创新、7 绿色、8 体制机制与要素、2 基础与人才。→ 材料拆的是 A 侧，故拆 A。
- 材料 1 同时给了 A 的官方分解（"既包括技术和业态模式层面的创新，也包括管理和制度层面的创新"）和 B 的特征（"高科技、高效能、高质量"；"技术革命性突破"；"先进生产要素集聚"；材料 7 补"绿色生产力"）→ 这些就是边上的 bᵢ。

**刷毛选择（4 根，每根约 200 字）**

| aᵢ（A 的分量） | bᵢ（B 的分量） | 证据来源 |
|---|---|---|
| 科技创新 | 技术革命性突破 / 高科技 | 材料 3：全过程创新链、国家实验室、大科学装置、卡脖子攻关 |
| 产业创新（科技与产业融合） | 现代化产业体系 / 高效能高质量 | 材料 4、6：企业主体、发榜、三类产业并举、机器人、新能源汽车 |
| 绿色创新 | 绿色生产力 | 材料 7：龙岗、阳江、湛江、惠州 |
| 体制机制创新 | 先进要素集聚 | 材料 8：政策体系、深圳先行先试、大湾区平台、百千万工程、人才 |

- 为什么不是 5 根：1000 字预算下 4×200 + 开头 200 + 结尾 130 已满；人才折入第 4 根（要素），企业主体折入第 2 根（产业）。
- 边的语义：题干"做好…大文章"兼有 why（为什么创新是关键）与 how（怎么继续做好）。分论点用"以 X 创新为 Y"句式把 how 放在标题，段内用 why + 广东证据。

**每段结构（影分身，深度 1）**
观点句（aᵢ ⇒ bᵢ ⇒ B）→ 理论句（习语或材料规范话）→ 广东证据（材料事实 2–4 个）→ 收束句（回到 B）。

**开头/结尾**
- 开头走柄：引语 → A 对 B 重要 → 广东地位（过去/如今）→ 继续做 A → B/C/D。
- 结尾反向走柄：四个创新同频共振 → 新质生产力 → 高质量发展 → 中国式现代化，以材料 1 的意象收尾。

### 答案（≈1060 字）

**以创新为笔　写好新质生产力的广东答卷**

创新是第一动力。习近平总书记指出，"新质生产力的显著特点是创新"，"必须继续做好创新这篇大文章，推动新质生产力加快发展"。改革开放以来，广东凭着"闯"的精神、"创"的劲头，从农业省份成长为世界工厂和智造基地，区域创新能力连续8年全国第一。面向新征程，广东作为改革开放的排头兵、领跑全国的经济大省和制造业大省，有基础、有责任抓住创新这个"牛鼻子"，继续做好创新这篇大文章——这是因地制宜发展新质生产力的必由之路，也是在中国式现代化建设中走在前列的使命担当。

以科技创新为核心，夯实新质生产力的技术根基。新质生产力主要由技术革命性突破催生，科技创新是其核心要素。广东以建设大湾区国际科创中心为牵引，构建"基础研究+技术攻关+成果转化+科技金融+人才支撑"全过程创新链：鹏城、广州两个国家实验室引领的多层次实验室体系日趋完善，10个大科学装置成为"大国重器"，"广东强芯"等重大工程持续推进，精密仪器、工业软件取得突破，一系列高端手术设备打破国外技术垄断。正是这些源头突破，让广东在战略必争领域并跑领跑，把创新的活水引向新质生产力。

以产业创新为载体，推动科技创新与产业创新深度融合。创新只有落在企业上、产业上，才能转化为现实生产力。广东坚持实体经济为本、制造业当家，让企业当创新主角：S市九成研发经费来自企业，"企业出题、高校揭榜"让需求由市场提出、成果由市场验证；坚持传统、新兴、未来产业并举，让"老树发新芽""新树扎深根""小树变大树"，全国每3台工业机器人就有1台"广东造"，新能源汽车产量占全国四分之一。科技与产业互促双强，正挺起现代化建设的"产业脊梁"。

以绿色创新为底色，提升新质生产力的"含绿量"。习近平总书记强调，"新质生产力本身就是绿色生产力"。广东以科技创新推动生产过程清洁化、能源消费低碳化、产业结构高端化：深圳龙岗能源生态园把垃圾焚烧厂变成"网红打卡地"，日发电300万度；阳江海上风电并网装机约占全国七分之一；湛江氢基竖炉每年减碳50万吨以上；惠州红树林碳汇交易超400万元。绿色生产力指数居全国第二，说明绿色不是发展的约束，而是新质生产力的竞争优势。

### 预登记的不确定点
- (a) **四根刷毛的切法**。机构范文可能切成"科技创新 / 产业创新 / 人才 / 体制机制"（把绿色折进产业），或直接按材料顺序五段。切法差异属结构参数，不是模型错误；但若多家都单独写"人才"，说明材料 2 的详略权重比我判的高，要回看"拆哪一边"的判据。
- (b) **开头是否应更多引用材料 2 的数据**（14 万亿、36 年第一等）。我只用了一个，把握：中。
- (c) **分论点句式**。机构可能用"×××是发展新质生产力的×××"的判断句式，而我用"以…为…，…"的动宾句式。属语言层，不修。
- (d) **结尾是否需要名言**。我用材料 1 的对句代替外部名言，把握：中高。
- (e) 每段证据密度（2–4 个材料事实）是否过高、挤占了论证句。这是我最没把握的一条：广东范文可能更重"说理"、轻"堆例"。若多家范文的证据密度明显低于我，修的是命题 6.3 中"证据"与"why"的字数配比。
