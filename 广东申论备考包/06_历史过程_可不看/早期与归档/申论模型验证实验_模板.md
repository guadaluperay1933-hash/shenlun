# 申论模型验证实验：流程与模板

## 隔离原则（必须遵守）

- **A 流（盲写）**：新对话。不贴报告，不提"结构""模型"等词。只给题干和材料。
- **B 流（结构化）**：新对话。先贴《申论三题型统一结构模型_评审稿》，再给题干和材料。
- **B2 流（稳定性）**：与 B 流相同的 prompt，再跑一次（可换一个实例）。
- **C 流（对比）**：新对话或任一对话追加。给 A、B 两份输出。
- **自测**：在看到任何模型输出之前完成。计时。

每道题一个对话。不要在同一对话里跑多道题。

---

## Prompt A：盲写

```
你是申论作答者。下面是一道真题的题干与材料，请直接作答，不要解释方法，不要引用任何培训机构的答案。

要求：
1. 严格遵守题干的作答要求与字数上限；
2. 作答后另起一节"要点清单"，每行一个要点：关键词 + 相对权重（高/中/低）+ 对应材料段落号；
3. 要点清单按你实际写入答案的顺序排列。

【题干】

【作答要求与字数】

【材料】
```

---

## Prompt B：结构化作答

```
附件是一份作答结构模型。请严格按该模型作答下面这道题，不参考任何机构答案。按以下顺序输出，每一步都必须显式写出，不得跳步：

1. 投影：题干中心语；元素的语义类型与句法形式（模型命题 3.1）；若为对策题，先按 5.5 锚定 B。
2. 第一遍：逐段列出元素——材料原词的动宾短语（或对应类型的最小完整单位）+ 段号。段用字母占位，此步不起名、不合并、不评价。
3. 第二遍（只对第一遍的骨架操作）：
   - 分组与层级：每个元素标注一级/二级/三级，给出所依据的判据（装得下所有兄弟 / 冒号连读 / 施动者-对象 / 删除测试）；
   - 合并决策：列出每一处考虑过合并的元素对，写明合并或不合并及理由；
   - 命名：每个父节点的名称及其来源（材料原词 / 词表选择 / 合成），若为合成，说明抽象层为何取这一高度；
   - 对策题另列：手段来源（材料明示 / a 反推 / 自补）与前置词来源（A 取反 / B 取反）。
4. 预算：估点数、每点字数；说明哪些三级元素被砍、哪些例证被保留及理由（3.12）。
5. 答案（严格遵守字数）。
6. 要点清单：每行一个要点：关键词 + 相对权重（高/中/低）+ 所在层级 + 段号。
7. 规则调用日志：逐条列出本题用到的模型命题编号；每条注明：顺利 / 犹豫（写明犹豫点）/ 冲突（与哪条冲突、你最终如何取舍）/ 不适用（为什么）。另列：材料中出现了模型未覆盖的情形吗？请具体描述。

【题干】

【作答要求与字数】

【材料】
```

大作文版本把第 2–4 步替换为：

```
2. 命题定位：A、B、目标链（柄）、星心（6.1、6.6）；说明题干动词决定的边语义（6.7）。
3. 刷毛：对材料以"A 的方面/做法"投影，列出一级节点 a_i 及其证据（6.8）；为每个 a_i 指定 b_i 及其在 B 官方分解中的来源（6.4）。
4. 段落规划：开头（走柄的路径）、每个分论点段的 what/why/证据/how、结尾；标注哪些 how 段为必需。
```

## Prompt C：对比与稳定性

```
下面是同一道题的两份作答（A：盲写；B：结构化）及各自的要点清单。请以"元素"为单位（不是句子）做对比：

1. 对齐两份清单，分为四类：B 有 A 无；A 有 B 无；同一元素、不同命名；同一元素、不同分组或层级。
2. 对每一处差异判断性质：覆盖的增减 / 同一内容的不同抽象层 / 合并粒度不同 / 单纯措辞差异。
3. 输出"高置信要点集"（两份都有）与"争议集"（只一份有），争议集逐条写明争议原因。
4. 若同时给出 B2（第二次结构化），另计 B 与 B2 要点清单的重合率，并列出不重合项。
5. 不给总分，只给相对权重。

【A 作答与要点清单】

【B 作答、骨架与要点清单】

【B2 要点清单（可选）】
```

## Prompt D：汇总（全部跑完后）

```
下面是 N 道题的"规则调用日志"汇总。请统计并输出：

1. 每条命题被调用的次数；
2. 每条命题出现"犹豫"的次数及典型情形（给题号）；
3. 每条命题出现"冲突"的次数、冲突对象及最终取舍是否一致；
4. 从未被调用的命题；
5. 日志中报告的"模型未覆盖的情形"，去重后列出；
6. 基于以上，给出修订建议：建议删除 / 合并 / 细化 / 补充优先级的命题各有哪些，每条附一个题目实例。

【日志】
```

## 题目配比建议（20 道）

| 类型 | 数量 | 说明 |
|---|---|---|
| 概括做法/经验 | 4 | 含至少一道"整体需自行拼合"的 |
| 概括问题 | 2 | 检验 5.4 的问题窗口 |
| 概括特点/其他属性类 | 2 | 检验投影在非动作类型上的表现 |
| 对策 | 4 | 含材料无明示对策、需从 a 反推的 |
| 大作文 | 4 | 广东近三年 + 一道国考概念型题作压力测试 |
| 综合分析 / 公文 | 3–4 | 检验模型向未专门覆盖题型的迁移 |

顺序：先跑 3 道试点（各类型至少一道），根据日志修 prompt，再跑其余。广东近七年优先。

---

## 自测规则

- 至少 5 道在看任何模型输出前完成，计时。
- 只记两样：不适感出现的环节、超时的环节。不在自测时改方法。
- 自测答案与高置信要点集对照，记漏点 / 错层 / 错名三类，与模型的争议集交叉看：自己漏的点如果也在争议集里，是题的问题；如果在高置信集里，是执行的问题。
