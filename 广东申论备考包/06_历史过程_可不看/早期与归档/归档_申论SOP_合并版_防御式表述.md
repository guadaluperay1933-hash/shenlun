# 申论做题 SOP（人话版 · 合并版）

> 用十四套广东真题（2020–2026，县级 / 乡镇 / 省市 / 县镇）盲做后对照校验：十二套对机构参考答案（2020 县级卷两家），两套对真人得分卷（2026 省市卷 84.5 分两份、77 分一份；2026 县镇卷 90 分三份）。文中括号里的年份是这条规矩的来源。
>
> 这份文件只回答一件事：拿到题以后，手先干什么、再干什么、脑子里想什么、什么时候停。词汇、训练方法、我和你的差别，在另一份《SOP 之外》里。
>
> 用法：考前背第 1 节和第 7 节；练题按第 2、3 节走，练完按第 5 节对答案；考场上出事翻第 7 节；第 8 节告诉你这份东西管什么、不管什么。
>
> 前提：广东申论 120 分钟；答题卡每行 25 格，标点也占格；拿到卷子先数格子（2026 卷：220 / 320 / 1220 或 1120）。

---

## 1. 五条铁律（背下来）

**一、字数只能数，不能估。**
限 200 字写 7 行（≈175），限 300 字写 11 行（≈275），800–1000 字写 36–38 行，1000 字左右写 40 行左右，都按格子的九成留。每写完一点看一眼行数，作文每写完一段数一次。头脑估算普遍偏少 15–30%——十四套定稿校对时六篇作文全超（2026 校对）。**一点一行半**，写到第二行一半就收。

**二、草稿只写骨架，不写句子。**
骨架 = 每点一个 4–8 字的标签 + 几个两三字的缩写。整句只在答题卡上写一遍。

**三、超了砍尾巴，不砍点。**
砍的顺序：数字和例子 → 最长那一点的最后一个分句 → 永远不删整个点。写少了，往最短的点里补一个材料原词。

**四、拿不准就往安全的一边倒。**
算不算一个点 → 写。该不该合 → 不合。例子留不留 → 压成词留着。多写一条浪费十几个字，漏一条丢两分。

**五、条数跟材料走，不跟预算走；可以更细，不能更粗。**
一级要点数 = 材料里互不重复的问题 / 做法数，通常 4–6，拆得更细也不吃亏（55 份真人卷：八问九策 90、九条理解题 90、六问六策 82–89，压成四问四策泛话的 80–84.5，压成三条的 81.5）。机构参考答案常压成三四条，跟着压过的两套定稿已改回。只有"同一件事说了两遍"才合（六个人里三个说的是同一个问题，合）；两件不同的事不能为省标签而合（2024 一卷："产业集聚低"和"硕博培养少"我合了，参考答案分开，错）。预算不够就把每条写短——类名 + 一个表现词——不减条数。

## 2. 小题通用流程（概括、对策都走这七步）

### 第 1 步　审题（30 秒–1 分钟）

**手**：在题干上圈四样——中心词（做法 / 问题 / 对策 / 作用 / 优势 / 成效 / 启示 / 特点）、主体和身份、字数和要求词（全面 / 准确 / 具体明确 / 针对性 / 观点鲜明 / 理解深刻）、引号里的每一个词。

**脑子**：
- 中心词决定找什么样的句子：做法 = "谁做了什么"；问题 = "什么不足、什么脱节"；作用 / 成效 = "对象得到了什么"；优势 / 特点 = "什么怎么样"。不是这种句子的，不是点。
- 主体决定谁的动作算数，身份决定对策的动词（科技局能推动、督促、搭建，不能替高校改评价；镇一级不能写"人工增雨"）。
- **题干引号里的每个词都要在答案里出现**（2023 县级："追求质量、打造品牌"，"提升产品质量"不能砍）。
- 字数换成行数写在题干旁。
- **先翻总述材料，看对象有没有官方分量**（乡村振兴 → 五个振兴 / 五个总要求；绿美广东 → 生态美产业强文化兴百姓富；政府管理与服务 → 管理、服务）。有，后面按分量分（2021 乡镇、2020 乡镇）。

### 第 2 步　扫段落（1 分钟，不读内容）

**手**：数段，看首尾句，段旁标掉三种不用读的：背景段、数据段、评论段。

**脑子**：估点数 = 正文段数上下浮动一个；每点行数 = 目标行数 ÷ 点数。看段落是按**内容**分的（一段一个做法，段落就是分组）还是按**人、地点、时间**分的（读完要重新归堆）。

### 第 3 步　第一遍读（占这题 40% 的时间）

**手**：
- 做法题圈"动词 + 名词"；问题题圈"名词 + 坏词"；作用 / 成效题圈"效果词"。
- 每段读完，段旁写一个字母加两三个字。
- 总结句、目的句（"为了……"）、需求句（"迫切需要……"）、人物后面的评论句（教授说、专家说）划波浪线标"名"——将来的标签住在这些句子里。

**脑子**：
- **只判类型，不判价值。** 是不是一个动作 / 坏状态 / 效果？是就圈。重不重要到分字数时再说。
- 类型不对的当场跳过：人名、数字、故事、情绪、背景。
- **不起名、不合并、不评价**，这三件事第二遍再做。
- 篇幅只管字数：一段写得长，念头只能是"这点多给几个字"，不能是"这点是大点"。
- **对话里的随口抱怨也是证据**（"果园信号不好"，2020 乡镇）；反面评论反过来也是效果（"没有信息化要耗费大量人力物力"，2021 县级）。

### 第 4 步　搭骨架（2 分钟）

草稿纸一行一个点：字母、标签位置空着、后面缩写。早填的名字会粘住，先空着。

### 第 5 步　第二遍，在骨架上做（3 分钟，不回材料）

**① 归堆。** 钥匙按这个顺序找：对象有官方分量 → 按分量分；没有，段落按内容分 → 一段一堆；段落按人 / 地点分 → 按"谁做的 × 哪一环"归。条数跟材料走（铁律五）。
"塞进去"和"合并"是两回事：塞进去是两件事都写、共用一个标签，不丢词（一站式平台并进职业资格互认，2022 县级）；合并是把两件事写成一件，会丢词。同一制度域的可以塞，不同主体、不同类别的不合。

**② 定父子。** 能装下所有兄弟的才是父。装不下的就是兄弟，哪怕它那段写了一整页（2025 省市：银行那段不是投入体系的儿子）。

**③ 合并。** 只合"一件事说了两遍"的（企业发榜 / 高校揭榜）。主体不同、能被一个大词罩住、拿不准，都不合。

**④ 起名。** 抄材料 > 从材料的目的句需求句评论句里选 > 五个动词加名词 > 自己造。标签 4–8 字，动词 + 名词；材料给的长名放标签后第一句。标签词性要和内容一致（内容是动作，标签就是动作）。材料用"最、核心、宝贵、关键"强调的元素单列一条（2022 县级：孙中山）。

**⑤ 分字数。** 每点一行半；例子和数据是三层，行数不够先砍它们。

### 第 6 步　写（占这题 40% 的时间）

**手**：序号 + 标签 + 句号 + 几个短句。问题和对策各一段，段内不分行。每写完一点看一眼行数。

**脑子**：
- 不写总括句，**除非材料自己有结构性的总结句**（"以文兴村，农文旅一体化，游养买一条龙"，2023 乡镇），感叹句不算（"整个镇年轻了"，2022 乡镇）。
- **小题不搞二级结构**，几个方面就平铺几条（2026 省市 77 分卷的"理念绿"套四项）。
- **主语精确**：农户响应县里做的事写成县里的动作（"平台预警指导荔农浇灌"，2025 县镇）；主语和平台名用材料原词（"供应链平台"不是"联盟"）。
- **总结句和例名都要**：总结句是清单最可能用的措辞，例名是低频词保险，形式"总结句 + 例名、例名"。
- **排比整抄**：三个并列四字短语整体抄；"××就是生命"引出的动作是必踩点（2024 一卷）。
- 效果尾巴可以带一个（"延长食用期"）。
- 数字：做法、问题题砍数字；成效题留结果词、每条至多一个数字；优势题里的条件数字（5000 万、3 公里）留。

### 第 7 步　检查（1 分钟）

每点有动词 / 坏词？标签 8 字内？有没有哪个点其实是另一个点的儿子？材料低频词在不在？**行数数过了吗**（不是估）？"最 / 首位 / 入选 / 全覆盖"这类判断词每个能指回材料原句吗？

## 3. 分题型（只写和通用流程不一样的地方）

### 概括做法 / 举措 / 经验
找"谁做了什么"，主语必须是题目指定的主体。目的句、效果句不当点，可以当标签的名字来源，或跟在动作后当尾巴。

### 概括问题
写"名词 + 坏词"。总括性的问题写出来，小毛病跟在后面。**别从建议反推问题**：有人说"要搭平台"不等于材料说了"缺平台"。从规划反推的（"正在筹备协会" → 缺协会）把握中等，放尾巴。副作用不写。

### 问题 + 对策
- 先按上面找问题。对策的名字 = 问题的名字反过来（脱节 → 对接，不足 → 强化，滞后 → 推动落地）。
- **两侧分工**：问题侧写"表现词"（类名 + 一两个表现词，不写句子；"缺乏人才""资金匮乏"四个字一条的卷子 80–81.5，写"缺运营管理和复合型人才""补贴远远不够"的 84.5），对策侧写"手段"。两侧只共用类名，类名各出现一次是给阅卷人对针对性用的。出现"X 不畅 / 完善 X"这种镜像，说明对策缺手段——给真手段（修建机耕道），或降级只留问题侧。
- **手段从哪来**：材料明说的办法（包括同一套卷子里别的材料的正面做法：材料 8 的社会资本、材料 6 的集体经济）> 从"以前怎么做错的"反推 > 从"没人愿意 / 还在摸索 / 不知道怎么办"反推成激励或培训 > 自补标准手段。自补每堆至多一条，只在材料办法用完后，永远不替代材料办法。
- **"具体明确"= 写到工具**：无人机巡山、古树数字档案、先抢救后补手续、发传单办讲座、专项资金、绿色通道、以老带新（2026 县镇 90 分卷）。"运用科技手段""加强宣传"是动词级，拿不到这个分。反推时多问一句"用什么工具做"。
- **一一对应**：问题几条对策几条，一是对一是（2026 省市：问题相同的两份卷，六问六策的 84.5，六问九策自补泛话的 77）。对策可以比问题多，前提是每条对回某个问题、都是材料来的具体工具。
- **"针对性"= 一类风险一条**：材料里每一户、每一个案例都要有对应（2020 乡镇参考答案整户漏了因残致贫的老刘家）。
- 主语做不了的事不写（镇写"人工增雨"，2021 乡镇）。对策不张冠李戴：材料里 A 园区做的是风光储，就不能写成"推广 A 园区绿电直连经验"（2026 一卷 80 分卷）。

### 作用 / 意义 / 重要性题
- 每条 = 标签 + 动作串 + **效果词**。分组钥匙看对象：有官方分量按分量（"改善基层治理"这种领域词，2023 乡镇）；没有、材料按主体排的，按主体（"青年企业家引领发展"，2023 县级）。
- **例子不砍，砍人名和数字；效果词是采分点，一个不能丢**。效果词三个来源：例子后面的结果（"远销 80 国" → 拓宽市场）、群众的反应（"讲给孙子听" → 自发传播，2022 乡镇）、反面评论反过来（2021 县级）。
- 人物后面的评论句是这条的父名。同一主体层可合（企业家和职业经理人）。
- 题干要"观点鲜明"才写一句总观点，14 字内；只要求"概括"不写。

### 优势 / 有利条件 / 特点题
- 元素是"名词 + 判断"，标签越短越像特点（任务急 / 任务重 / 挑战多 / 责任大 / 风险高，2020 乡镇）。
- 做过的事不是优势，但能证明"已有基础"——事实留，动作词不当标签。材料自己的总述句是第一条。当事人总结的"最难的几点"是特点的直接来源；当事人的个人经历不算。
- 每条 = 标签 + 事实 + 半句意义。跨篇的条件是保险，压成最后一条写短（2021 乡镇）。

### 成效 / 效果题
标签"名词 + 变好的动词"（复苏、回稳、减轻、提速）。结果词是主力（转正、第一、量质齐升），数字每条至多一个。做法当主语、结果当谓语（"减免社保惠及 29 万家"）。"市场主体增长"并进经济复苏；同一材料里两件事各一条（2020 县级两家答案一致）。

### 理解题（"密码 / 秘诀 / 关键"）
先一句解比喻（"密码"是 G 市加强科技创新的一系列做法），再分条，分条同做法题。讲做法的段落每段一条，写成效的段落（无人工厂）也算一条（2021 县级）。

### 启示题
- 每条 = 标签 + **认识句（抄原话）** + 做法句。"理解深刻"靠抄原话最省力。
- 会议对话：每个发言人的话题一条；别人被指出的错反过来是做法；**直接对"我"说的那句必须是一条**（"提高思想觉悟"，2023 乡镇）；每个难题多问一句"它为什么会出现"，动作层一条、深一层再一条（挖掘机难请 → 预见性，2022 乡镇）。
- 多人物：一人一条，品质当标签，做法收全，末尾一句深一层（2021 乡镇）。
- 不写"我"没权限的事。

### 发言提纲 / 汇报
标题 → 开头一句总述 → 主体分条 → 结尾一句（用材料里领导的总结句）。条目不是稿子：标签 + 一句做法 + 半句例证。材料按村走的就按村写（2023 乡镇提纲 84.5；2024 二卷"草拟汇报"按镇写问题+建议的那份是同套最高分 88）；按主题走的按主题写。

### 大作文（议论文 / 策论文）
- **审题**：A = 要拆的，B = 每段落到的。标题必须含 A，落点可以是题干的近目标也可以是上层目标（2025 省市卷最高的两份标题都落在"高质量发展"而非"新质生产力"）；近目标至少在开头和一句观点句里出现；题干给了口号句的把口号带上（2021 县级参考答案丢了"新起点新征程"）。
- **拆哪边**：材料在拆哪边，你就拆哪边。材料给 A 的做法 → 按 A 拆（2025 省市）；材料给 B 需要什么 → 按 B 拆（2025 县镇）。按 B 拆时官方分解每个分量的词都要出现；按 A 拆时题干引语里 A 的每个分量都要有一段或一句（2024 一卷参考答案漏了企业转化）。
- **题干两个落点的（"关系 A 和 B"）**：分论点要么就是两个落点各一大段，要么四段但每句观点句点明属于哪个落点；开头末句、结尾各点一遍（2026 县镇 90 分卷）。
- **分论点和材料对位**：每层用讲那一层的材料（镇 → 讲镇的那份，2024 二卷）。问题类材料取反写成"要……"放进对应段（2024 二卷、2026 省市）。
- **观点句优先用材料各面开头的判断句**（"生态环境是根基""绿色发展作为生产方式的变革已成为新增长点"），自己的对仗句保留时这几句当道理句（2026 省市两份 84.5 分卷）。
- **每段**：观点句 → 道理句（怎么导致的）→ 三个名词化证据、至多一个数字 → 收束回 B。开头 6 行（有靶子、有分论点预告——2023 县级 86.5、2024 二卷 88 都这么开）、每段 7–8 行、结尾 4 行。每份材料至少露一次脸（材料没用完的 78.5，2023 县级）。
- **例子的量到即止，材料外的例子不能替代材料**：例子少但主题句全用材料的 90（2021 县级），例子堆最多的 83（2024 二卷）没有更高；四段全用材料外例子的 81.5（2025 县镇）、牛顿爱因斯坦当论据的 82（2024 一卷）。结尾用材料里的原句或意象，不自己编对联。
- **策论文**：动词一律"要"；开头抄材料里的短板句当靶子；每段三个"要"，每个"要"带材料专有名。**题干含"经验"**：观点句写成规律句，收束"经验是：……"，实效仍做证据（2022 县级参考答案为写规律丢了全部论据）。
- **写完两遍核**：案例的地名、人名、做法对得上（2024 二卷参考答案把番薯节安到南紫村头上）；"最 / 首位 / 入选"每个指回原句，不加码（2026 校对）。**每段数一次格子。**

### 原因 / 影响 / 应用文（简）
原因往上游找，影响往下游找。应用文 = 同一套找点 + 格式框。

## 4. 起名手册

- **来源顺序**：材料总结句 / 目的句 / 需求句 / 评论句 → 抄；没有：五个动词（增强、健全、优化、构建、推动）+ 段里反复出现的名词（服务、平台、机制、体系）；问题题：名词 + 不足 / 缺乏 / 脱节 / 滞后 / 短板；对策题：问题的名字反过来。
- 标签 4–8 字。内容是动作，标签是动作；内容是特点，标签是特点。检查法：标签和内容用冒号连起来读，内容应读成"标签的一个例子"。
- 完整词表在《SOP 之外》第 4 节，考前背。

## 5. 练习时怎么对答案

- **写答案之前先预登记**：哪个点不确定算不算、哪个名字是自己造的、哪两个点不确定该不该合，各标一个把握（高 / 中 / 低）。
- **对照分四类**：漏点多点（看第 3 步的圈法）；层级错（看"装得下"）；名字不同（不改规则，攒样本）；例子取舍不同（两家一致才改）。
- **改规则的门槛**：能说清机制，写一句对下一题的预测；预测两次落空就撤回。
- **参考答案按 85 分对待**，先推它扣在哪：材料低频词漏了几个；材料点了名的类别合掉没；自补挤掉材料办法没；作文标题和观点句落在题干目标上没；每份材料露脸没；字数够没；案例串没。
- **它的固定风格**（十二套总结）：学它的——标签 4–6 字、效果尾巴、一一对应、各说各的一人一条；不学它的——标签泛化、只抄总结句不写例名、问题侧没表现词、对策自补泛话、作文证据薄材料用不全字数常不够。
- **两家答案**：一致处才改，不一致处按 SOP 自己的判断（2020 县级）。**真分数卷**：比机构答案值钱，同题不同分的差别就是规则的证据。55 份卷校准过的几条：背机构答案逐字写的得 80–83.5（2024 两套）；同题同结构的卷子之间常见 ±2 的浮动，两分以内不下结论，三份以上同向才改规则；第一题几乎不区分，分差出在第二题的条数和对策、作文的落点和材料使用。

## 6. 考场时间表（120 分钟）

三题卷：0–3 分钟读题干、每份材料顶上写一个词；问题一 20；问题二 30；大作文 55（审题定分论点 7，开头 5，每段 8，结尾 3，检查 3）；机动 12。
五题卷：按分值定行数定时间——15 分题 15 分钟，20 分题 22 分钟，30 分题 35 分钟；一题一材料不跨材料找点。

## 7. 出事了怎么办

- 写超了：小题砍最长那条的最后一个分句，作文砍最后一个证据；一条横线划掉，别涂整行。
- 想不出名字：看段首段尾有没有总结句，抄；没有就五个动词加反复出现的名词；三十秒想不出，先写"一、"空四格写内容，最后回来填。
- 材料读不完：大作文只要每份材料的第一段、最后一段和顶上那个词，中间段是证据仓库，写到哪段翻哪段。
- 不确定算不算一个点：写。不确定该不该合：不合。不确定主体是谁：分开写。
- 作文时间不够：先写结尾，三行。没结尾会被当成结构不完整。
- 发现前面写错了一个点：不涂，在后面把正确的关键词带上。

## 8. 这份 SOP 能解决什么、不能解决什么

**能解决的（十四套真题、八份真人卷验证过）：**
1. 找全采分点：什么算一个点、怎么归堆、条数怎么定、标签从哪抄。十四套里问题梳理这一侧和高分卷几乎全部一致。
2. 不丢词：材料点了名的类别词、低频专有词、排比、效果词、题干引号词，每一类都有一条规矩管。
3. 结构判断：对策和问题的分工、作文拆哪边、多落点怎么写、材料怎么对位。两套 2026 真题的结构判断全部成立。
4. 对策的来源和形状：从材料来、写到工具、一一对应。真分数证明了它换分。
5. 字数和格子：按行数写、按格子数、超了砍什么。
6. 练习方法：预登记、四类分差异、参考答案怎么用、真分数怎么用。

**不能解决的（要靠别的东西）：**
1. **词汇储备。** 标签词、官方分量、效果词、对策工具，SOP 只给了来源规则，词本身在《SOP 之外》第 4 节，要背。
2. **速度。** 圈词、归堆、起名的速度只能限时练出来，SOP 定不了。
3. **一眼看全材料的能力。** 我一次装下八份材料，你装不下；"材料顶上写一个词""两遍读法"是给人的拐杖，拐杖不等于腿。
4. **阅卷的真实标准。** 采分点清单没人见过，这里的一切都是从参考答案和真分数反推的，是推测不是事实；真分数样本目前只有 2026 两套八份卷。
5. **作文的"深一层"。** 解比喻、找机制句、把做法说成规律，SOP 给了位置和例子，能不能写出来靠理解力和阅读积累。
6. **时政和政策积累。** 联系实际那一句、开头的引语，来自材料之外的时候，SOP 帮不上。
7. **考场上的手写、卷面、心理、体力。** 一个字没管。
8. **没见过的题型。** 目前覆盖：概括做法 / 问题 / 问题对策 / 作用 / 优势特点 / 成效 / 理解 / 启示 / 提纲 / 议论文 / 策论文。原因、影响、应用文只有一句话，没练过。
9. **我的示范不等于你的执行。** 那些"思路和动作"文件是我按 SOP 写给人看的示范，不是我的执行日志；SOP 能不能被人落地，只有你自己掐时间盲做一套、和高分卷对过之后才算数。
