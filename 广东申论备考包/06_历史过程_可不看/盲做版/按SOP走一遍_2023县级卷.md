## 2. 问题二　分析说明青年人才对推动制造业高质量发展的重要作用（30 分，≤300 字）

### 第 1 步　审题（1 分钟）
**手**：圈"材料 7""分析说明""青年人才""重要作用""观点鲜明正确""分析全面透彻""300 字"。
**脑子**：
- 中心词是"作用"——找的不是做法、不是问题，是"青年人才让制造业得到了什么"。每个点的形状是：**哪类青年 + 做了什么 + 制造业因此怎么样**。
- "观点鲜明正确"意味着开头要有一句总的观点句，不能直接一是二是。
- "分析全面透彻"：材料 7 写了几类青年，就要有几个作用；"透彻"是每条要说到效果，不能停在"做了什么"。
- 材料里的例子（高先生、方先生、刘工、小郑、小黎、吴博士、王律师）是证据，压成半句带一下，不展开。
- 11 行：观点句 1 行，五条各两行。

### 第 2 步　扫段（1 分钟）
**手**：数段。开头两段是习语和总述（青年是源头活水、挑大梁当主角；青年队伍有理想敢担当能吃苦肯奋斗）。后面按人走：高先生、周教授评、方先生、刘工、小郑、技能人才数据、研究生小黎、吴博士、研发人才数据、王律师、专家评。

## 4. 这套新出现的题型，走出来的做法（待参考答案验证后进 SOP）

**作用 / 意义 / 重要性题**
- 找的是"主体让对象得到了什么"，每条的形状：作用标签（动词 + 名词）+ 哪类主体 + 做了什么 + 对象因此怎么样。
- 材料按人物走的，人物后面那句评论（教授说、专家说、当事人总结）是这条作用的父名，比例子值钱。
- 开头一句总观点，用材料原词拼；例子只留身份不留人名；数字只留"全国首位"这种结论。
- 条数 = 材料里的主体类型数。

**策论文**
- 分论点全是对策，动词一律"要"。
- 开头必须有靶子：材料里的短板/问题句抄进去。
- 每段：对策观点句 → 一句道理 → 三个"要"，每个"要"带一两个材料里的具体做法名 → 收束。
- 对策从材料的正面做法里来（"要推广……"），不自己编。
