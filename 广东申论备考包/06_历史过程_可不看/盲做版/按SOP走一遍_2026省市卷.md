## 1. 问题一　谈谈"绿色工厂"的"绿"体现在哪些方面（20 分，≤200 字）

### 第 1 步　审题（30 秒）
**手**：圈"材料 3""绿色工厂""绿""体现在哪些方面""概括全面、准确""条理清晰""200 字"。
**脑子**：这是"体现在哪些方面"的表现题，和 2022 乡镇卷"小林村的美体现在哪些方面"同型：元素是"某个方面 + 怎么绿"，标签是方面名。对象是一家工厂的"绿"，材料自己按环节写：种树、能源、产品、办公、供应链。主语是 H 电子。7 行半。

### 第 2 步　扫段（1 分钟）
**手**：数段。开头两段是画面描写（植物园、绿意赛博朋克）→ 陈董事长"多种树"→ 5000 株树、垂直绿墙 → 曾女士"凉快"、县里支持示范点 → 首批碳达峰碳中和试点企业，理念融入基因 → 叶总经理"生态是生产的好伙伴"，屋顶光伏 → 李工程师第三代产品纳米涂层、减重 2 克 → 办公管理细微处：无一次性用品、无纸化 → 供应链：供应商环保数据、回收利用 → 2024 订单产值 → 结语"含绿量越高含金量越足"。
**脑子**：材料自己的过渡句把方面分好了："不是简单种树"（环境→能源）、"还体现在办公管理的细微处"、"延伸至原材料领域"。五个方面：厂区生态、能源、产品技术、办公管理、供应链。"首批碳达峰碳中和试点、理念融入基因"是总括，可当总句；订单产值是效益，不是"绿"，最多当尾巴。

### 第 3 步　第一遍读（6 分钟）

|---|---|---|---|

**脑子**（读的时候的念头）：
- 五个方面材料自己分好了，一个不多一个不少。
- 数字：5000 株、91 万千瓦时、2 克、20%、11 亿——表现题砍数字，留一个"5000 多株"当具体度就够。
- "首批碳达峰碳中和试点、理念融入基因"是总括句，抄成总句。
- "含绿量越高含金量越足"是结语的判断，是"绿"带来的结果，不是"绿"本身，不占条目，行数够时当最后半句。

### 第 4 步　骨架

```
总句：绿色低碳理念融入企业基因（首批碳达峰碳中和试点）
① 厂区生态绿   5000株乡土阔叶树 / 灌木花草 / 垂直绿墙 / 吸碳 / 降温美化

③ 产品设计绿   纳米涂层替代喷胶 / 可拆解维修 / 配件循环利用 / 减重减碳
④ 办公管理绿   无一次性用品 / 无纸化
⑤ 供应链绿    供应商环保数据 / 原材料绿色低碳 / 回收包材线圈 / 降本增效
```

### 第 5 步　第二遍（3 分钟）
- **归堆**：五堆，跟材料的过渡句走。
- **父子**：五个方面并列，理念是总句。
- **合并**：不合。产品和供应链都涉及"循环利用"，但一个是自家产品一个是上游物料，环节不同。
- **起名**：题干的字是"绿"，标签就用"××绿"，五个同型，四到六字。
- **分字数**：总句一行，五条各一行多，①③内容最多给一行半。

### 第 6 步　写（6 分钟）
**念头**：数字只留"5000 多株"；③把"替代喷胶"带上，它说明为什么绿（不用喷胶就能拆）；⑤"降本增效"是材料原话，四个字带上；超行先砍总句里的括号，再砍①的"美化"。

### 产出（约 186 字，7 行半）

绿色低碳理念融入企业基因。一是厂区生态绿。种植5000多株乡土阔叶树和灌木花草，建垂直绿墙，吸收二氧化碳、降温美化。二是能源清洁绿。屋顶铺设光伏板，绿电满足自用并输送电网，减少碳排放。三是产品设计绿。研发纳米涂层替代喷胶，耳机可拆解维修、配件循环利用，减重减碳。四是办公管理绿。不用一次性用品，全流程无纸化办公。五是供应链绿。要求供应商提供物料环保数据，鼓励回收利用包材线圈，节能降本。

### 第 7 步　检查
总句是材料原话 ✓；五条标签同型、方面和材料过渡句一一对应 ✓；每条有具体表现 ✓；数字只留一个 ✓；效益不占条目 ✓；7 行半 ✓。

### 预登记
- (a) **五条还是六条**：参考答案可能把"理念/试点企业"单独成一条，或把"效益（含绿量含金量）"当一条"绿色效益"。把握：中。
- (b) **总句**：参考答案可能不写总句，或用"含绿量高含金量足"收尾。把握：中。
- (c) **标签形式**："××绿"还是"厂区绿化 / 能源清洁 / 产品环保……"。命名差异，不修。
- (d) **产品那条**参考答案可能拆成"技术研发绿"和"产品循环利用"两条。把握：中低。
- (e) 数字：参考答案可能一个不留。不修。

## 2. 问题二　S 市发改局工作人员：梳理零碳园区建设遇到的问题，提出对策建议（30 分，≤300 字）

### 第 1 步　审题（1 分钟）
**手**：圈"发展和改革局工作人员""材料 5""梳理问题""对策建议""全面准确""合理、有针对性、具体明确""紧扣材料""300 字"。
**脑子**：
- 问题 + 对策，两段，用"问题：""对策："做小标题。
- 身份是市发改局——对策是市一级能做的：制定标准、细化政策、协调电网、补贴、培育服务商、对接高校。
- 问题侧写"表现词"，对策侧写"手段"，两侧只共用类名，出现镜像就是对策缺手段。
- 12 行（格子到 320）：问题 5 行，对策 6 行半。

### 第 2 步　扫结构（1 分钟）
**手**：材料 5 按园区走：定义两段 → 国家通知 → S 市总述（落地见效但有问题）→ A 园区（风光储 80% 绿电、碳智慧平台；人才缺）→ 李教授（复合型人才紧缺；重建设轻运营、评价考核没跟上、企业变动要持续跟踪）→ B 园区（绿电直连 + 光伏；买电连网没办法；协同周边、交易对接配套设施是市里要解决的；光伏储能资金大、补贴远远不够、不少园区都这样）→ C 园区（传统制造亟需转型；供能方案设计论证难；本地专业公司少、不能全流程服务；李教授：全链条方案、综合能源服务商、分步骤专业指导）→ 退出园区（以为装几块光伏板就行，未考虑产业特点周边设施，半路退出；李教授：科学规划稳妥推进、政策细化明确、摸清家底探索模式）。
**脑子**：段落按园区分，问题按类型归：人才、运营考核、绿电直连、资金、专业服务、认识规划与政策。六个，材料都点了名。A 园区的"风光储一体化 + 碳智慧管理平台"是正面做法，对策里可以"推广"。

### 第 3 步　第一遍读（按园区记 × 和 √）

```
A园区  √风光储一体化，80%绿电自供；√碳智慧管理平台（核算、减排分析、交易、能源管理）   → 正面做法，对策可推广
      ×人才缺乏，尤其零碳园区运营管理专业人才；李教授：×能源管理、数字技术、信息工程复合型技术人才紧缺  → ①人才
李教授  ×有些园区前期大搞建设、后期无实质运营，不一定达零碳；×评价考核没有跟上；×企业数量门类变化后是否仍符合标准需政府持续跟踪  → ②运营与考核
B园区  √绿电直连+光伏双驱动方案；×附近光伏厂直接买电"怎么买怎么连"没办法；李教授：×绿电市场交易如何对接、配套设施如何完善是市里必须解决的；√协同周边绿色能源互济、设施共享  → ③绿电直连
      ×光伏板+配套电网+储电系统投入一大笔资金；×市里补贴远远不够；×不少园区面临，影响推进            → ④资金
C园区  ×传统制造业亟需转型；×综合供能方案设计论证难；×本地专业服务公司少、不能全流程服务；李教授：√"规划—设计—建设—运营—碳服务"全链条方案、催生综合能源服务商、专业指导分步骤推进  → ⑤专业服务
退出   ×以为装几块光伏板就行；×未考虑产业特点、周边基础设施；×半路退出；李教授：√科学规划稳妥推进、√政策细化明确、√摸清家底探索模式  → ⑥认识规划政策
```

**脑子**（读的时候的念头）：
- 六个问题材料都点了名，六条，不合。
- 李教授的话一半是问题一半是对策，√ 的那些直接进对策：全链条方案、综合能源服务商、科学规划稳妥推进、政策细化、摸清家底、协同周边能源互济。
- 问题侧不写"缺标准"（那是从"考核没跟上"反过来的对策），写"评价考核没跟上、持续跟踪不足"。
- 对策手段来源：材料明说（√）> 反推（人才→培养引进；资金→加大补贴）> 自补（社会资本，至多一条）。

### 第 4 步　骨架

```
问题                              对策
① 人才紧缺 ←运营管理/能源数字信息复合型      联合高校院所培养引进（反推）
② 重建设轻运营 ←无实质运营/考核没跟上/企业变动    制定评价标准、建成后持续跟踪动态评估（反推）
③ 绿电直连不畅 ←怎么买怎么连/交易对接/配套设施    明确交易规则对接流程、完善配套电网、协同周边能源互济（材料√）
④ 资金投入大补贴不足 ←光伏储能电网/补贴远不够     加大补贴、引入社会资本（一处自补）、推广风光储一体化（A园区√）
⑤ 专业服务缺 ←供能方案难/本地机构少/非全流程     培育引进综合能源服务商、全链条方案、专家指导（材料√）
⑥ 认识片面规划不科学政策不细 ←装几块光伏/未考虑产业特点/退出  细化政策、指导摸清家底科学规划分步推进（材料√）
```

### 第 5 步　第二遍（3 分钟）
- **条数**：六条问题、六条对策，一一对应。
- **分工检查**：问题侧全是表现词（怎么买怎么连、补贴远远不够、装几块光伏板、半路退出），对策侧全是手段。镜像检查：④"补贴不足 / 加大补贴"是镜像——对策侧要有真手段：加大补贴之外，加"引入社会资本""推广风光储一体化降低用能成本"。
- **主语**：对策全是市发改局能做的（制定、细化、协调、培育、联合）。
- **分字数**：问题六条各一行不到，对策六条各一行多。

### 第 6 步　写（12 分钟）
**念头**：
- 问题①把"复合型"写上，②把"评价考核没跟上"和"持续跟踪"都写，③"怎么买怎么连"压成"交易对接、配套设施不完善"，⑥"半路退出"是最具体的表现，留。
- 对策⑤"规划—设计—建设—运营—碳服务"全链条是材料专有说法，留；⑥"摸清家底"是李教授原话，留。
- 超行先砍对策④的"引入社会资本"，再砍对策①的"引进"。
