## 2. 问题二　谈谈榕泉村是如何利用自身文化资源吸引游客的（15 分，≤200 字）

### 第 1 步　审题
**手**：圈"材料 2""如何利用""文化资源""吸引游客""分析全面""200 字"。
**脑子**："如何利用"是做法题，主语是榕泉村；限定词"文化资源"——民族风情、古村风貌、农耕文化、饮食、民族医药、非遗手工，都是文化资源；"吸引游客"是目的，做法要落到游客身上。7 行。

### 第 2 步　扫段
**手**：材料 2 按参观顺序走：游览线路→古村修缮→体验基地→稻田鱼→美食→康养区（针对"夜晚冷清"）→文创专卖和直播→阳书记总结"游养买一条龙""引得来玩得嗨留下来买买买"。

## 3. 问题三　在全镇推广大围村积分制经验，临溪镇应重点把握哪些方面（20 分，≤300 字）

### 第 1 步　审题
**手**：圈"材料 3""全镇推广""大围村经验""临溪镇""重点把握哪些方面""考虑全面""300 字"。
**脑子**："推广经验要把握的方面" = 从大围村的做法里抽出**关键环节**，再加上材料里踩过的坑（一开始不重视效果差、村民不信）。主语变成镇，动词是镇能做的：加强指导、统一规范、统筹资金。11 行。

### 第 2 步　扫段
**手**：材料 3 按对话走：奖品和公开栏 → 村民阿姨（起初不信→参加活动兑奖→都参与）→ 朱书记（以前不重视效果差→学外地→民主定标）→ 赵副书记（组织方先明白意义）→ 程序规范、监督、公开 → 资金来源 → 奖励方式（更丰富奖品、文明先锋流动红旗、征求意见、超市消费券）→ 杨组长（有效奖励机制，值得推广）。
**脑子**：对话里每个人说的就是一个环节，按环节归：认识 / 定标 / 程序 / 资金 / 奖励 / 参与。六条。

### 第 3 步　第一遍读

```
奖品公开栏  奖品实用（杯子牙刷雨伞）；公开栏：经费来源、奖品价格、村民得分、兑换情况一目了然     → 公开
阿姨      起初不信怕换不到；党员带着参加防诈宣传、交通劝导、治安巡逻拿积分兑奖；慢慢都参与；争着做好事  → 参与/取信
朱书记    以前没认识到意义、不重视、效果不好；去了解外地做法才明白好处                        → 认识（坑）
赵副书记   积分制引导村民参与治理、促进和谐稳定；组织方得先明白为什么                           → 认识
朱书记    召开党员大会、村民代表大会，各抒己见，制定更符合实际的赋分内容和评分标准；可操作性强；参与多、乡风文明  → 定标
杨组长问   随意兑换？钱哪来？
朱书记    村两委评分小组负责评分兑换；党员代表村民代表监督小组核实公示；申报审核评定统计全过程公开；每月公布明细（公开栏+群）  → 程序
朱书记    资金来自村集体收入和乡贤捐赠；正寻找其他渠道                                    → 资金
朱书记    更丰富奖品；季度评"文明先锋"颁流动红旗；征求村民意见其他奖励方式；跟超市谈消费券            → 奖励
杨组长    有效奖励机制；国家省市倡导；值得推广
```

**脑子**：朱书记那句"以前不重视效果不好"是反面经验，推广时最该把握——第一条就是它。阿姨那段是"信任怎么建立起来"的过程，写成"党员带头、以实兑奖取信于民"。

### 第 4 步　骨架

```
① 提高认识    组织方先明白意义/学习外地经验/镇加强培训指导
② 民主定标    党员大会村民代表大会/结合各村实际/赋分内容评分标准/可操作
③ 规范程序    评分小组/监督小组/申报审核评定公开/每月公示
④ 保障资金    集体收入/乡贤捐赠/拓宽渠道/长期运行
⑤ 丰富奖励    实用奖品/文明先锋流动红旗/超市消费券/征求意见
⑥ 引导参与    党员带头/防诈宣传治安巡逻等活动兑奖取信于民/逐步扩大
```

### 第 5 步　第二遍
- **条数**：六个环节六条，不合。
- **主语**：镇推广，所以①写"镇里加强培训指导"，②写"各村……结合实际"，其余是各村要做的、镇要盯的。
- **分字数**：六条各一行半，③程序那条内容最多给两行。

### 第 6 步　写

## 6. 这套新出现的题型，走出来的做法（待验证后进 SOP）

**启示题**（"此次会议/这件事对你有什么启示"）
- 每条 = 标签 + **认识句（抄材料里的原话或道理）** + 做法句。"认识深刻"靠抄原话最省力。
- 材料是会议对话的，每个发言人的话题就是一条；发言人指出的别人的错（出动慢、预案疏漏）反过来就是启示。
- 身份是当事人时，做法句可以带"要"，不必每句"我"。

**发言提纲**
- 格式：标题（关于……的发言提纲）→ 一、总体思路（材料里领导的总结句）→ 二、主要做法（一）（二）……→ 三、下一步（一句）。
- 提纲是条目不是稿子：每条标签 + 一句做法 + 半句例证，不寒暄，不展开。
- 材料按村/单位走的，做法按类型归，村名当例证。

**五题小题卷的节奏**：分值定行数定时间，30 分的那题留 35 分钟；一题一材料时不跨材料找点。
