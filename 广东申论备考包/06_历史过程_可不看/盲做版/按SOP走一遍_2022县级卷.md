## 1. 问题一　简述广东在促进大湾区"软联通"方面的主要做法（20 分，≤200 字）

## 2. 问题二　分析说明粤港澳三地推进文化交流合作、共建人文湾区的优势（30 分，≤300 字）

### 第 1 步　审题（1 分钟）
**手**：圈"材料 4""三地""文化交流合作""共建人文湾区""优势""分析透彻全面""300 字"。
**脑子**：中心词"优势"——找的是**有利条件**，形状是"名词 + 判断"（文化同源、地理相近、遗产丰富、产业雄厚），不是做法。材料里广东做的事（首倡游径、办戏曲节）是做法不是优势，但可以当"已有合作基础"这种优势的证据。"分析透彻"：每条要说清为什么它是优势（它让合作更容易做什么）。11 行。

### 第 2 步　扫段（1 分钟）
**手**：数段。总述（文化同源血脉相通是基础）→ 图片展"五同"→ 专家（百越、岭南文化珠江文化主流、语言文化根基）→ 地域相近山水相连 → 遗产游径（五地遗产可串联）→ 孙中山足迹 → 粤剧联合申遗、戏曲节、銮舆堂、盘伯每周来 → 醒狮、舞剧 → 文博合作（外销画、办展）→ 文化产业数据、文交会、上市公司 → 结语。
**脑子**：按"优势"的类型归：同源（历史文化）、地理、遗产、非遗民俗、机构合作、产业。六条。第一段"文化同源、血脉相通，是共建人文湾区的重要基础"是材料自己给的第一条名字。

### 第 3 步　第一遍读（重点圈"名词 + 判断"）

```

## 3. 大作文　围绕"粤港澳大湾区建设取得的实效和经验"（50 分，800–1000 字）

### 第 1 步　审题（2 分钟）
**手**：圈"大湾区建设""国际一流湾区和世界级城市群""实效和经验""联系实际""800–1000 字"。
**脑子**：
- 判断句："大湾区建设向国际一流湾区和世界级城市群逐浪前行"。A = 大湾区建设（怎么建的），B = 国际一流湾区、世界级城市群。标题含 A 含 B。
- 题干要的是**两样东西：实效和经验**。实效是成绩，经验是做法背后的规律。这两样不是分两大块写，而是每段都有：**经验做观点句，实效做证据**。
- 800–1000，36 行。

### 第 2 步　定拆哪边（3 分钟）
**手**：材料 2–7 六个面：硬联通、软联通、平台、人文、绿色、辐射。
**脑子**：材料在拆 A 的做法，按 A 拆。六个面合成四段：硬联通+软联通（一体化的双轮）、深度合作平台、人文+绿色（优质生活圈）、辐射带动（区域协调）。材料 1 的部署和数据放开头。七份全到。

### 第 3 步　分论点表（3 分钟）

```
A=大湾区建设  B=国际一流湾区/世界级城市群

**以联通聚合力　向世界级城市群迈进——粤港澳大湾区建设的实效与经验**

推进粤港澳大湾区建设，是习近平总书记亲自谋划、亲自部署、亲自推动的重大国家战略。从2017年三地签署框架协议，到2019年中央印发规划纲要，四年多来大湾区经济总量迈上11.5万亿元，世界五百强企业和国家级高新技术企业持续增加，向国际一流湾区和世界级城市群迈出坚实步伐。实效的背后是经验：把三地的制度差异变成制度优势，把要素流动的堵点变成合作的支点。

## 4. 这套新题型走出来的做法（待验证后进 SOP）

**优势 / 有利条件题**
- 中心词"优势"，元素形状是"名词 + 判断"（文化同源、地理相近、遗产丰富、产业雄厚），和"特点"题同一类，标签和内容都是"怎么样"。
- 做法不是优势，但做过的事（联合申遗、合作办展）能证明"已有合作基础"这种优势——事实留，动作词不当标签。
- 材料自己的总述句（"文化同源、血脉相通，是重要基础"）就是第一条的名字。
- 每条 = 标签 + 事实 + （预算够时）半句意义。

**"实效和经验"议论文**
- 两样东西不分两大块，每段都有：经验做观点句，实效做证据，收束句把经验说成规律。
- 材料按面走的（硬联通/软联通/平台/人文/绿色/辐射），两两合并成四段，每段一面或两面。
