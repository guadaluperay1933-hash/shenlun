## 1. 问题一　"绿色工厂"的"绿"体现在哪些方面（20 分，≤200 字）

### 第 1 步　审题
**手**：圈"材料 5""绿色工厂""绿""体现在哪些方面""200 字"。和省市卷第一题逐字对——题干一样，材料 5 和省市卷材料 3 一字不差。
**脑子**：表现题，五个方面材料自己用过渡句分好了（"不是简单种树""还体现在办公管理的细微处""延伸至原材料领域"）。省市卷两份 84.5 分卷也是这五个方面，平铺不套二级。7 行半。

### 第 2 步　扫段

### 第 3 步　第一遍读

| 方面 | 圈下来的 |
|---|---|
| 厂区环境 | 5000 多株乡土阔叶树 / 灌木花草 / 垂直绿墙 / 吸二氧化碳 / 凉快、风景线 |

### 第 4 步　骨架
总句 + 五条"××绿"，同省市卷。

### 第 5 步　第二遍
五堆平铺；总句抄"理念融入基因"；数字只留"5000 多株"。

### 第 6 步　写
同省市卷，超行先砍总句。

### 产出（约 186 字，7 行半）

绿色低碳理念融入企业基因。一是厂区生态绿。种植5000多株乡土阔叶树和灌木花草，建垂直绿墙，吸收二氧化碳、降温美化。二是能源清洁绿。屋顶铺设光伏板，绿电满足自用并输送电网，减少碳排放。三是产品设计绿。研发纳米涂层替代喷胶，耳机可拆解维修、配件循环利用，减重减碳。四是办公管理绿。不用一次性用品，全流程无纸化办公。五是供应链绿。要求供应商提供物料环保数据，鼓励回收利用包材线圈，节能降本。

### 第 7 步　检查
五条平铺、同型 ✓；7 行半 ✓。

### 预登记
同省市卷：(a) 理念 / 效益要不要单列（省市卷两份 84.5 都不单列）；(b) 总句（它们没写）。这题看 90 分卷有没有不一样的写法。

## 2. 问题二　S 市古树名木保护的问题与对策（30 分，≤300 字）

### 第 1 步　审题（1 分钟）
**手**：圈"调研组成员""材料 7""梳理问题""对策建议""全面准确""合理、有针对性、具体明确""紧扣材料""300 字"。
**脑子**：问题 + 对策两段。身份是调研组（林业 + 自然资源部门），对策是建议市里做的：制定规范、设资金、简化审批、普法、奖励、文旅、科技监管。问题侧表现词、对策侧手段、一一对应。12 行，格子 320。

### 第 2 步　扫结构（1 分钟）
**手**：材料 7 按走访走：背景（古树是活化石；S 市六大行动、古树保护提升行动；调研组）→ 白水景区（豪华围栏、地砖、填树洞）→ 江心岛（130 株；政府重视打击破坏；台风受损要雇专业团队；申请经费跑部门填表等几天，错过黄金时间）→ 乐业镇（专职护林员；张大爷铺水泥盖树根，"没挖树卖钱哪里违法"；护林员：号召村民，积极性不高，想办法激发热情）→ 老马（深山古树散落、坡陡难行、滑倒、野猪）→ 座谈：廖局长（条例已实施明确处罚；更重要让群众知法守法，群众是基本盘）、刘教授（保护性破坏突出、好心办坏事、案例增多）、曾主任（单靠政府不够，探索灵活救治模式；深山难保护巡山危险；借助科技动态监管全程保护）、郭组长（按条例表彰奖励；挖掘古树文化故事，结合旅游，靠护树致富，激发全民护树热情）。
**脑子**：走访四个点四个问题，座谈四个人给的是对策。四问四策：保护性破坏 / 抢救机制不畅 / 群众意识薄弱积极性低 / 深山巡护难缺科技。座谈四人和四个问题正好对上：刘教授对①，曾主任对②④，廖局长郭组长对③。

### 第 3 步　第一遍读（按点记 × 和 √）

```
白水景区  ×古树周围修豪华围栏、铺地砖、树洞用材料填补                    → ①保护性破坏（刘教授给名："保护性破坏""好心办坏事""案例增多"）
江心岛   √政府重视、严打破坏、环境好转（正面）

      曾主任：×单靠政府力量不够；√探索更灵活的救治模式                      → ②对策
乐业镇   √镇里成立专职护林员队伍（正面）
      ×张大爷铺水泥盖古树根，认为不违法，沟通无果；×护林员号召村民但积极性不高      → ③群众意识薄弱、积极性低
      廖局长：√条例已实施明确处罚；√让群众知法守法，群众是基本盘               → ③对策：普法
      郭组长：√按条例表彰奖励贡献单位个人；√挖掘古树历史文化故事结合旅游，靠护树致富，激发全民护树热情  → ③对策：激励、文旅

      曾主任：×深山保护难度大、巡山有危险；√借助科技手段掌握长势，动态监管、全程保护    → ④对策：科技
```

**脑子**（读的时候的念头）：
- 四个走访点各是一个问题，座谈四个人各给了对策，材料的结构就是"四问四策"。
- "保护性破坏"是刘教授给的类名，抄；"错过抢救黄金时间"是江心岛那段最具体的表现词，留；"群众是基本盘"是廖局长的原话，可以当对策③的道理。
- 对策②的手段：设专项资金、简化审批是从"跑部门填表等几天"反推的；"灵活救治模式、社会力量"是曾主任明说的。
- 对策④的手段：科技手段是曾主任明说的；"加强护林员安全保障"是从老马滑倒、野猪反推的。
- 问题侧不写"缺规范""缺科技"这种反推的对策词，写表现。

### 第 4 步　骨架

```
问题                              对策
① 保护性破坏 ←围栏/地砖/填树洞             制定保护技术规范、专家指导、纠正不当措施（刘教授+反推）
② 抢救机制不畅 ←审批跑部门填表等几天/错过黄金期/单靠政府不够   专项资金、简化审批快速拨付、社会力量参与的灵活救治模式（反推+曾主任）

④ 深山巡护困难 ←散落深山/坡陡/野兽/巡山危险      科技监测动态监管、护林员安全保障（曾主任+反推）
```

### 第 5 步　第二遍（3 分钟）
- **条数**：四问四策，材料结构就是这样，不多不少。
- **分工检查**：问题侧全是表现词；对策侧全是手段。镜像检查：①"保护性破坏 / 科学保护"是镜像，对策侧靠"制定技术规范、专家指导"承担手段；④"缺科技 / 用科技"是镜像，对策侧写具体"监测设备动态监管"。
- **主语**：调研组建议市里，动词用制定、设立、简化、宣传、落实、运用。
- **分字数**：问题四条各一行多，对策四条各一行半。

### 第 6 步　写（12 分钟）
**念头**：问题②把"跑多部门、填多表、等多日"三个"多"写出来，是材料最具体的表现；对策③三个手段（普法、奖励、文旅）都是座谈明说的，全留；超行先砍对策④的"加强护林员安全保障"，再砍问题④的"野兽多"。

### 产出（约 297 字，12 行）

问题：一是保护性破坏，景区古树修豪华围栏、铺地砖、填树洞。二是抢救机制不畅，经费审批跑多部门、填多表、等多日，错过黄金期，单靠政府力量不够。三是群众意识薄弱，村民铺水泥盖古树根不知违法，护树积极性不高。四是深山巡护困难，古树散落深山，坡陡野兽多、巡山危险，缺科技监管手段。

对策：一是科学规范保护，制定保护技术规范，请专家指导，纠正不当措施。二是畅通抢救通道，设立抢救专项资金，简化审批、快速拨付，探索社会力量参与的灵活救治模式。三是普法宣传激励，宣传保护条例让群众知法守法，落实表彰奖励，挖掘古树文化、结合旅游让群众护树致富。四是科技赋能巡护，运用监测设备动态监管深山古树，加强护林员安全保障。

### 第 7 步　检查
四问全是材料明说、无反推条目 ✓；四策一一对应、每条有手段，来源座谈原话或反推，无凭空自补 ✓；镜像处理 ✓；市级动词 ✓；材料专有词（保护性破坏、黄金时间、条例、表彰奖励、动态监管）在 ✓；12 行，格子 320 ✓。

### 预登记
- (a) **四条还是五条**：90 分卷可能把"群众法治意识淡薄"和"护树积极性不高"分成两条，或把"单靠政府力量不够"单列"保护力量不足"。把握：中。
- (b) **问题①的名字**："保护性破坏"是教授的词，90 分卷可能写"保护措施不科学"。命名差异。

- (d) **对策③三个手段合一条**：90 分卷可能把"文旅致富"单列一条对策。把握：中。
- (e) 表彰奖励是郭组长明说的，我放③里；90 分卷可能单列。把握：中。

## 3. 大作文　围绕"绿美广东生态建设是关系广东长远发展和民生福祉的重要工程"（50 分，800–1000 字）
