## 1. 问题一　简要说明"乡村新闻官"在推动农业农村发展中的作用（15 分，≤200 字）

### 第 1 步　审题（30 秒）
**手**：圈"乡村新闻官""农业农村发展""作用""紧扣材料""分析全面""200 字"。
**脑子**：作用题——找"乡村新闻官让农业农村得到了什么"。对象"农业农村发展"没有现成分量，材料按唐书记做的事排，按事分，标签写作用。15 分，总句不写——吴委员那句"乡村代言人，有影响力引导力"是评价，不是结构总结。7 行。

### 第 2 步　扫段（1 分钟）
**手**：资料 3 按段：大喇叭宣传人居环境政策 → 十佳乡村新闻官、20 万粉丝 → 山歌卖葡萄视频 100 万播放 → 葡萄园火了、电商售空、助农平台推广其他农产品价升量增 → 与农科院合作拍农技视频、帮联系专家 → 拍系列视频推介山水文化节日手工艺美食吸引游客 → 吴委员：代言人、影响力引导力，做乡风文明大喇叭；村规民约顺口溜。
**脑子**：五件事五条：宣传政策、带货促销、推广农技、推介文旅、引领乡风。粉丝 20 万、播放 100 万是影响力的证据，写成"影响力大"不写数字。

### 第 3 步　第一遍读（6 分钟）

### 第 4 步　骨架

```
① 宣传政策   大喇叭 / 人居环境整治 / 门前三包垃圾定点
```

### 第 5 步　第二遍

### 第 6 步　写
**念头**：②效果词最多，给两行；农产品名字留三个；超行先砍①的"门前三包"。

### 产出（约 187 字，7 行半）

### 第 7 步　检查
五条都有动作 + 效果 ✓；数字全砍 ✓；人名不写 ✓；7 行半 ✓。

### 预登记
- (a) **五条还是四条**：参考答案可能把带货和文旅合成"推介农产品和乡村旅游"。把握：中。
- (b) **总句**：参考答案可能写"乡村新闻官是乡村代言人，有影响力和引导力"。把握：中。
- (c) **"带动乡村旅游"**参考答案可能单列（游客激增、葡萄园火了）。把握：中。
- (d) 标签用"宣传政策"还是"推动人居环境整治"。命名差异。

## 2. 问题二　针对 2020 年 12 月 4 日火情暴露出的问题，提出解决建议（15 分，≤200 字）

### 第 1 步　审题（30 秒）
**手**：圈"12 月 4 日""火情""暴露出的问题""解决建议""符合实际""切实可行""有针对性""200 字"。
**脑子**：对策题。题干要的是建议，但"针对问题"——每条建议对着一个问题，标签里把问题带出来。主语是镇（林业站、护林员归镇管）。7 行。

### 第 2 步　扫段（1 分钟）
**手**：资料 5 按情节：形势严峻 → 岗南自然村山火 → 前几天排查漏了这个点（只排偏远地方）→ 汇报副镇长、通知林业站消防队 → 林业站没风机（新护林员未培训操作不当弄坏，没修）→ 消防队 3 台风机扑灭 → 起火原因：村民烧秸秆无人看护 → 护林员新来不熟地形没巡到 → 副镇长批评：反思吸取教训。
**脑子**：四个问题：排查漏点、设备损坏未修、护林员未培训不熟地形巡查缺位、村民用火无人看护。每个反过来是一条建议。副镇长说"日常工作存在问题"，还可以加一条高火险期的应急值守。

### 第 3 步　第一遍读（记 × 问题 / 反推 √ 建议）

```
× 排查只排了偏远地方，漏掉近村隐患点                → √ 排查全覆盖不留死角、建台账
× 两台新风机被没培训的新护林员演练时弄坏，没来得及修     → √ 设备专人管护、及时维修、配备用；演练前先培训
× 新护林员没经过培训、对地理环境不熟、没巡到          → √ 岗前培训（操作、地形）、划片包干、定期巡查
× 村民以为烧秸秆没事，无人看护，引燃杂草             → √ 防火宣传、规范秸秆焚烧、用火看护、及时报告
（形势）干冷北风、防灭火形势严峻；这次靠消防队3台风机   → √ 高火险期加强值守、镇村林业站消防联动
```

### 第 4 步　骨架

```
① 排查全覆盖   不留死角 / 偏远近村一并 / 台账
② 管好设备    专人管护 / 及时修 / 配备用 / 演练先培训
③ 护林员培训巡查 岗前培训操作地形 / 划片包干 / 定期巡查
④ 防火宣传    规范秸秆焚烧 / 用火看护 / 及时报告
⑤ 高火险期应急  加强值守 / 镇村站队联动
```

### 第 5 步　第二遍
五条，每条对一个问题。⑤是从"形势严峻 + 靠消防队救场"反推的，把握低一些，放最后，超行先砍。

### 第 6 步　写
**念头**：每条标签把问题反过来写（"排查全覆盖"对"排查漏点"）；建议动词用镇能做的：组织、配足、培训、宣传、值守。

### 产出（约 180 字，7 行）

一是排查全覆盖。隐患排查不留死角，偏远和近村山林一并排查，建立隐患台账。二是管好灭火设备。风机等专人管护，损坏及时维修，配足备用，演练前先培训操作。三是加强护林员培训巡查。新护林员岗前培训设备操作、熟悉地形，划片包干、定期巡查。四是强化村民防火宣传。禁止或规范秸秆焚烧，用火须看护，发现火情及时报告。五是高火险期加强值守，镇村与林业站、消防队联动。

### 第 7 步　检查
四个问题各有一条建议 ✓；建议都是镇能做的 ✓；无镜像（问题只在标签里点一下）✓；7 行 ✓。

### 预登记
- (a) **五条还是四条**：⑤是反推，参考答案可能没有。把握：中低。
- (b) **要不要先写问题再写建议**（"问题：……建议：……"）：题干只要建议，我把问题揉进标签。把握：中。
- (c) **秸秆**：参考答案可能写"禁止焚烧"或"引导综合利用"。命名差异。
- (d) 参考答案可能把设备和培训合成一条（都是护林员的事）。把握：中。

## 3. 问题三　松岭镇打造松岗—沙坪—红山乡村旅游示范片区有哪些有利条件（20 分，≤300 字）

### 第 1 步　审题（1 分钟）
**手**：圈"根据给定材料""示范片区""有利条件""考虑全面""分析透彻""300 字"。
**脑子**：优势题，元素是"名词 + 判断"。"根据给定材料"没限定哪篇——片区在资料 4，但荔枝产业在资料 2，网红推介和"乡村休闲旅游成风尚"在资料 3，都是有利条件，要跨篇找。11 行。

### 第 2 步　扫段（1 分钟）
**手**：资料 4 按行程：项目定位（重点项目、5000 万、吃住玩购）→ 松岗村（离高速 3 公里；老寨八卦石头房；村民支持改民宿、专业团队、五五分成）→ 沙坪村（新农村示范村建成；山环水绕白墙黛瓦；松岭河清澈荔枝林；碧道在建；荔枝公园自摘园）→ 红山村（靠近镇区人流量大；农家餐厅黑山羊鸡鸭河鲜；特色产品一条街）→ 徐书记称赞、希望做细做实。资料 2：山清水秀、荔枝主导产业全链条。资料 3：唐书记网红推介、乡村休闲旅游成风尚。
**脑子**：有利条件的类型：政策资金、区位交通、资源禀赋（历史文化、自然生态、物产）、建设基础、产业基础、群众支持与运营模式、宣传渠道和市场趋势。七类。

### 第 3 步　第一遍读（圈"名词 + 判断"）

```

资料2      山区镇山清水秀7万亩山地；荔枝主导产业种植加工销售全链条；打造荔枝重镇                  → 生态 / 产业基础
```

### 第 4 步　骨架

```
① 政策资金保障   乡村振兴重点项目 / 5000万 / 县镇领导重视
```
