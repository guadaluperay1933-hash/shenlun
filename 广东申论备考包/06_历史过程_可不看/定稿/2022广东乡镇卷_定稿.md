## 1. 问题一　概括新时代文明实践所的作用（15 分，≤200 字）

### 怎么做
- **审题**：作用题，对象没有官方分量，材料按活动类型排，按活动类型分五条。7 行。
- **第一遍读**（活动 + 效果词）：宣讲（轻骑队、田间地头、党史好人好事；赵婶"讲给孙子听"→群众自发传播；白老师"讲得明白有意思"→讲得清楚有趣）/ 文艺（合唱班志愿者指导、舞狮队、露天电影→丰富文化生活）/ 宣传咨询（反诈科普安全健康农技；阿军"果树不长虫了"→学以致用）/ 非遗（剪纸展厅、外出参展、进校园→年轻传承人）/ 志愿（探访老人做家务聊天→照料慰藉；辅导陪伴留守儿童）。
- **效果词这次多抓了两个**：赵婶那句和阿军那句。盲做版把它们当群众感想砍了，其实是效果——作用题里群众的反应就是效果词。
- **总句**：王鹏那句"整个镇年轻了"是感叹，不是分点的结构总结，不抄。抄总句的条件是那句话本身概括了分点（"游养买一条龙"），感叹句不算。
- **写**：五条各一行半，人名不写。

### 定稿答案（194 字，含标点，程序核数）

一是开展理论宣讲。组建宣讲轻骑队，到田间地头讲理论政策、党史和好人好事，讲得明白有趣，群众自发传播。二是丰富文化生活。提供场地并指导老年合唱班排练、少年舞狮队训练，放露天电影。三是传播实用知识。开展反诈、科普、安全、健康宣传和农技咨询，群众学以致用。四是传承非遗技艺。设剪纸展览厅，推动艺人外出参展、非遗进校园，吸引年轻传承人。五是开展志愿服务。探访独居老人、照料慰藉，辅导陪伴留守儿童。

### 定稿说明
参考答案五条（开展宣讲 / 提供活动场地 / 传播实用知识 / 传承剪纸技艺 / 开展暖心活动），分组和我完全一样。它多了"促进群众自发传播""学以致用""心灵慰藉"三个效果词，定稿补上；它没写总句，我盲做版的总句删掉。我保留的：轻骑队、田间地头、非遗进校园这些专有名，它写得泛。

## 3. 问题三　寒潮受灾，大坪镇应如何应对，列出工作要点（20 分，≤300 字）

### 怎么做
- **审题**：对策题，主语镇。赵小明当天做的每件事提炼成一条，副镇长叮嘱的（持续关注天气）单独一条，材料暗示但没做完的（大棚膜没盖全、买了保险的有保障）反推成防范和恢复。10 行。
- **第一遍读**：通知村干部分头了解灾情 / 露天受灾重、大棚膜完好 / 买了保险→报案查勘定损 / 曾伯困难→临时救助、安抚 / 拍照发农科所专家 / 向副镇长汇报 / 持续关注天气、减少损失 / 与村干部商量下一步。借材料五：果丰公司提供品种、上门收购。
- **归堆**：摸排 / 持续防范 / 抢救植株 / 理赔 / 临时救助 / 恢复生产与抗灾，六条。参考答案五条，把防范和恢复合成"提升抗灾能力"（气象预警机制、防灾培训）。定稿保留六条，但把它的"防灾技术培训""保护现场""跟进赔付到位""按不同受损情况获取方案"几个实用手段收进来——这些是从材料事实反推的，不是凭空补的。

### 定稿答案（259 字，含标点，程序核数）

一是摸排灾情。组织党员干部第一时间进村入户，掌握各户受灾情况和诉求，重点核查福垌村，统一部署救灾。二是持续防范。关注近期天气变化，加强预警，指导农户抢盖大棚膜、采取防寒措施。三是抢救植株。拍摄受冻照片报市农科所专家，按不同受损情况获取抢救方案，指导农户专业化抢救。四是推进理赔。提醒投保农户保护现场、及时报案，协助保险公司查勘定损，跟进赔付到位。五是临时救助。协助受灾重、生活困难的农户申请临时救助，做好安抚。六是恢复生产、提升抗灾能力。商定后续措施，开展防灾技术培训，推广大棚设施和农业保险，对接企业提供品种和收购。

### 定稿说明
参考答案五条：了解受灾 / 抢救植株 / 保险理赔 / 临时救助 / 提升抗灾能力。前四条和我一一对应；第五条把我的"持续防范"和"恢复生产"合成一条，写的是"与气象部门合作、预警机制、防灾培训"。它没写"抢盖大棚膜"这个材料里最具体的防范动作，也没写"持续关注天气变化"这句副镇长原话，"恢复生产"更是没有。定稿六条，吸收它的几个实用手段，保留大棚膜、企业对接这些材料来源的东西。

## 4. 问题四　复耕复种顺利完成，对新入职干部做好基层工作的启示（20 分，≤300 字）

### 怎么做
- **审题**：启示题，材料是老张做事的过程，每个环节抽一条。10 行。
- **第一遍读**：汇报担责 / 学政策梳理重难点 / 协调部门、每周研判、部署会动员 / 谢阿婆：闭门羹不放弃、了解情况、做孩子工作、多次上门 / 一个多月烈日核实、晚上资料、没说累 / 挖掘机难请→协调隔壁镇。
- **深一层读**：挖掘机为什么难请？"全县都在复耕复种"——这是能预见的资源紧张。参考答案把这一段读成"增强工作预见性、提前协调资源"，比我盲做的"灵活借力"深一层。"理解深刻"的做法：**每个难题多问一句"它为什么会出现"，答案就是深一层的启示。** 定稿采纳。
- **条数**：盲做六条，参考答案五条（把担当并进队伍建设/奉献精神）。定稿五条：深入一线和担当奉献合一条。

### 定稿答案（238 字，含标点，程序核数）

一是吃透政策、明确任务。领会上级部署的背景目标，学习政策文件，掌握具体要求，梳理重点难点。二是建立机制、协同推进。及时向领导汇报，明确责任部门，协调各部门共商困难，定期研判，统一部署、集体行动。三是群众工作要耐心有方。入户宣讲把道理讲透，遇阻不放弃，摸清情况，发动家属协助劝说，多次沟通。四是深入一线、担当奉献。逐村逐地块核实，白天跑现场、晚上理资料，不畏辛苦，确保按时高质量完成。五是增强预见性、善于借力。摸清实际，预判挖掘机紧缺等困难，提前协调外部资源，集中力量啃硬骨头。

### 定稿说明
参考答案五条：明确工作任务 / 确定工作机制 / 重视思想工作 / 加强队伍建设 / 增强工作预见性。前三条和我对应，第四条把我的"深入一线"和"担当"合并（定稿跟），第五条"预见性"比我的"借力"读得深（定稿跟，并保留"借力"）。它有一处不贴身份："加强队伍建设、要求党员干部弘扬奉献精神"是领导的口吻，新入职干部的启示应该是"自己要吃苦奉献"。它没有"及时汇报"这个动作，定稿保留。

## 5. 问题五　为大坪镇进一步推进农业现代化提出建议（30 分，≤400 字）

### 怎么做
- **审题**：对策题，主语镇政府，"可行性强"要求手段是镇能做的。13 行。
- **第一遍读**：陈伯改良品种效益好，全镇只有一家愿意试点 / 阿康直播销量有限、还在摸索，要农超农企对接冷链 / 周副主任：手工赚得少，建加工厂 / 老杨：争取培训班，种植户没技术 / 果丰：给农户品种、指导、上门收购 / 试验园无人机 AI，成本高，补贴可降。
- **反推补两处**：参考答案有两个反推我盲做没做——"全镇只有一家愿意试点"反推出"发放试种补贴"，"直播还在摸索"反推出"电商技能培训"。材料里"没人愿意 / 还在摸索 / 不知道怎么办"这类句子，都能反推成激励或培训，这条进 SOP。
- **不跟的**：参考答案的"建设现代农业产业园""兼职农民讲师团"是自补，材料没依据；它漏了果丰公司"公司+农户"的订单模式，那是材料明写的正面做法，定稿保留。

### 定稿答案（331 字，含标点，程序核数）

一、推广优良品种。将品种改良户树为典型宣传，争取扩大试点并发放试种补贴，筛选优质品种在全镇推广。
二、拓宽销售渠道。搭建农超对接、农企对接平台，争取冷链配送项目，扶持返乡青年直播电商并开展技能培训。
三、发展精深加工。引进或扶持建设食品加工厂，推动龙眼干、龙眼蜜由手工烘制转向标准化现代化生产，延伸链条，提高附加值。
四、强化科技服务。争取市里农业实用技术培训班落户本镇，组织种植户培训，发挥农技员和科研人员作用，解决落果、病虫害等问题。
五、推进智慧农业。以果丰公司试验园为示范，争取政府补贴，推广无人机监测和智能管理系统，降低农户使用成本。
六、发挥龙头带动。推广"公司+农户（家庭农场、合作社）"模式，由企业提供改良品种、技术指导和上门收购，稳定农户销路和企业原料。

### 定稿说明
参考答案五条：提升产品品质 / 拓展销售渠道 / 发展加工工业 / 推广农业技术 / 发展智慧农业。前五条和我一一对应，它多了两个合理反推（试种补贴、电商培训）定稿收进来；它自补的"现代农业产业园""讲师团"不跟；它漏了果丰公司的订单模式和"政府补贴降低智能系统成本"这句材料原话，定稿保留。

## 7. 这套改进 SOP 的东西

1. **作用题的效果词包括群众的反应**："回去讲给孙子听"→自发传播，"果树不长虫了"→学以致用。这类句子盲做时容易当感想砍掉。
2. **抄总句的条件收窄**：那句话本身概括了分点的结构（"游养买一条龙"）才抄；只是感叹（"整个镇年轻了"）不抄。
3. **启示题"理解深刻"的做法**：每个难题多问一句"它为什么会出现"——挖掘机难请是因为全县同时复耕，启示就从"借力"变成"预见性、提前协调资源"。动作层是"怎么解决的"，深一层是"为什么会遇到"。
4. **反推的第二种来源**：材料里"没人愿意 / 还在摸索 / 不知道怎么办"这类句子，反推成激励（补贴）或培训。
