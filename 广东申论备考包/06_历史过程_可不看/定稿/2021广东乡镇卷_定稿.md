## 2. 问题二　针对火情暴露出的问题，提出解决建议（15 分，≤200 字）

### 第 1 步　审题（30 秒）
**手**：圈"12 月 4 日""火情""暴露出的问题""解决建议""符合实际""切实可行""有针对性""200 字"。
**脑子**：对策题，题干只要建议，但每条建议要对着一个暴露的问题，标签里把问题反过来。主语是镇（林业站、护林员归镇管）。"符合实际、切实可行"——镇能做的事。7 行半。

### 第 2 步　扫段（1 分钟）
**手**：资料 5 按情节：形势严峻（久不下雨、干冷北风）→ 山火 → 排查漏点（只排偏远）→ 汇报、通知林业站消防队 → 没风机（新护林员未培训操作不当弄坏、没修）→ 消防队 3 台风机扑灭 → 起火原因村民烧秸秆无人看护 → 护林员新来不熟地形没巡到 → 副镇长批评反思。
**脑子**：四个暴露的问题：排查漏点、设备损坏未修、护林员未培训不熟地形没巡、村民用火无人看护。加一条从形势反推的高火险期值守。

### 第 3 步　第一遍读（× 问题 / √ 反推建议）

```
× 排查只排偏远地方，漏了近村隐患点              → √ 排查全覆盖不留死角、建隐患台账；划片巡查
× 新风机演练时被未培训的新护林员弄坏，没来得及修       → √ 设备专人管护、及时修、配足备用；演练前先培训

× 村民以为烧秸秆没事、无人看护                  → √ 防火宣传；规范秸秆焚烧；用火看护；及时报告

```

**脑子**："以老带新"是从"新护林员不熟"反推出来的好办法，比"岗前培训"具体——参考答案给的，收。"人工增雨"是市县气象部门的事，题干要"符合实际"，镇一级写这个不贴身份。

### 第 4 步　骨架

```
① 排查巡查全覆盖   不留死角 / 台账 / 划片包干定期巡查 / 火源管理
② 管好灭火设备    专人管护 / 及时修 / 配足备用 / 演练先培训
③ 培训护林员     岗前培训操作地形 / 以老带新 / 演练规范
④ 防火宣传      规范秸秆焚烧 / 用火看护 / 及时报告
⑤ 高火险期应急    加强值守 / 镇村站队联动
```

### 第 5 步　第二遍
五条各对一个问题。巡查从③挪到①（巡查是排查的日常化），③专写培训。⑤把握低放最后。

### 第 6 步　写
**念头**：标签把问题反过来写；动词用镇能做的：组织、配足、培训、宣传、值守；超行先砍⑤。

### 定稿答案（191 字，含标点，程序核数）

一是排查巡查全覆盖。隐患排查不留死角，偏远和近村山林一并排查，建立台账，护林员划片包干、定期巡查，管住野外火源。二是管好灭火设备。风机等专人管护，损坏及时维修，配足备用，演练前先培训操作。三是加强护林员培训。新护林员岗前培训设备操作、熟悉地形，以老带新，规范演练。四是强化防火宣传。引导村民规范秸秆焚烧，用火须看护，发现火情及时报告。五是高火险期加强值守，镇村与林业站、消防队联动。

### 第 7 步　检查
四个暴露的问题各有一条 ✓；建议都是镇能做的 ✓；"以老带新"收了 ✓；7 行半 ✓。

### 定稿说明
参考答案五条：及时增雨 / 加强巡查 / 完善设备 / 扩大宣传 / 加大培训。四条和我对应，它的"以老带新"是好的反推，定稿收进培训那条。它的"人工增雨"是自补，而且是气象部门的事，镇一级的建议写它不符合"符合实际"。它没有我的"高火险期值守"，我保留。

## 7. 这套改进 SOP 的东西

1. **作用题分组钥匙——先查总述材料**。对象的分量常常写在第一份总述材料里（"产业人才文化生态组织五个振兴，农业高质高效、乡村宜居宜业、农民富裕富足"），题干指定的那篇材料里没有，容易漏看。有分量就用分量当标签（推进生态宜居、拓宽销售渠道），动作放进内容。
2. **多人物启示题按人写**：一人一条，品质当标签，这个人的做法收全，末尾一句深一层的启示；品质相同的人合一条。按品质跨人写会为了归类丢掉一半做法。
3. **优势题跨篇的条件是保险**：讲对象的那篇是主材料，跨篇的条件压成最后一条写短，不和主材料的条件平分字数。
4. **对策自补的又一种越界**：主语做不了的事（镇写"人工增雨"）不写，题干"符合实际"就是在查这个。
