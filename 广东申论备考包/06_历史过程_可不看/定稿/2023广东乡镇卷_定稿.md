## 1. 问题一　概括人才在北山镇乡村振兴中发挥的作用（15 分，≤200 字）

### 怎么做
- **审题**：作用题，找"人才让乡村得到了什么"。15 分"概括"，不要总观点句。7 行。
- **扫段**：七个人物五种身份。**分组用什么钥匙？** 盲做版按主体分（村支书/企业家/返乡人才/非遗/工作队）。定稿改按**对象的分量**分——"乡村振兴"有现成的分量：治理、产业、文化、收入、生态（总括材料说的"乡村发展、建设、治理"）。判据：**对象有官方分量就按对象分量分，没有才按主体分**。上一套（青年对制造业）对象没有现成分量、材料按主体排，所以按主体；这套对象是乡村振兴，按它的分量。
- **第一遍读**（效果词为主）：
  ```
  邓忠达  调解纠纷/处突/解难/治理示范村                → 治理
  林启长  预制菜加工带动产业/慰问困难户                  → 产业 + 公益（治理）
  赖以赏  电商打开销路/农消一步到位                     → 产业
  邓志明  生态养殖打响品牌/带动旅游                     → 产业
  李其让  根雕做活/带徒/工作队帮找市场小福鹿三四千         → 文化 + 增收
  工作队  跑项目资金引进项目/党支部+公司+基地+农户联农带农  → 增收
  林科长  垃圾污水面源污染治理/村容村貌/驻点咨询           → 生态
  ```
- **骨架**：治理 / 产业 / 文化 / 增收 / 生态，五条；每条主体写进句子里当例证。
- **写**：作用题例子不砍效果词；人名不写；"党支部+公司+基地+农户"预算不够压成"联农带农模式"。

### 定稿答案（191 字，含标点，程序核数）

一、改善基层治理。村支书调解纠纷、处置突发事件、帮解难题；企业家热心公益。
二、发展农村产业。预制菜加工带动产业，返乡人才电商拓销路、实现农消对接，养殖打响品牌、带动旅游。
三、传承乡村文化。非遗传承人精研根雕、带徒传艺，把根雕文化做活。
四、促进村民增收。工作队帮根雕开拓城市市场提升售价，引进项目资金，推行联农带农模式。
五、改善农村生态。治理垃圾污水，提升村容村貌，驻点提供技术咨询。

### 定稿说明
参考答案五条按领域分（改善基层治理 / 发展农村产业 / 传承乡村文化 / 提升村民收入 / 保护农村生态），我盲做按主体分，效果词两边差不多。定稿跟它的分组钥匙——对象有官方分量。它没有任何专有名（预制菜、电商、根雕、联农带农全没有），我保留；"便民咨询"我盲做为预算砍了，定稿补回。

## 2. 问题二　谈谈榕泉村是如何利用自身文化资源吸引游客的（15 分，≤200 字）

### 怎么做
- **审题**：做法题，主语榕泉村，限定"文化资源"，目的"吸引游客"。7 行。
- **扫段**：按参观顺序：线路→古村→体验→稻田鱼→美食→康养→文创→阳书记总结"以文兴村，农文旅一体化，游养买一条龙"。
- **分组**：材料自己的总结句就是分组——引得来（游）/玩得嗨（玩）/留下来（养）/买买买（买）。四组。
- **总句**：**材料自己有总结句的，抄成总句放最前面**——"以文兴村，农文旅一体化，游养买一条龙"18 个字，是材料原话，参考答案写了。SOP 里"总括句可省"只适用于材料没给总结句的情况。
- **写**：总句占掉 21 字，四组各压一点：线路那组砍"千年榕"，康养那组砍"篝火晚会"。

### 定稿答案（196 字，含标点，程序核数）

榕泉村以文兴村，农文旅一体化，游养买一条龙。一是打造特色游线引客。围绕民族风情等主题打造"一河十景"风情游，修缮古村落打造网红打卡点。二是开发民族风情体验。设体验基地，游客可当银匠绣娘、制茶抓鱼；办稻田鱼文化节"万人抓鱼"；美食街歌舞款待。三是发展康养休闲留客。发挥民族医药优势，提供温泉、推拿、药膳、养生讲座。四是开发文创产品促消费。办创意设计大赛开发文创，设专卖区直播带货、线上线下销售。

### 定稿说明
参考答案四条和我的"游玩养买"完全一致，美食也塞在体验里。它比我多一句总句（材料原话），定稿补上；它的四条没有一个专有名（一河十景、稻田鱼文化节、创意设计大赛、直播带货、温泉药膳全没有），我保留。

## 3. 问题三　在全镇推广大围村积分制经验，临溪镇应重点把握哪些方面（20 分，≤300 字）

### 怎么做
- **审题**：从大围村的做法抽关键环节，加上材料里踩过的坑；主语是镇。11 行。
- **扫段**：对话按环节走：奖品公开栏→阿姨（起初不信→兑奖→都参与）→朱书记（以前不重视效果差→学外地）→赵副书记（组织方先明白意义）→民主定标→程序监督公开→资金→奖励方式→杨组长评。
- **骨架**：认识 / 定标 / 程序 / 资金 / 奖励 / 参与，六条。朱书记"以前不重视效果不好"和赵副书记"组织方先明白为什么"是材料明说的教训，推广时第一条就是它——参考答案没写，我判这是它漏的采分点，保留。
- **写**：每条四字标签 + 做法；程序那条把评分小组、监督小组、全过程公开、每月公示四个词都放进去。

### 定稿答案（281 字，含标点，程序核数）

一是提高认识。组织方先弄清积分制引导村民参与治理的意义，学习先进经验，镇里加强培训指导。二是民主定标。各村召开党员大会、村民代表大会，结合实际制定赋分内容和评分标准，确保可操作。三是规范程序。村两委组成评分小组负责评分兑换，党员村民代表组成监督小组核实公示，申报审核评定全过程公开，明细每月公布。四是保障资金。以村集体收入、乡贤捐赠为主，拓宽渠道，保障长期运行。五是丰富奖励。奖品实用，评选"文明先锋"、颁流动红旗，对接超市用消费券奖励，征求村民意见增强吸引力。六是引导参与。党员带头，初期通过防诈宣传、治安巡逻等活动让村民积分及时兑奖、取信于民，逐步扩大参与。

### 定稿说明
参考答案五条：落实奖励吸引参与 / 民主协商 / 严格把关 / 广开渠道 / 丰富奖励——正好是我的②③④⑤⑥，少了①"提高认识"。材料里朱书记和赵副书记两个人都在讲这件事，我判它是采分点，保留六条。它的"初期举办主题活动、所获积分及时兑换"写得比我好，定稿把"及时兑奖"补进⑥。

## 4. 问题四　假如你是小麦，此次会议对做好应急管理工作有什么启示（20 分，≤300 字）

### 怎么做
- **审题**：启示题，每条 = 标签 + 认识句（抄原话）+ 做法句。"认识深刻"靠抄原话。11 行。
- **扫段**：六个话题：预案 / 处置速度 / 思想觉悟 / 隐患排查 / 依法监管 / 群防群治。
- **反推**：小曾"预案疏漏、缺经验"反过来就是"请有经验的同事参与、逐级审核"——参考答案这样写了，比我盲做版的"多请教"具体，定稿采纳。邻镇"处分了不少人"参考答案反推成"明确处罚标准"，这个我不跟——启示对象是小麦本人，处罚标准不是他能定的。
- **保留**：詹副镇长对小麦说的"提高思想觉悟，安全重于泰山"是这场会议里唯一直接冲着小麦说的话，参考答案居然没写，我判它是最该有的一条。

### 定稿答案（274 字，含标点，程序核数）

一是提高思想觉悟。安全重于泰山，保障群众生命财产安全是重中之重，工作多杂也要随时待命。二是编好应急预案。预案是处置依据，群众转移路线、人员安置、物资保障要考虑周全，多向有经验的同事请教、逐级审核补漏。三是快速响应处置。每慢一分钟就多十分危害，接报后要快出动、快处置。四是坚持预防为主。经常进村入户走企业排查整治隐患，重点时段开展消防检查，把隐患扼杀在萌芽。五是依法严格监管。用好安全生产法律法规这个"武器"，对不重视安全的企业依法责令限期整改、停产停业。六是发动群众参与。多宣传多动员，引导党员、群众、企业、社会组织参与排查防治，合力筑牢安全防线。

### 定稿说明
参考答案五条全是做法，没有一句认识句，也没有"思想觉悟 / 安全重于泰山"这条；题干要求"认识深刻"，我判这是它失分最多的一题。它的"邀请经验丰富的干部参与预案撰写、逐级审核"是好的反推，定稿收进②。

## 5. 问题五　杨组长介绍上塘镇推动村集体经济增收做法的发言提纲（30 分，≤400 字）

### 怎么做
- **审题**：提纲 = 标题 + 开头一句 + 主体分条 + 结尾一句。14 行半。
- **结构选择**：盲做按做法类型分五条（盘活/抱团/办企业/流转/劳务）；参考答案**按村分**（一、百岭村 二、塘头村 三、羊角村），村下面再分做法。哪个好？杨组长是走访了三个村的人，交流会上按村讲最自然，也和材料结构一致，不用冒归错组的风险。**材料按村走的提纲，就按村写，做法标签放在村名后面。** 定稿改按村。
- **条数**：参考答案六个做法（观景亭茶座单列"发展旅游产业"），我盲做五个（茶座塞进盘活资产）。茶座是村集体新建经营的，不是盘活旧资产，单列对。
- **开头结尾**：开头一句总述，结尾用杨组长的总结句"各尽所能、各展所长"。

### 定稿答案（365 字，含标点，程序核数）

关于上塘镇推动村集体经济增收做法的发言提纲

调研组走访上塘镇百岭、塘头、羊角三村，各村立足自身基础和资源优势推动集体增收，做法如下。

一、百岭村：盘活闲置资产，发展旅游服务。1.清点集体资产，闲置厂房出租给电商、快递企业，废弃校舍租给村民改民宿。2.依托本地游建观景亭茶座，村集体管护经营。

二、塘头村：抱团合作、兴办企业、流转土地。1.与塘尾、羊角村优势互补合建甲鱼基地，出地出钱出力，收益按比分成。2.贷款购置茶叶色选机，承接茶企分拣，年增收十余万。3.村民以土地入股，连片流转规模化种植或承包企业，发展花卉大棚，争取纳入现代农业产业园。

三、羊角村：发展劳务服务。村集体对接茶企、种茶大户签服务协议，组织村民采茶收费；为工程、养殖项目供工；吸纳返乡大学生拓展农产品网络推广。

各村各尽所能、各展所长，走出特色增收路，建议因村制宜推广。

### 定稿说明
参考答案按村分、六个做法、开头一句结尾一句，定稿跟它的结构。它比我少的：花卉大棚、争取纳入产业园、"贷款购置"、"为工程养殖供工"——定稿保留；它的"提供收费服务"这个标签太弱，我用"发展劳务服务"。

## 7. 这套改进 SOP 的东西

1. **作用题分组的钥匙**：对象有官方分量（乡村振兴→治理/产业/文化/收入/生态）就按对象分量分；对象没有现成分量、材料按主体排的，按主体分。两套参考答案一套按主体一套按领域，判据在对象。
2. **材料自己有总结句的，抄成总句放最前面**（"以文兴村，农文旅一体化，游养买一条龙"）。"总括句可省"只在材料没给总结句时成立。
3. **发言提纲**：材料按村/单位走的，提纲就按村写，做法标签放村名后面；标题 + 开头一句 + 按村分条 + 结尾一句（用材料里领导的总结句）。
4. **启示题**：别人被指出的错（预案疏漏、缺经验）反推成做法（请有经验的同事参与、逐级审核）；直接对"我"说的话（提高思想觉悟）必须是一条；不写"我"没权限做的事（定处罚标准）。
5. **五题小题卷**：分值定行数定时间，30 分的题留 35 分钟；一题一材料不跨材料。
