## 1. 问题一　简述广东在促进大湾区"软联通"方面的主要做法（20 分，≤200 字）

### 怎么做
- **审题**：做法题，主语广东（含市、区）。材料末段自己下了定义——"以制度、规则衔接为重点"，找的是制度规则层面的动作。7 行半。
- **扫段**：律所→横琴资质立法→职业资格互认→一站式平台→社保通办→仲裁平台→市场准入→总结句。六块。
- **第一遍读**（圈动作）：试点律所联营 / 立法认可建筑资质 / 拓展 8 领域、单边认可带动双向互认 / 试点聘港澳居民为公务员、招聘办法 / 建职称职业资格一站式平台 / 珠澳社保跨境试点、"零通关"通办、多点办就近办 / 搭建仲裁交流合作平台、港澳机构进驻、规则互认衔接 / 放宽准入特别措施清单、商事登记确认制、放宽产业投资医药金融。
- **归堆**：盲做五堆（互认 / 一站式 / 通办 / 法治 / 准入）。定稿四堆：**一站式平台是"职称和职业资格业务"的平台，和互认同一个制度域，塞进互认那条**，标签省一个，省下的字数换回"单边认可带动双向互认""零通关""商事登记确认制"三个低频词。
- **写**：第一条内容最多给两行半；数字不写；成效（受理 493 例）不写。

### 定稿答案（195 字，含标点，程序核数）

一、推进职业资格互认。试点律所联营、认可港澳建筑资质，以单边认可带动双向互认，放开招聘港澳居民；建职称职业资格一站式服务平台。
二、推动湾区通办。试点珠澳社保跨境合作，"零通关"跨境通办，多点办、就近办。
三、开展法治合作。搭建国际仲裁交流合作平台，引进港澳法律机构，推动制度机制规则互认衔接。
四、放宽市场准入。出台先行示范区放宽准入特别措施清单，试点商事登记确认制，放宽产业、医药、金融准入。

### 定稿说明
参考答案四条，把一站式平台并进了职业资格互认——同一个制度域，合理，定稿跟。它的内容泛：没有律所联营、立法认可、单边双向互认、零通关、商事登记确认制、具体领域，"制定试点方案"这种词在材料里对应的是"特别措施清单试点"和"商事登记确认制试点"，泛化后就没了低频词。定稿全部保留。

## 2. 问题二　分析说明三地推进文化交流合作、共建人文湾区的优势（30 分，≤300 字）

### 怎么做
- **审题**：优势题，元素是"名词 + 判断"（同源、相近、丰富、雄厚），不是做法。做过的事（联合申遗、合作办展）当"已有合作基础"的证据。11 行。
- **扫段**：总述（同源血脉相通是基础）→ 五同图片展 → 专家（百越、岭南珠江文化、语言根基）→ 地域相近山水相连 → 遗产游径 → 孙中山 → 粤剧、戏曲节、銮舆堂、盘伯 → 醒狮 → 文博合作 → 产业数据 → 结语。
- **归堆**：盲做六条（同源 / 地理 / 遗产 / 非遗民俗 / 文博 / 产业）。定稿调两处：**孙中山单列一条"伟人渊源"**——材料用"宝贵而核心的共同财富"单独强调了它，材料用"最、核心、宝贵"强调的元素要单列；非遗民俗和文博合作合成"交流合作密切"（都是"已经在合作"的事实，一个民间一个官方）。还是六条。
- **标签**：全是"名词 + 判断"，和内容词性一致。
- **写**：五地遗产名字全留；粤剧、銮舆堂、醒狮、外销画留；数字只留"支柱产业"这种结论。

### 定稿答案（265 字，含标点，程序核数）

一是文化同源。三地自古同属百越之地，以岭南文化和珠江文化为主流，语言文化根基相通。二是地域相近。山水相连，交通便利，港澳民众往来频繁，文化合作有天然地理优势。三是遗产丰富可串联。广州遗产、岐澳古道、改革开放遗迹、澳门世遗、香港文物径可连成文化遗产游径。四是伟人渊源深厚。孙中山在中山、澳门、香港、广州的足迹连成一体，是三地共同财富。五是交流合作密切。粤剧由三地联合申报人类非遗，銮舆堂穗港共有、会员频繁往来，醒狮各地皆有；文博界联合追回外销画、合作办展。六是文化产业雄厚。已成大湾区新兴支柱产业，文交会活跃，文化上市公司形成板块。

### 定稿说明
参考答案五条：文化同源 / 地理相连 / 伟人渊源 / 文化交流日益密切 / 文化产业蓬勃发展。它单列孙中山，我跟；它把非遗和文博合成"交流密切"，我跟；产业算优势，我盲做时最没把握的一条它写了。它的问题："地理相连"那条的内容是遗产游径（一个做法），不是地理的证据，交通便利、往来频繁这些真正的地理证据反而没有；粤剧、銮舆堂、醒狮、岐澳古道、文物径一个都没出现。定稿六条，把遗产单独留一条。

## 3. 大作文　围绕"大湾区建设取得的实效和经验"（50 分，800–1000 字）

### 怎么做
- **审题**：A = 大湾区建设，B = 国际一流湾区、世界级城市群。题干要两样：实效和经验。**处理法：经验做观点句，实效做证据，收束句把经验写成可迁移的规律**——参考答案把经验写成给其他地区的借鉴，这个角度好，定稿在开头和收束句里加进去；但它为了写规律把论据全丢了，这个不学。
- **拆哪边**：材料 2–7 六个面，按 A 拆，合成四段：硬软联通 / 合作平台 / 人文绿色 / 辐射带动。材料 1 进开头。七份全到。
- **每段**：经验观点句 → 一句道理 → 三个实效（一个数字）→ 规律句收束。
- **核案例**：梦工厂—前海，实验室分部—横琴，港科大—南沙，肇庆院区—中大附三，市市通高铁—赣深高铁。

### 定稿答案（961 字，含标点，程序核数）

**以联通聚合力　向世界级城市群迈进——粤港澳大湾区建设的实效与经验**

推进粤港澳大湾区建设，是习近平总书记亲自谋划、亲自部署、亲自推动的重大国家战略。从框架协议到规划纲要，四年多来大湾区经济总量迈上11.5万亿元，向国际一流湾区和世界级城市群迈出坚实步伐。实效的背后是经验：把三地的制度差异变成制度优势，把要素流动的堵点变成合作的支点。也为其他区域提供了借鉴。

硬联通打基础、软联通破壁垒，是湾区一体化的双轮。港珠澳大桥、广深港高铁建成通车，新横琴口岸开通，城市轨道运营里程超过千公里；更关键的是规则衔接——港澳专业资质立法认可、八个领域职业资格互认、珠澳社保"零通关"通办、国际仲裁交流合作平台、放宽市场准入清单。经验是：基础设施先行，规则衔接跟上，"同事同标、湾区通办"，一体化才从地图走进日常。

搭建深度合作平台，是三地融合的支点。前海以金融开放试验窗口聚集港资企业逾万家，深港青年梦工厂孵化数百个创业团队；横琴与澳门高校共建产学研基地，澳门四所国家重点实验室设立分部，数千名澳门居民办理居住证、在横琴生活就医；南沙引来香港科技大学（广州）。经验是：平台先行先试，从经济产业融合走向社会民生融合，融合才有落脚点。

以人文为纽带、以绿色为底色，共建宜居宜业宜游的优质生活圈。三地文化同源、血脉相通，共建人文湾区有天然基础：文化遗产游径把广州遗产、岐澳古道、澳门世遗、香港文物径串成一线，粤剧由三地联合申报人类非遗，文化产业已成为大湾区新兴支柱产业。守护好青山绿水是绿色发展的保障：肇庆当好大湾区"绿肺"，新能源汽车产量增速领跑全国，虚拟电厂在广州首试。经验是：人文聚人心，绿色聚人气，世界级城市群要有世界级的生活品质。

辐射带动粤东西北，构建区域协调发展新格局。大湾区一头挑起广阔腹地，一头挑起全球市场，能级越高，带动越强。中山大学附属第三医院肇庆院区启用；广州港与湛江港签约合作，把湛江打造成沿海经济带重要发展极；赣深高铁通车让广东"市市通高铁"，全域步入"3小时经济生活圈"。经验是：按"一核一带一区"布局，让湾区的动能向全省传导，核心越强，全域越活。

四年多的实践，经验可以归为一句：以联通聚合力、以平台促融合、以人文绿色提品质、以辐射带全省。站在新起点上，广东要以更大魄力推进改革开放，联手港澳打造更具综合竞争力的世界级城市群。

### 定稿说明
参考答案五段：顶层设计 / 硬联通 / 软联通 / 文化 / 合作平台，结尾提一句生态。它把"经验"写成了给其他区域的通用规律，角度好，定稿在开头加了"为其他区域提供借鉴"、每段收束改成"经验是：……"的规律句。但它整篇几乎没有材料事实——硬联通那段没有港珠澳大桥，合作平台那段没有前海横琴，"顶层设计"整段是材料外的话——题干"论据确凿""与材料联系紧密"两条都没做到；材料 6、7 基本没用。定稿保留四段和全部论据。

## 5. 这套改进 SOP 的东西

1. **优势 / 有利条件题（新增一节）**：元素是"名词 + 判断"，和特点题同类；做过的事当"已有合作基础"的证据，动作词不当标签；材料自己的总述句（"文化同源、血脉相通，是重要基础"）是第一条；每条 = 标签 + 事实 + 半句意义（"所以……有基础"）。
2. **材料用"最、核心、宝贵、关键"强调的元素单列一条**（孙中山足迹"宝贵而核心的共同财富"）。强调词是出题人在给采分点画线。
3. **同一制度域的做法可以塞进一条**（一站式平台并进职业资格互认），关键词保留，省下的标签字数换低频词。
4. **题干含"经验"的作文**：观点句写成可迁移的规律句（"基础设施先行、规则衔接跟上"），收束句用"经验是：……"；实效仍然每段做证据，不能像参考答案那样为了写规律丢掉论据。

## 校对记录（2026-09-06）

所有答案用程序重数了字数（含标点）。原来标注的“约 × 字”是头脑估的，作文普遍偏少 15–30%，六篇 800–1000 字的作文实际都超过了 1000，已逐篇砍到 1000 以内；砍的是每段的第二个证据和重复的道理句，结构、每段一个数字、材料露脸都没动。小题只有个别第一题超 200，已压回。教训进 SOP v15：字数只能数，不能估。
