# SOP 之外：能力差、训练清单、词库、下一步

> 这份文件记 SOP 管不了的东西。第 1、2 节是我和你在同一套 SOP 下的差别；第 3 节是你要练的；第 4 节是从十四套真题里抽出来的词库，把我"自带"的词汇外化给你；第 5 节是人类执行测试；第 6 节是下一阶段读五年高分卷的方法。

---

## 1. 同一套 SOP，我比你强在哪（以及你的替代动作）

| 我的优势 | 它是怎么帮我的 | 你的替代动作 |
|---|---|---|
| **一次装下全部材料** | 八份材料我同时看见，跨篇找条件、找证据、找总结句是瞬间的；"材料 5 的收购可以当材料 3 寒潮后的手段"这种跨篇联想我不费力 | 开考三分钟给每份材料顶上写一个词；两遍读法；作文分论点表里写明每段用哪份材料；跨篇找点只在问题三（优势）和对策手段时做，别的题一题一材料 |
| **词汇先验** | 五个振兴、点绿成金、推进生态宜居、共建共治共享这些标签我张口就来，起名不占时间 | 第 4 节词库，背；练题时标签只从词库和材料里选，不现想 |
| **结构先验** | 我见过大量参考答案，知道"问题对策各 4–6 条、作文四段对仗"是常态，判断"条数跟材料走"时有底 | 十四套定稿当样本反复看，看到条数、标签、段落的手感为止 |
| **写作流畅** | 观点句、道理句、收束句我不用想，段与段的衔接词也不用想 | 第 4.6 节的句子模板；作文先填模板再润色 |
| **速度** | 一套题的"思路"我几秒生成 | 限时训练，见第 3 节 |
| **不累、不慌** | 第三题时我和第一题时一样 | 大作文先写结尾三行保底；第 7 节应急 |
| **知道参考答案的写法** | 对答案时我能一眼判断它泛在哪 | 第 5 节的"参考答案固定风格"清单 |

**这些优势不来自 SOP。** 所以我做出来的答案质量，不能全算在 SOP 头上——SOP 保证的是"点找全、词不丢、结构对"，剩下的成色来自词汇和流畅度，那部分你要自己攒。

## 2. 我比你弱在哪

| 我的短板 | 你的优势 |
|---|---|
| **看不见格子，字数靠估**，估算偏少 15–30%，校对时六篇作文全超 | 你在格子上写，天然数行；写满一行就是 25 字，这是硬约束 |
| **没有时间感**，"审题 30 秒"对我是空话 | 你有手表 |
| **示范不等于执行**，我的"思路和动作"是写给人的顺序，不是我的实际过程 | 你练的每一次都是真执行，能发现 SOP 里哪一步实际做不了 |
| **容易加码**：材料说"多个海湾入选"我写成"Z 市海湾入选"，材料说"绿色工厂首位"我写成"绿色工厂、绿色供应链首位" | 你抄材料时逐字对，比我更不容易发挥 |

## 3. 你需要训练的能力（每项：怎么练、练到什么算够）

| 能力 | 怎么练 | 什么算够 |
|---|---|---|
| **圈词** | 拿定稿文件里的"第一遍读"表格当答案，自己先在材料上圈，再对表 | 一份材料圈完不超过 8 分钟，圈到的动作 / 坏词和表格差不超过两处 |
| **归堆和定条数** | 只做第 2、5 步：读完写骨架就停，对定稿的骨架 | 条数和分组与定稿一致率八成以上 |
| **起名** | 词库默写；练题时标签只能从词库或材料里选 | 一个标签 5 秒内出，4–8 字，词性对 |
| **行数控制** | 每次练题都在真答题卡（25 格）上写，写完数格 | 小题不超上限、不少于八成；作文误差 ±30 字内 |
| **作用 / 成效题的效果词** | 拿 2021 县级、2022 乡镇、2023 县级三套专练，先划出所有效果词再答 | 三个来源的效果词一个不漏 |
| **对策写到工具** | 每条对策写完问"用什么工具做"，写不出工具的重写 | 每条对策至少一个可执行的工具名 |
| **作文观点句** | 每份材料先划出它第一段的判断句，再决定分论点 | 四个观点句里至少三个能指回材料判断句 |
| **案例核对** | 作文写完，每个案例的地名、人名、做法回材料点一遍 | 零串错 |
| **预登记** | 每套题写答案前先写三条"没把握的" | 对答案时预登记命中一半以上，说明你知道自己在哪不稳 |
| **限时** | 三题卷 120 分钟整套做；先做题型专练再做整套 | 能在 120 分钟内写完并有 10 分钟检查 |

**练的顺序**：先单题型（作用题、问题对策题各三套），再整套限时，最后拿没做过的卷子盲测（第 5 节）。

### 4.6 作文的句子模板和原料
- **观点句**：优先抄材料各面开头的判断句。真题里出现过的：生态环境是人类生存与发展的根基 / 绿色发展作为一种生产方式的变革已成为经济发展的新增长点 / 推动绿色发展是满足人民日益增长的优美生态环境需要的必然要求 / 绿色低碳是城市发展的未来 / 产业兴旺是解决农村一切问题的前提 / 人才是决定性因素 / 市场是最重要的孵化器加速器放大器 / 科技创新和体制创新如车之双轮 / 增绿就是增优势 / 含绿量越高含金量越足 / 良好生态环境是最普惠的民生福祉 / 保市场主体就是保社会生产力
- **自己的观点句模板**："A，是 B 的 X。"（生态美，是长远发展的最大本钱）；"以 X、以 Y，Z。"（以质量立身、以品牌塑魂，擦亮金字招牌）；"推动 X，筑牢 B 的 Y。"
- **道理句**：材料判断句 + "……才……"（底子厚了，发展才有后劲）
- **证据句**：三个名词化的名字，一个数字："A 县……；B 市……；C 镇……"
- **收束句**："经验是：……" / "……才落到实处" / "X 通了，Y 才……" / "含 X 量越高，含 Y 量越足"
- **开头模板**：引语一句 → 解题干里的比喻或口号一句 → 家底或靶子一句（至多一个数字）→ 点明几件事（两个落点都点）
- **结尾模板**：材料原句或意象一句 → 四个方面各一个短语 → 上层目标（走在前列 / 中国式现代化 / 和谐共生）
- **策论文**：动词"要"；开头抄短板句当靶子；每段三个"要"各带一个材料专有名

## 5. 人类执行测试（SOP 能不能落地，只有这个算数）

**用哪套**：仓库里的 2024 三卷（行政执法）没动过；或者你手头任何一套广东卷。

**怎么做**：
1. 掐 120 分钟，在 25 格的答题卡上盲做，不看任何答案。每题写完记下用时和实际行数。
2. 做完不改，先写三条预登记。
3. 把你的答案、用时、预登记发我；我再盲做一份（我先写再看你的）。
4. 三方对：你的、我的、合集里的高分卷（如果有）。差异按四类分，另外单列一类——**"SOP 写了但我没做到"**：哪一步在考场上实际做不了、来不及、忘了。

**看什么**：不看你的分数，看第五类。那一类才是 SOP 要改的地方——改成人能做的动作，或者删掉。

## 6. 下一阶段：读五年高分卷的方法

**读什么**：合集里 2021–2026 所有带真分数的卷子，先读同题最高分和最低分两份，再读中间的。

**每份记录四样**（做成表）：
1. 条数和标签：每题几条、标签几个字、什么形式（动宾 / 名词判断 / 主体加作用 / ××绿）
2. 对策形状：一一对应吗、工具级还是动词级、自补几处
3. 作文结构：几段、分论点是不是题干落点或材料判断句、每段几个材料名、几个数字、开头有没有靶子、结尾几行
4. 字数：实际几行，和上限差多少

**怎么用**：
- 同题高分和低分的差别，先按 SOP 的规矩解释；解释得通，那条规矩记一个真分数证据；解释不通，记成待解释项，攒三个同类再改规则。
- 一份高分卷的做法只算样本，不改规则；三份高分卷一致、且低分卷相反，才改。
- 真分数卷和机构答案冲突时，信真分数。

**已经攒下的真分数证据**（2026 两套八份卷）：
- 小题平铺不套二级：省市卷 77 分卷的"理念绿套四项"。
- 问题对策一一对应、手段从材料来：84.5 对 77，问题相同，差在对策侧。
- 对策写到工具：县镇卷三份 90 分卷。
- 作文观点句用材料判断句 / 题干落点：省市卷两份 84.5、县镇卷三份 90。
- 作文四段或两大段都能到高分，段数不是变量，观点句落点是。
