# 申论做题法（原理 · 程序 · 信号）

> 这是主文件。它的层次是：阅卷机制 → 四条原理 → 一个短程序 → 一张信号表 → 附录里的案例样本。前三层是要学的，信号表是要熟的，案例样本是查的不是背的。
>
> 它替代之前那份"看到 → 做"的 SOP：那份里几十条案例规则，全部按支撑数分了级，能从原理推出来的进了信号表，只有一两份样本撑着的进了附录，标"未验证"。
>
> 来源：十四套广东真题盲做对照，55 份真人得分卷校准。

---

## 0. 为什么先讲阅卷机制

小题是**踩点给分**：出题人从材料里划出若干采分点（通常四到六个，每个是材料里的一句或一个词组），阅卷人拿着清单在你的答案里找，找到一个给一个的分。作文是**分档给分**：先按立意和结构定档（有没有落在题干的判断上、有没有清楚的分论点），再按论证和语言在档内浮动。两个人独立评，分差超过阈值才仲裁——所以同一份答案在两个阅卷人手里差两三分是常态，55 份真人卷里同题同结构的差距就是这个量。

这三件事决定了后面的一切：

- 采分点是材料的压缩，所以答案也应该是材料沿着题干那条轴的压缩——用材料的词、覆盖材料的单位。
- 清单里一条是一条，所以条数细分不吃亏、合并一定吃亏，多写一条不扣分、漏一条丢两分。
- 作文先看落点和结构，所以观点句落在题干的判断上，比多举两个例子值钱。

这也是它和"技巧集"的区别：每条规矩要能从机制推出来，推不出来的只是样本。

## 1. 四条原理

**覆盖**：材料里沿着题干这条轴互不重复的单位，有几个写几个。检验：数一遍材料里的单位，和答案的条数相等或答案更细。

**保真**：用材料自己的词——低频专有名、排比、总结句、判断句；主语和平台名用原名；"最 / 首位 / 入选"每个能指回原句。检验：答案里的每个名词都能在材料里找到出处。

**对齐**：按题干指定的轴（做法 / 问题 / 作用 / 特点）和材料自己的组织方式（总述给的分量、段落的分法、人物的分法）来分组和起名。检验：标签和内容读起来是同一种东西（动作对动作、判断对判断），分组用的是材料里已有的分类。

**预算**：格子是硬约束，超出的字不算分。按格子的九成定行数，每条一行半，三层内容（例子、数字）先砍。检验：写完数格子，不估。

四条之外没有第五条。后面所有程序和信号都是这四条在不同材料上的样子。

## 2. 小题程序：四问一表

每道小题在草稿纸上回答四个问题，答完再动笔。四问填完就是骨架。

### 第一问：单位是什么？

题干的中心词决定你要找的"单位"，单位决定圈什么、标签长什么样。

| 中心词 | 单位 | 圈什么 | 标签形式 | 每条的形状 |
|---|---|---|---|---|
| 做法 / 举措 / 经验 / 建议 / 密码 | **动作** | 动词 + 名词，主语是题目指定的主体 | 动宾 4–8 字 | 标签 + 两三个动作短语（+ 一个效果尾巴） |
| 问题 / 短板 / 困难 | **状态** | 名词 + 坏词（不足、脱节、滞后） | 名词 + 坏词 | 类名 + 一两个表现词 |
| 作用 / 意义 / 成效 | **效果** | 效果词（拓宽、提升、增收、转正、后继有人） | 领域词或主体 + 作用 | 标签 + 动作串 + 效果词（效果词一个不少） |
| 优势 / 特点 / 表现 / 体现在哪些方面 | **判断** | 名词 + 判断（同源、相近、任务急） | 名词 + 判断，越短越好 | 标签 + 事实 + 半句意义 |
| 启示 | 动作 + 认识 | 别人做对的、做错的、直接对"我"说的 | 动宾 | 标签 + 认识句（抄原话）+ 做法句 |

**效果单位在文章里的三个位置**（保真原理在效果题上的样子）：例子后面的结果句（"远销 80 国"）、群众的反应（"讲给孙子听"）、反面评论反过来（"没有信息化要耗费大量人力物力"）。三个位置都扫一遍。

**人名、数字、故事、情绪**不是单位，读到跳过；数字在做法题和问题题里换成程度词，在成效题里每条留一个，在优势题里作为条件本身保留。

### 第二问：用谁的分组？

分组决定条数和标签的种类。钥匙按顺序找，找到第一个就停：

| 材料的样子 | 分组钥匙 | 条数 |
|---|---|---|
| 总述材料或领导讲话给了对象的分量（五个振兴、生态美产业强文化兴百姓富、管理和服务） | **按分量分**，标签用分量词 | = 分量数 |
| 段落按内容分，一段一件事 | **一段一堆** | = 段数 ± 1 |
| 段落按人、地点、时间分（座谈、走访、日记） | **按"谁做的 × 哪一环"归**，同一件事说了两遍才合 | = 互不重复的事的数量 |
| 材料自己有过渡句划出方面（"不是简单种树""还体现在办公管理""延伸至原材料"） | **按过渡句分** | = 过渡句划出的方面数 |

条数的下限是材料里互不重复的事，上限没有——拆得更细也不吃亏（八问九策 90，九条理解题 90；压成四条泛话 80–84.5，三条 81.5）。两件事同属一个制度域、各自很短的，可以塞进一条共用标签，两件事的词都写；主体不同或类别不同的，各一条。

### 第三问：名字从哪来？

| 材料里有 | 名字 |
|---|---|
| 结构性总结句（"以文兴村，农文旅一体化，游养买一条龙"） | 抄成第一句；感叹句（"整个镇年轻了"）当效果词用，不当总句 |
| 目的句、需求句、评论句（"为了……""迫切需要……""教授说……"） | 抄成标签 |
| 分量词（第二问找到的） | 用分量词 |
| 都没有 | 五个动词（增强、健全、优化、构建、推动）+ 段里反复出现的名词 |

标签 4–8 字，词性和内容一致：把标签和内容用冒号连起来读，内容应该读成标签的一个例子。

### 第四问：预算怎么分？

格子数 × 0.9 ÷ 25 = 目标行数；目标行数 ÷ 条数 = 每条行数，写在骨架旁。每条：标签 + 一层（材料的类名词）+ 二层（材料的具体名）+ 三层（例子、数字）。行数紧，先砍三层，再砍最长那条的最后一个分句，条数保持。写完数格子。

### 两个核对（动笔前十秒）

- **主语核对**：每条动作是不是题目指定的主体做的；农户在响应县里的事写成县里的动作。
- **保真核对**：每个具体名回材料看一眼；"推广 X 经验"回材料看 X 到底做了什么（A 园区做的是风光储，不是绿电直连）。

### 草稿纸上的四问表

```
一问 单位：动作/状态/效果/判断/动作+认识    圈：____
二问 分组：分量/段落/谁×环/过渡句   条数：__（材料里互不重复的事：__）
三问 名字：总结句/目的句/评论句/分量词/动词+名词
四问 预算：格子__ ×0.9÷25 = __行  每条 __行
骨架：
① [标签]  一层/二层/三层
② ...
核对：主语□  保真□  格子数了□
```

## 3. 问题 + 对策的附加程序

问题侧按第 2 节走（单位 = 状态）。对策侧多三步：

**反转**：对策的类名 = 问题的类名反过来（脱节 → 对接，不足 → 强化，滞后 → 推动落地）。类名各出现一次，是给阅卷人对针对性用的。

**手段**：类名后面必须有手段，手段的来源分三档，用完上一档再用下一档：
1. 材料明说的办法——包括座谈里专家给的、同一套卷子别的材料里的正面做法。
2. 材料反推的办法——"以前怎么做错的"反过来；"没人愿意 / 还在摸索"反推成激励或培训；"错过黄金时间"反推成绿色通道、先救后批。
3. 标准手段——培训、平台、机制、专项资金。每堆至多一条，只在前两档用完后。

写出来是问题镜像的（"X 不畅 / 完善 X"），说明没手段，回第二档找。

**具体度**：题干要求"具体明确"时，手段写到工具——无人机巡山、古树数字档案、发传单办讲座、一网通办、以老带新、联合高校定向培养。动词级（"加强宣传""运用科技手段"）拿不到这个分。

**对应与身份**：问题几条对策几条，一是对一是；对策比问题多也行，只要每条对得回某个问题、都是材料来的工具。每条的动词是这个身份能做的（镇：组织、协调、申请；科技局：推动、督促、搭建）。材料里有几户、几个案例，每户每案例各有一条。

题干是"草拟汇报 / 发言提纲"、材料按镇或村走的，按镇或村写，每个下面问题 + 建议或做法（2024 二卷 88，2023 乡镇 84.5）。

## 4. 作文程序：五问

### 第一问：落在哪？（立意）
题干的判断句里圈出 A（要拆的）和 B（每段落到的）。标题含 A，落点用题干的近目标或上层目标都行；近目标在开头一句和至少一句观点句里出现；题干有口号句就带上。

### 第二问：拆哪边？（结构）
材料在拆哪边，你就拆哪边：材料给的是 A 的做法（科技 / 产业 / 绿色 / 体制）→ 按 A 拆，题干引语里 A 的每个分量都要有一段或一句；材料给的是 B 需要什么（产业给乡村带来富、才、美、文）→ 按 B 拆，B 的官方分解每个词都出现。题干有两个落点（"关系长远发展和民生福祉"）→ 两个落点各一大段，或四段但每句观点句点明属于哪个落点。材料六个面合成四段；问题类材料取反成一句"要……"放进对应段；讲镇的材料配给讲镇的段。

### 第三问：每段怎么长？（段落）
观点句 → 道理句 → 三个名词化证据（至多一个数字）→ 收束回 B。观点句优先用材料各面开头的判断句（"生态环境是根基""绿色发展作为生产方式的变革已成为新增长点"），两份 84.5 分卷直接拿它们当分论点；自己的对仗句保留时，这几句当道理句。开头 6 行：引语 → 解题干的比喻或口号 → 靶子或家底 → 预告几件事。结尾 4 行：材料原句或意象 → 各段一个短语 → 上层目标。策论文动词一律"要"，开头抄材料短板句当靶子，每段三个"要"各带一个材料专有名。

### 第四问：材料用够了吗？（保真）
每份材料至少露一次脸；例子每段三个够了，例子少但主题句全用材料也能 90，例子堆得最多的 83 没有更高；材料外的例子只用来补一句联系实际，主体证据全用材料（材料外例子替代材料的 81.5、82；材料没用完的 78.5）。写完核案例：地名、人名、做法三样对上；核判断词：每个指回原句。

### 第五问：格子够吗？（预算）
800–1000 写 36–38 行，1000 左右写 40 行；每写完一段数一次。时间不够先写结尾三行。

### 草稿纸上的五问表

```
一问 A=____ B=____ 近目标____ 上层____   标题：____
二问 材料在拆__ → 按__拆   分量/引语分量：____   段：①__ ②__ ③__ ④__
三问 每段：观点句（材料判断句）____ / 道理 / 证据×3（数字×1）/ 收束
四问 材料露脸 1□2□3□4□5□6□7□8□  案例核对□  判断词核对□
```

## 附录 A：案例样本（支撑不足，查用，不背）

这些是从一两套卷子里来的，能用原理解释但还没验证到第三次。写在这里是为了不丢，不是规则。

- 材料用"最、核心、宝贵、关键"强调的元素单列一条（2022 县级：孙中山）。
- 从规划句反推的问题放尾巴（"正在筹备协会" → 缺协会，2020 乡镇）。
- 当事人自己总结的"最难的三点"直接成特点，个人经历不算（2020 乡镇）。
- 对话里随口一句抱怨算问题证据（"果园信号不好"，2020 乡镇）。
- 启示题：直接对"我"说的那句必须单独一条（2023 乡镇）；每个难题多问"为什么会出现"（2022 乡镇）；多人物一人一条（2021 乡镇）。
- 理解题：写成效的段落也算一条（2021 县级）。
- 成效题：市场主体增长并进经济复苏（2020 县级）。
- 优势题：别篇材料里的条件压成最后一条（2021 乡镇）。
- 同一制度域的两件小事塞进一条（一站式平台并进职业资格互认，2022 县级）。
- 作文：开头有靶子有预告的都在高分段（2023 县级 86.5、2024 二卷 88）。

被推翻过的（记着，免得再捡回来）：堆数四到五个；标题必须含近目标；成效题每条留数字；问题对策必须严格一一对应。

**对答案的顺序**：先对条数（覆盖），再对词（保真），再对分组和标签（对齐），最后对格子（预算）。差异分四类记（漏点多点 / 层级 / 名字 / 例子取舍），名字和例子的差异不改方法。

**改方法的门槛**：一条新的信号要在三套不同的卷子上出现同样的形状才进信号表；一两套的进附录 A。

## 附录 B-2：回忆版卷子（选调）的第 0 步

选调卷没有官方公布，题目和答案都是考生回忆拼出来的，两家拼的可能不是同一份。做题前先做一件事：**把题干里的专有词（"下乡返乡兴乡""G 市""金树林"）回材料里找，找得到才开始做，找不到就换材料版本；对答案前再把答案里的专有名回题目文件的材料找，找不到的那部分不作数。** 2024 选调题目文件的材料 3、4 就是拼错的（大鹏版带完整材料，题干和材料对得上）。除此之外，选调卷的卷面和题干措辞与省考逐字相同，四问五问不用改。

## 边界

方法负责：找全单位、不丢词、分组和起名有依据、对策有手段有工具、作文落点和结构、格子。
方法之外：词汇（词库 + 背）、速度（限时）、一眼看全材料（材料顶上写词、两遍读）、作文语言、时政积累、阅卷的真实清单、阅卷噪声（±2）、我的示范和你的执行之间的差距（只有你做了才知道）。
