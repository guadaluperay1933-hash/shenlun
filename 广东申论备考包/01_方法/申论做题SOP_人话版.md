# 申论做题 SOP（人话版 · 正向流程版）

> 十四套广东真题（2020–2026）盲做对照、55 份真人得分卷校准。括号里的年份和分数是这条规矩的来源。
>
> 这份文件按"遇到什么，就做什么"写：每一步先说手做什么，再列"看到 → 做"。要背的是第 1 节和第 7 节；练题走第 2、3 节；练完按第 5 节对答案；考场上出状况翻第 7 节；第 8 节写这份东西负责什么、别的交给谁。
>
> 前提：广东申论 120 分钟；答题卡每行 25 格，标点占格；拿到卷子先数格子（2026 卷：220 / 320 / 1220 或 1120）。

---

## 1. 五件必做的事（背下来）

**一、字数按格子数。**
限 200 写 7 行（≈175），限 300 写 11 行（≈275），800–1000 写 36–38 行，1000 左右写 40 行，都取格子的九成。一点占一行半，写到第二行一半就收尾。每写完一点看一眼行数；作文每写完一段数一次。（头脑估算普遍偏少 15–30%，十四套定稿校对时六篇作文全超；数出来的才算数。）

**二、草稿只写骨架。**
每点一个 4–8 字的标签加几个两三字的缩写，整句只在答题卡上写一遍。

**三、超了就砍尾巴。**
顺序：数字和例子 → 最长那一点的最后一个分句。每个点都留着。写少了，往最短的点里补一个材料原词。

**四、拿不准就选保险的那边。**
拿不准算不算一个点 → 写上。拿不准该不该合 → 分开写。拿不准例子留不留 → 压成词留着。多写一条最多浪费十几个字，漏一条丢两分（2026 县镇：第一题写七条的 86.5）。

**五、条数跟材料走，可以更细，不能更粗。**
材料里互不重复的事有几件就写几条，通常 4–6；再拆细也不吃亏（八问九策 90、九条理解题 90、六问六策 82–89；压成四问四策泛话的 80–84.5，压成三条的 81.5）。同一件事说了两遍才合成一条。预算不够就把每条写短——类名加一个表现词——条数保持。

## 2. 小题通用流程（概括、对策都走这七步）

### 第 1 步　审题（30 秒–1 分钟）

**手**：题干上圈四样——中心词、主体和身份、字数和要求词、引号里的每一个词。字数换成行数写在题干旁。翻到总述材料看一眼。

| 看到 | 做 |
|---|---|
| 中心词是做法 / 举措 / 经验 | 去找"谁做了什么"的句子 |
| 中心词是问题 / 短板 | 去找"什么不足、什么脱节"的句子 |
| 中心词是作用 / 成效 / 意义 | 去找"对象得到了什么"的句子，效果词优先 |
| 中心词是优势 / 特点 / 表现 | 去找"什么怎么样"的句子 |
| 题干给了主体和身份 | 只收这个主体的动作；对策的动词按身份选（科技局：推动、督促、搭建；镇：组织、协调、申请） |
| 题干引号里有词（"追求质量、打造品牌"） | 每个词都要在答案里出现，各占一条或一句（2023 县级） |
| 要求词有"具体明确" | 对策写到工具级（第 3 节） |
| 要求词有"理解深刻""认识深刻" | 每条带一句认识句，抄材料原话 |
| 总述材料或领导讲话第一句给了对象的分量（五个振兴 / 生态美产业强文化兴百姓富 / 管理和服务） | 按分量分组、按分量起标签（2021 乡镇、2020 乡镇） |

### 第 2 步　扫段（1 分钟，只看首尾句）

**手**：数段，段旁写三个字母：背 / 数 / 评（背景、数据、评论），这三种段落读的时候跳过。

| 看到 | 做 |
|---|---|
| 段落按内容分（一段一个做法） | 段落就是分组，估点数 = 正文段数 ± 1 |
| 段落按人、地点、时间分（日记、走访、座谈） | 记下来"读完要重新归堆"，按"谁做的 × 哪一环"归 |
| 段落很多、字数很紧 | 每点行数 = 目标行数 ÷ 点数，写在旁边 |

### 第 3 步　第一遍读（占这题 40% 的时间）

**手**：
- 做法题圈"动词 + 名词"；问题题圈"名词 + 坏词"；作用 / 成效题圈效果词；特点题圈"名词 + 判断"。
- 每段读完，段旁写一个字母加两三个字。
- 总结句、目的句（"为了……"）、需求句（"迫切需要……"）、人物后面的评论句（教授说、专家说）划波浪线，标"名"——标签住在这些句子里。

| 看到 | 做 |
|---|---|
| 一个动作 / 一个坏状态 / 一个效果 | 圈。只判"是不是这个类型"，重不重要第二遍再说 |
| 人名、数字、故事、情绪 | 跳过，读下一句 |
| 一段写得特别长 | 记"这点多给几个字"，其他念头不起 |
| 材料自己给的总结句（"以文兴村，农文旅一体化，游养买一条龙"） | 标"总"，写的时候抄成总句（2023 乡镇） |
| 材料用"最、核心、宝贵、关键"强调的东西 | 标"单"，单独成一条（2022 县级：孙中山） |
| 对话里随口一句抱怨（"果园信号不好"） | 圈，它是问题证据（2020 乡镇） |
| 反面评论（"没有信息化要耗费大量人力物力"） | 反过来记成效果词：节约人力物力（2021 县级） |
| 群众的反应（"讲给孙子听""果树不长虫了"） | 记成效果词：自发传播、学以致用（2022 乡镇） |
| 有人提建议（"要搭平台"） | 记到对策候选栏，问题栏不动 |
| 规划句（"正在筹备协会"） | 反推的问题（缺协会）记到尾巴栏，把握中 |

### 第 4 步　搭骨架（2 分钟）

草稿纸一行一个点：字母、标签位置空着、后面缩写。名字最后填。

### 第 5 步　第二遍，在骨架上做（3 分钟，看骨架不看材料）

**① 归堆**，钥匙按顺序找：

| 看到 | 做 |
|---|---|
| 对象有官方分量 | 按分量分 |
| 没有分量，段落按内容分 | 一段一堆 |
| 段落按人 / 地点分 | 同一主体、同一件事归一堆；不同主体各一堆 |
| 两件事同属一个制度域，各自很短（一站式平台和职业资格互认） | 塞进一条，共用标签，两件事的词都写（2022 县级） |
| 两件事主体不同或类别不同（产业集聚低 / 硕博培养少） | 各一条（2024 一卷：合了就错） |
| 六个人里三个说的是同一个问题 | 合成一条，写"三个人都说" |

**② 定父子**：能装下所有兄弟的才是父；装不下的就是兄弟，哪怕它那段写了一整页（2025 省市：银行那段是兄弟）。

**③ 起名**，来源按顺序：

| 看到 | 做 |
|---|---|
| 材料有总结句 / 目的句 / 需求句 / 评论句 | 抄，4–8 字 |
| 没有 | 五个动词（增强、健全、优化、构建、推动）+ 段里反复出现的名词 |
| 内容是动作 | 标签也是动作；内容是特点，标签也是特点。用冒号读一遍：标签：内容，内容应读成标签的例子 |
| 材料给了长名（"党支部+公司+基地+农户"） | 长名放标签后第一句 |

**④ 分字数**：每点一行半；例子和数据是三层，行数紧先砍它们。

### 第 6 步　写（占这题 40% 的时间）

**手**：序号 + 标签 + 句号 + 几个短句。问题和对策各一段，段内接着写。每写完一点看一眼行数。

| 看到 | 做 |
|---|---|
| 材料有结构性总结句 | 抄成第一句；没有就直接"一是" |
| 材料里的感叹句（"整个镇年轻了"） | 当效果词用在条目里，不当总句（2022 乡镇） |
| 几个方面 | 平铺几条，每条同一种标签形式（2026 一卷：套二级的那份 77） |
| 主语是农户在响应县里 | 写成县里的动作："平台预警指导荔农浇灌"（2025 县镇） |
| 材料给了主语和平台的原名（供应链平台） | 原名照写 |
| 总结句和例名都有 | 两个都写："总结句 + 例名、例名" |
| 三个并列的四字短语（凝练·吸聚·兑现） | 整体抄；"××就是生命"后面的动作必写（2024 一卷） |
| 做法、问题题里的数字 | 换成程度词（大幅、近九成） |
| 成效题里的数字 | 每条留一个最结论性的，其余换成结果词 |
| 优势题里的条件数字（5000 万、3 公里） | 留 |
| 人名 | 换成身份词（村支书、企业家） |

### 第 7 步　检查（1 分钟）

按这个顺序看：每点有动词 / 坏词吗 → 标签 8 字内吗 → 哪个点其实是另一个点的儿子 → 材料低频词在不在 → 行数数了吗 → "最 / 首位 / 入选 / 全覆盖"每个指回材料原句了吗。

## 3. 分题型（每型只写和通用流程不一样的地方）

### 概括做法 / 举措 / 经验
找"谁做了什么"，主语是题目指定的主体。目的句、效果句用来起名或当尾巴。

### 概括问题
写"名词 + 坏词"。总括性的问题先写，小毛病跟在后面当展开。

| 看到 | 做 |
|---|---|
| 材料里的建议句 | 记对策栏 |
| 材料里的规划句 | 反推的问题放尾巴，把握中 |
| 副作用句（"经费打了水漂"） | 留在问题的展开里，当表现词 |

### 问题 + 对策
- 先按上面找问题。对策的名字 = 问题反过来（脱节 → 对接，不足 → 强化，滞后 → 推动落地）。
- **问题侧写表现词，对策侧写手段**，类名各出现一次给阅卷人对针对性用。

| 看到 | 做 |
|---|---|
| 问题写完只有四个字（"缺乏人才"） | 补一两个表现词："缺运营管理和复合型人才"（写四个字的卷 80–81.5，补了的 84.5） |
| 对策写出来是问题的镜像（"X 不畅 / 完善 X"） | 给真手段（修建机耕道、明确交易规则），给不出就只留问题侧 |
| 材料明说了办法（含同一套卷子别的材料里的正面做法） | 第一优先用（材料 8 的社会资本、材料 6 的集体经济都算） |
| 材料写了"以前怎么做错的" | 反过来写成办法 |
| 材料写了"没人愿意 / 还在摸索 / 不知道怎么办" | 写成激励（试种补贴）或培训（电商技能培训）（2022 乡镇） |
| 材料的办法用完了还差一条 | 自补一条标准手段（培训 / 平台 / 机制），每堆至多一条 |
| 要求"具体明确" | 每条写到工具：无人机巡山、古树数字档案、先抢救后补手续、发传单办讲座、专项资金、绿色通道、以老带新、一网通办（2026 县镇 87–90） |
| 数问题和对策的条数 | 一一对应；对策比问题多也行，只要每条对得回某个问题、都是材料来的工具（四问六策 90） |
| 材料里有几户、几个案例 | 每户每案例各有一条对策（2020 乡镇参考答案整户漏了老刘家） |
| 写完检查主语 | 每条都是这个身份能做的（镇：组织、协调、申请；不是人工增雨） |
| 写完检查出处 | 每个"推广 X 经验"回材料对一遍 X 到底做了什么（A 园区做的是风光储，2026 一卷 80 分卷写成绿电直连） |
| 题干是"草拟汇报""发言提纲"且材料按镇 / 村走 | 按镇 / 村写，每个下面问题 + 建议（2024 二卷 88；2023 乡镇 84.5） |

### 作用 / 意义 / 重要性题
- 每条 = 标签 + 动作串 + 效果词。

| 看到 | 做 |
|---|---|
| 对象有官方分量（乡村振兴） | 领域标签："改善基层治理"（2023 乡镇） |
| 对象没分量、材料按主体排 | 主体标签："青年企业家引领发展"（2023 县级 86.5） |
| 例子 | 留动作，去人名和数字，效果词一个不少（"远销 80 国" → 拓宽市场） |
| 人物后面的评论句 | 当这条的标签 |
| 同一主体层的两种人（企业家和职业经理人） | 合一条，分号隔开 |
| 题干要"观点鲜明" | 开头一句总观点，14 字内，用材料习语拼 |
| 题干只要"概括" | 直接"一是" |

### 优势 / 有利条件 / 特点题
- 元素"名词 + 判断"，标签越短越像特点（任务急 / 任务重 / 挑战多 / 责任大 / 风险高，2020 乡镇）。

| 看到 | 做 |
|---|---|
| 材料自己的总述句（"文化同源、血脉相通，是重要基础"） | 第一条 |
| 做过的事（联合申遗、合作办展） | 当"已有基础"的证据写进条目，标签用判断词 |
| 当事人总结的"最难的三点" | 直接成三个特点 |
| 当事人的个人经历（城里长大第一次见过年） | 跳过 |
| 别篇材料里的条件（另一篇的产业基础、网红渠道） | 压成最后一条写短（2021 乡镇） |
| 每条 | 标签 + 事实 + 半句意义 |

### 成效 / 效果题
标签"名词 + 变好的动词"（复苏、回稳、减轻、提速）。

| 看到 | 做 |
|---|---|
| 结果词（转正、第一、量质齐升） | 一定写 |
| 数字 | 每条留一个 |
| 材料里的做法（减免社保） | 做法当主语、结果当谓语："减免社保惠及 29 万家" |
| 市场主体增长 | 并进经济复苏 |
| 同一材料里两件事（商事秒批、知识产权保护） | 各一条（2020 县级两家答案一致） |

### 理解题（"密码 / 秘诀 / 关键"）
第一句解比喻（"密码"是 G 市加强科技创新的一系列做法），再分条，分条同做法题。

| 看到 | 做 |
|---|---|
| 讲做法的段落 | 每段一条 |
| 写成效的段落（无人工厂效率提升） | 也算一条，它是"企业应用创新"这个做法（2021 县级；九条的那份 90） |

### 启示题
每条 = 标签 + 认识句（抄原话）+ 做法句。

| 看到 | 做 |
|---|---|
| 会议对话 | 一个发言人的话题一条 |
| 别人被指出的错（预案疏漏、出动慢） | 反过来写成做法 |
| 直接对"我"说的那句（"提高思想觉悟"） | 必须单独一条（2023 乡镇） |
| 一个难题 | 多问一句"它为什么会出现"：挖掘机难请是因为全县同时复耕 → "增强预见性"再一条（2022 乡镇） |
| 多个人物 | 一人一条，品质当标签，做法收全，末尾一句深一层；品质相同的两人合一条（2021 乡镇） |
| 写完检查身份 | 每条都是"我"这个身份能做的（定处罚标准、加强队伍建设是领导的事，改成"我要……"） |

### 发言提纲 / 汇报
标题 → 开头一句总述 → 主体分条 → 结尾一句（用材料里领导的总结句）。每条 = 标签 + 一句做法 + 半句例证。

| 看到 | 做 |
|---|---|
| 材料按村 / 镇走 | 按村 / 镇写，每个下面做法或问题 + 建议 |
| 材料按主题走 | 按主题写 |

### 大作文（议论文 / 策论文）

**审题**

| 看到 | 做 |
|---|---|
| 题干判断句 | 圈出 A（要拆的）和 B（每段落到的） |
| 标题 | 含 A，落点用近目标或上层目标都行（2025 省市最高两份都落"高质量发展"）；题干有口号句（"站在新起点，迈向新征程"）就带上 |
| 近目标 | 开头一句、至少一句观点句里出现 |
| B 再往上的目标（中国式现代化） | 只放开头结尾 |

**拆哪边**

| 看到 | 做 |
|---|---|
| 材料给的是 A 的做法（科技 / 产业 / 绿色 / 体制） | 按 A 拆；题干引语里 A 的每个分量都要有一段或一句 |
| 材料给的是 B 需要什么（产业给乡村带来富、才、美、文） | 按 B 拆；B 的官方分解每个词都要出现（五个振兴全覆盖，段数不够两两合并） |
| 题干有两个落点（"关系长远发展和民生福祉"） | 两个落点各一大段；或四段但每句观点句点明属于哪个落点；开头末句、结尾各点一遍（2026 县镇 90×3） |
| 材料按面走（硬联通 / 软联通 / 平台 / 人文 / 绿色 / 辐射） | 两两合成四段 |
| 问题类材料（零碳园区短板） | 取反写成"要……"放进对应段，一句带过 |
| 讲镇的材料、讲村的材料 | 各配给讲镇、讲村的那一段（2024 二卷） |

**写**

| 看到 | 做 |
|---|---|
| 材料各面开头的判断句（"生态环境是根基""绿色发展作为生产方式的变革已成为新增长点"） | 当观点句或道理句（2026 一卷两份 84.5 直接用作分论点） |
| 开头 6 行 | 引语 → 解题干的比喻或口号 → 靶子或家底（至多一个数字） → 预告几件事（2023 县级 86.5、2024 二卷 88） |
| 每段 7–8 行 | 观点句 → 道理句（怎么导致的）→ 三个名词化证据、一个数字 → 收束回 B |
| 例子 | 每段三个够了；例子少但主题句全用材料也能 90（2021）；材料外的例子只用来补一句"联系实际"，主体证据全用材料（材料外例子替代材料的 81.5、82） |
| 八份材料 | 每份至少露一次脸（没用完的 78.5） |
| 结尾 4 行 | 材料原句或意象 → 四个方面各一个短语 → 上层目标 |
| 策论文 | 动词一律"要"；开头抄材料短板句当靶子；每段三个"要"，各带一个材料专有名 |
| 题干含"经验" | 观点句写成规律句，收束"经验是：……"，实效仍做证据 |
| 排比（货币补偿、物业安置、土地空间置换） | 整体抄 |
| 写完 | 核案例：地名、人名、做法三样对上（番薯节是 K 镇）；核判断词："最 / 首位 / 入选"每个指回原句；每段数格子 |

### 原因 / 影响 / 应用文（简）
原因往上游找，影响往下游找。应用文 = 同一套找点 + 格式框。

## 4. 起名手册

来源顺序：材料总结句 / 目的句 / 需求句 / 评论句 → 五个动词 + 反复出现的名词 → 问题题"名词 + 不足 / 缺乏 / 脱节 / 滞后 / 短板" → 对策题把问题反过来。标签 4–8 字，词性和内容一致。完整词表在《SOP 之外》第 4 节，考前背。

---

## 5. 练习时怎么对答案

**写答案之前**：预登记三条——哪个点不确定算不算、哪个名字是自己造的、哪两个点不确定该不该合，各标把握（高 / 中 / 低）。

**对照时**

| 看到 | 做 |
|---|---|
| 漏点、多点 | 回第 3 步看圈法 |
| 层级不同 | 回"装得下" |
| 名字不同 | 记样本，规则不动 |
| 例子取舍不同 | 两家一致才动 |
| 参考答案比材料少了低频词、合掉了材料点名的类别、自补挤掉了材料办法、作文证据薄 | 记它的扣分，保留自己的（机构答案按 80–85 对待：背它逐字写的两份真人卷 80 和 83.5） |
| 两家答案 | 一致处才改，不一致处按本 SOP（2020 县级） |
| 真分数卷 | 比机构答案值钱；两分以内的差别当阅卷浮动；三份以上同向才改规则 |
| 改一条规则 | 写一句对下一题的预测，落空两次就撤回 |

**参考答案的固定风格**（十二套总结）：学它的标签 4–6 字、效果尾巴、一一对应、一人一条；自己保留标签里的具体名、例名、问题侧表现词、材料办法、作文证据、字数、案例核对。

---

## 6. 考场时间表（120 分钟）

三题卷：0–3 分钟读题干、每份材料顶上写一个词；问题一 20；问题二 30；大作文 55（审题定分论点 7、开头 5、每段 8、结尾 3、检查 3）；机动 12。
五题卷：分值定行数定时间——15 分题 15 分钟，20 分题 22 分钟，30 分题 35 分钟；一题一材料。

## 7. 出状况了怎么办

| 状况 | 做 |
|---|---|
| 写超了 | 小题砍最长那条的最后一个分句，作文砍最后一个证据；一条横线划掉 |
| 想不出名字 | 看段首段尾抄总结句；没有就五个动词加反复出现的名词；三十秒到，先写"一、"空四格写内容，最后回来填 |
| 材料读不完 | 大作文只读每份材料的第一段、最后一段和顶上那个词，中间段写到哪段翻哪段 |
| 拿不准算不算一个点 | 写 |
| 拿不准该不该合 | 分开 |
| 拿不准主体是谁 | 分开写 |
| 作文时间不够 | 先写结尾三行，再补中间 |
| 发现前面写错了一个点 | 在后面把正确的关键词带上，前面的字留着 |

## 8. 这份 SOP 负责什么、别的交给谁

**这份 SOP 负责（十四套真题、55 份真人卷验证过）：**
1. 找全采分点：什么算一个点、怎么归堆、条数怎么定、标签从哪抄。
2. 词不丢：材料点名的类别词、低频专有词、排比、效果词、题干引号词，每一类都有一条"看到 → 做"。
3. 结构判断：对策和问题的分工、作文拆哪边、多落点怎么写、材料怎么对位。
4. 对策的来源和形状：从材料来、写到工具、一一对应、按身份选动词。
5. 字数和格子：按行数写、按格子数、超了砍什么。
6. 练习方法：预登记、对照分类、参考答案怎么用、真分数怎么用。

**交给《SOP 之外》和练习的：**
1. 词汇——标签词、官方分量、效果词、对策工具，在《SOP 之外》第 4 节，要背。
2. 速度——圈词、归堆、起名的速度，限时练。
3. 一眼看全材料——我一次装下八份，你用"材料顶上写一个词"和两遍读法替代。
4. 作文的深一层——解比喻、机制句、把做法说成规律，靠阅读和理解力。
5. 时政和政策积累——材料外那一句联系实际。

**这份 SOP 不知道的：**
1. 阅卷的真实采分清单——这里的一切是从参考答案和 55 份真分数反推的。
2. 手写、卷面、心理、体力。
3. 没练过的题型——原因、影响、应用文只有一句话。
4. 我的示范和你的执行之间的差距——只有你掐时间盲做一套、和高分卷对过才知道。
