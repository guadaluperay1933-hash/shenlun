**预登记结果**：(a) 五条 ✓；(b) "金树林"不只收变现举措——机构答案也收了制度、监管、修复 ✓；(c) 效果句不当尾巴 ✓。

## 4. 第三题　海洋强省建设（只能看结构）

| 原理 | 范文一 / 范文二 | 我的盲做 | 判断 |
|---|---|---|---|
| 覆盖 | 都是三段：产业布局 / 科技创新 / 生态保护；资源产业集群 / 产业升级 / 生态保护。没有开放、文化 | 四段：产业强海 / 科技兴海 / 生态护海 / 开放活海文化亲海，五个"海"全在 | 它那版材料可能没有材料 6、7；按题目文件的材料，漏开放和文化就是两份材料没露脸 |
| 保真 | 例子密（极地号、惠州风电、联塑、湛农、揭阳网箱），但都不在题目文件的材料里 | 例子全从材料 2、3、5、6、7 来 | 版本问题，不比 |
| 对齐 | 标题《以海洋强省建设，铸就广东蓝色辉煌》《深耕蓝色经济，绘就广东海洋强省新画卷》含 A，落点"蓝色辉煌 / 新画卷"是自造词，题干引语"海上新广东""蓝色动力"没用；开头没靶子；观点句"优化布局 / 推动科技 / 加强保护"是动词级 | 标题含"海上新广东"，开头有材料 1 的"两个不高不强"当靶子，观点句用五个"海" | 落点用题干引语、开头有靶子，是十四套省考里高分卷的形状；范文这两处都没做 |
| 预算 | 约 900 字 | 965 字 | 无差 |

**取用**：范文的三段结构（产业 / 科技 / 生态）证明按 A 拆、按分量分是对的；它们没有开放和文化，是它那版材料的事，不是分法的事。范文的落点自造（蓝色辉煌）、开头无靶子，不学。
**预登记结果**：(a) 三段四段都可以，段数不是变量；(b) 分量用五个"海"还是"产业 + 支撑"——范文用的是产业 / 科技 / 生态三块，和五个"海"的前三个重合，未决；(c)(d) 无从对。

**能信的**：第一题的五个类别（和我一致）；第二题的形状（一问一策、表现词、工具级）；第三题按分量分段。这三样和十四套省考里高分卷的形状一致，说明选调的评分标准和省考同源。
