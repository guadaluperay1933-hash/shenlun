# 2021 广东省考申论 乡镇卷 · 答卷

## 问题一
### 解题过程
四问表：
- 一问 单位：中心词"作用"→ **效果**单位。轴 = 乡村新闻官 + 推动农业农村发展。要求词只有"紧扣材料、分析全面、表达准确"，没有"观点鲜明"，所以不写总观点句，直接"一是"起。圈法按 3.1 的效果词四位置扫材料 3：例子后的结果句（"2 万多斤葡萄销售一空""游客量激增""价格销量都涨了不少""播放 100 多万次"）、群众/平台的反应（"不少人找到她联系农科院专家""市里助农电商平台邀请她推广"）、人物后的评论句（吴委员"乡村代言人，有影响力、引导力""乡风文明的大喇叭"）。唐书记本人被评"十佳"、20 万粉丝是她的影响力基础，不是农业农村发展的效果，不收。
- 二问 分组：钥匙①对象"农业农村发展"材料没给官方分量；钥匙②无过渡句；材料 3 按唐书记做的一件件事排（钥匙③），按"谁做的 × 哪一环"归，互不重复的事 5 件：宣传人居环境政策 / 带货增收 / 推广农业技术 / 推介旅游资源 / 传播乡风文明。**五条**。
- 三问 名字：吴委员的评论句是标签来源（"乡风文明的大喇叭"）；其余用"五个动词 + 段里反复的名词"配：宣传政策 / 拓宽销路促增收 / 推广农业技术 / 推介乡村旅游 / 培育文明乡风。标签是"领域 + 作用"型，和"效果"单位对齐。
- 四问 预算：200 × 0.95 ÷ 25 ≈ 7.6 行，五条各一行半。作用题的效果词不砍，砍的是人名（唐书记、吴委员）和多余数字；数字只留"播放百万次"一个（结论性最强）。实际写 196 字。
### 答案
一是宣传政策。用大喇叭播报门前三包、垃圾投放、家禽圈养，推动人居环境整治。二是拓宽销路促增收。短视频推介葡萄播放百万次，经电商售罄、游客激增；受邀在助农平台推广红薯、蜂蜜等，价升量增。三是推广农业技术。与农科院合拍果木嫁接、病虫害防治视频，牵线专家解难题。四是推介乡村旅游。宣介山水、民族文化、节日、手工艺品和美食，吸引游客。五是培育文明乡风。当乡风文明"大喇叭"，把村规民约编成顺口溜传播。

- 三问 名字：类名反转——排查漏点→全面排查隐患；装备损坏→配齐管好装备；护林员新手→建强护林队伍；村民意识淡薄→宣传引导群众；形势严峻→完善应急联动。
- 四问 预算：200 × 0.95 ÷ 25 ≈ 7.6 行，五条各一行半。手段来源分档：一档（材料明说）为空，材料里没有人给办法，五条全是二档反推（教程 4.2 第二步二档：从"漏掉了这个点""没来得及修""没经过培训""不熟悉地理环境""以为不会有多大问题"反过来写成手段），工具级词用词库的岗前培训、以老带新、划片包干、台账、传单、大喇叭、联训联演。实际写 193 字。
### 答案
一是全面排查隐患。偏远和村庄周边山林一并排查，不留死角，建台账整改。二是配齐管好装备。及时维修损坏风机，增配灭火工具，定期保养、专人管理。三是建强护林队伍。对新护林员岗前培训、以老带新，学会操作装备、熟悉地形；划片包干，加密巡山。四是宣传引导群众。用大喇叭、传单宣传用火规定，禁烧秸秆、推广综合利用。五是完善应急联动。干旱大风天加强值守预警，健全预案，组织镇村、林业站、消防队联训联演。

## 问题三
### 解题过程
四问表（题型按 5.5 优势/有利条件）：
- 一问 单位：**判断**（名词 + 判断）。轴 = 打造松岗—沙坪—红山乡村旅游示范片区 + 有利条件。圈"名词 + 判断"：山清水秀、不足 3 公里、历史悠久、示范村、主导产业、都支持、样样都有。数字按 3.1 的表：条件类数字（5000 万、不足 3 公里、7 万多亩）留，结果类数字砍。徐书记"设计得不错，吃、住、玩、购样样都有"是评价句，压成条件里的半句意义。
- 二问 分组：主材料 4 按走访的三个村排（钥匙③），但"有利条件"不能按村分——按村分会把同一类条件切碎；按"条件的类别"归：自然生态 / 区位交通 / 人文资源 / 新农村基础 / 产业支撑 / 规划配套 / 群众支持 / 政策资金与市场。**八条**。按 5.5 的规矩，别篇材料的条件压成最后一条写短：材料 2（山区镇、山清水秀、荔枝主导产业全产业链、乡村振兴重点谋划）和材料 3（乡村休闲旅游成风尚、乡村新闻官推介）并进第一、五、八条。
- 三问 名字：标签越短越像特点，用"名词 + 判断"三到七字：生态好 / 交通便 / 人文独特 / 有示范基础 / 产业强 / 规划配套全 / 群众支持 / 政策市场好。
- 四问 预算：300 × 0.9 ÷ 25 ≈ 11 行，八条每条不到一行半，所以每条只留"标签 + 事实 + 半句意义"，例子压成名词串。原稿 386 字，按 8.3 第 3 条砍最长条的末尾和三层（"车程 5 分钟""葡萄""绿树成荫""县镇领导重视"），条数不动，压到 294 字。
### 答案
一是生态好。山清水秀，松岭河清澈见底，两岸原生态草木、荔枝林连片。二是交通便。松岗村距高速路口不足3公里，红山村靠近镇区、人流量大。三是人文独特。松岗老寨按八卦布局、石头垒砌，村民已迁新寨，可改造民宿。四是有示范基础。沙坪村是首批新农村示范村，白墙黛瓦、广场宽敞，参观者多。五是产业强。荔枝主导产业种加销全链条发力，黑山羊、鸡鸭、河鲜等物产丰富。六是规划配套全。3村串成闭环线路，碧道、自摘园、农家餐厅、特产街配套，吃住玩购齐全。七是群众支持。村民赞成石头房改民宿、交专业团队管理、利润五五分成。八是政策市场好。列为乡村振兴重点项目、投5000万元；乡村旅游成风尚，"乡村新闻官"助推介。

## 问题四
### 解题过程
四问表：
- 一问 单位：**动作**（做法/主要做法）。主语必须是松岭镇（镇政府、镇干部、村干部），企业自己做的事要写成"镇推动/协助"。轴 = 春节期间 + 引导就地过年 + 服务保障。圈动词 + 名词。
- 二问 分组：材料 6、7、8 三篇日记按日期排（钥匙③），按"谁做的 × 哪一环"归，互不重复的事 7 件：①开会部署 ②联系在外村民劝导就地过年 + 返乡人员登记摸查 ③防疫宣传检查、喜事缓办、不加码不封路 ④走访企业保障留岗员工、派发年货大礼包 ⑤走访慰问留守儿童和独居老人、志愿服务队上门 ⑥市场超市保供稳价 ⑦舞狮、花街、拜年转线上留住年味。**七条**。②里"倡导留在当地过年"和"返乡人员登记管理"是同一天同一件工作的两面，合一条；③里的"不层层加码、不擅自封路"是欧书记明说的要求，是服务保障的一面，必须留。
- 三问 名字：欧书记、镇里的要求句当标签来源（"倡议喜事缓办、宴席不办""不能层层加码""不能少了年味"）；其余用动词 + 名词：加强部署 / 引导就地过年 / 抓实防控 / 保障留岗员工 / 慰问帮扶 / 保供稳价 / 留住年味。
- 四问 预算：300 × 0.9 ÷ 25 ≈ 11 行，七条各一行半略少。人名（小新、刘婶、罗书记、欧书记）全砍，只留身份（留守儿童、独居老人）；数字一个不留。原稿 352 字，按顺序砍三层和最长条的末句，压到 292 字。
### 答案
一是加强部署。召集镇干部和村书记开会，部署春节防控和就地过年服务保障。二是引导就地过年。村干部逐一联系在外村民，宣讲返乡政策、劝导就地过年；做好返乡人员登记摸查。三是抓实防控。宣传车播防疫知识，带队到村检查，倡议喜事缓办、宴席不办，不搞非必要聚集，不层层加码、不封路。四是保障留岗员工。走访企业了解员工就地过年情况，推动食堂开放、备年货；协助派发"年货大礼包"。五是慰问帮扶。为留守儿童送玩具零食、陪伴聊天，为独居老人送春联年货、打扫卫生，党群志愿服务队上门服务。六是保供稳价。检查市场超市，了解品种、价格、备货，督促补货。七是留住年味。舞狮录成视频线上展播，花街游行、拜年改在线上。

## 问题五
### 解题过程
四问表（题型按 5.7 启示题）：
- 一问 单位：**动作 + 认识**。身份是小江（镇党政办新人、驻点村干部），写完逐条检查"这是不是我能做的"。要求词"理解深刻"→ 每条带一句认识句，尽量抄材料原话："一头扎进了基层工作""多一事不如少一事""再大的困难也要解决""力求让每个干部都弄清楚""钻研政策、钻研荔枝""了如指掌"。
- 二问 分组：材料 9 按发言人排（钥匙③），一人一条，品质当标签，**做法收全**（不跨人按品质重排，那样会丢一半做法）。刘副主任和赵副镇长品质相同（钻研业务、吃透情况），按 5.7 的合并例外合一条，两人的词都写。**四条**：刘涛 / 陈书记 / 东哥 / 刘副主任+赵副镇长。
- 三问 名字：标签写成"态度 + 方法"的并列式（3.5 补丁：同一件事里的态度和方法合一条）：转变思想扎根基层 / 敢于担当迎难而上 / 深入群众抓好落实 / 勤学钻研精通业务。
- 四问 预算：400 × 0.9 ÷ 25 ≈ 14 行半，四条各三行半，末尾留半行写深一层的收束句。启示题的认识句不砍，砍的是人名和铺垫（"家在市里""2018 年考了选调生""农校毕业"压成"自学提升学历"）。原稿 433 字，压到 381 字。
### 答案
一是转变思想，扎根基层。初到岗位不习惯、感到茫然，要主动请教领导同事，尽快转变角色，一头扎进基层工作；深入了解村情民情，和老农一起施肥喷药、研究果树种植，勤于思考提新方法，自学把种植新技术介绍给果农。二是敢于担当，迎难而上。对群众有利的好事，不能"多一事不如少一事"，再大的困难也要解决；像建文体广场那样，反复上门做通拆迁户、占地户、小作坊的工作，跑镇跑县依规走程序，把实事办成。三是深入群众，抓好落实。挨家进户拉家常，了解群众所想所盼、熟悉村情；及时把上级决策部署传达给村干部，力求每人弄清楚，结合实际落实措施，带动干部做好人居环境整治、消防安全、山林防火。四是勤学钻研，精通业务。自学提升学历本领，"钻研政策、钻研荔枝"，把"三农"政策和农业技术弄懂弄通，对全镇荔枝种植了如指掌；围绕荔枝产业三年行动计划钻研，提出发展方案。我要以他们为榜样，沉下心、干实事。
