# 电子老师 · 广东申论做题法完整教程（审核修订版 v2）

> 这份文档只做一件事：把备考包里那套方法（四条原理、小题四问、作文五问、对策附加程序、信号表、训练方案、词库）嚼碎了讲给你。原文写得短、写得省，我把每条规矩背后的"为什么""怎么判""长什么样"补出来，散落在十四套重写末尾的补丁归到它该在的位置。原包里的方法文件、答案本、重写文件一个字没动。
>
> 它是自足的：学方法只读它；练题时再去翻《04_答案本》对条数和词、翻《02_真题重写》对分组和名字。审核发现了什么，第 12 章有清单，证据在同目录的《00_审核记录》。
>
> 标记的意思：【例】是真题；【补】是原文里散落在别处、这次归位的补丁，或审核后加的说明；【待验证：n 个样本】是只有一两个样本的经验，照着做没坏处，别当铁律；【为什么】是这条规矩从阅卷机制推出来的理由——原包的要求是每条规矩都得能推出来，推不出来的只算样本。

## 0. 怎么用这份文档

### 0.1 最低成本路径

**第一遍（约 90 分钟）**：读第 0、1、2、3、4 章和第 11 章"考场一页纸"。目标是看懂"为什么这么做"和"手上做什么"。

**第二遍（一个晚上）**：拿 2026 县镇卷的题目，读第 3、4、6 章里的三个【例】和第 5.11 节的五道例题；再翻开《02_真题重写》里 2026 县镇卷那一篇——每道题下面有一张和本文 3.6 同样式的四问表，右列"材料依据"写的是这一条抄自材料第几段哪句话。这一遍你要能回答：遇到这种材料为什么这么分、名字为什么这么起。

**第三遍（开始练）**：按第 9 章的训练表练。练之前读第 5 章对应题型那一小节，练完按第 9 章对答案。第 7 章信号表和第 10 章词库是练的过程中反复翻、翻到熟的东西。

**考前一周**：只背第 11 章一页纸和第 10 章词库。

**一句话版本**：答案就是材料沿着题干那条"轴"（见 0.2）的压缩。找全、抄准、分对、写够、不超。

### 0.2 本文的专用词（先认一遍，后面不再解释）

| 词 | 意思 | 例 |
|---|---|---|
| **单位** | 材料里能单独算一个采分点的最小一件事。问做法时是一个动作，问问题时是一个坏状态，问作用时是一个效果，问特点时是一个判断 | "建冷链仓"是一个动作单位；"人才缺乏"是一个状态单位 |
| **标签** | 每条开头那个 4–8 字的名字，"一是××。"里的××，阅卷人靠它定位清单上的类名。本文说"类名"就是标签；"类名词"指材料里给这类事的统称，写在标签后面的第一句 | "一是厂区生态绿。"里的"厂区生态绿" |
| **轴** | 题干的中心词加限定语划出的那条线。轴上的东西一个不漏，轴外的不收 | "科技赋能农业存在的问题"：轴 = 科技赋能 + 问题。竹林收益低是问题但不在科技这条轴上，不收 |
| **分量** | 官方文件或领导讲话把一个大概念固定拆成的几个组成部分 | 乡村振兴 = 产业、人才、文化、生态、组织五个振兴；绿美广东 = 生态美、产业强、文化兴、百姓富 |
| **堆 / 条 / 点** | 一个意思：分组后的一组材料，写出来就是答案的一条 | "一段一堆"= 一段写成一条 |
| **三层** | 每条答案的三层：一层是材料的类名词，二层是材料的具体名，三层是例子和数字 | ① 厂区生态绿【标签】｜绿化厂区【一层】｜乡土阔叶树、垂直绿墙【二层】｜5000 多株、吸碳降温【三层】 |
| **镜像** | 对策整条只有类名反转、后面没有任何手段 | 问题"审批不畅"，对策只写"畅通审批"——阅卷人看不到你要怎么畅通 |
| **落点 / 近目标 / 上层目标** | 落点 = 每段结尾归结到的目标；近目标 = 题干判断句里直接写出的 B；上层目标 = 比 B 再高一层、题干没写但材料反复提的 | 2025 省市卷：近目标"新质生产力"，上层"高质量发展"，再上"中国式现代化" |
| **靶子 / 家底** | 靶子 = 材料点出的短板，作文冲着它写；家底 = 材料罗列的既有成绩和资源 | 靶子："关键核心技术受制于人"；家底："绿色工厂数量全国首位" |
| **写残 / 写空 / 套二级** | 写残 = 一条只有标签或一个短语，具体名没写出来；写空 = 用自己的概括词替换了材料词；套二级 = 材料平铺五个方面，你硬造一个总标签再往下分小点 | 用"绿色景观"替换"乡土阔叶树、垂直绿墙"是写空 |
| **预登记** | 练题时的动作：写答案前先在草稿上写三条自己没把握的点，各标高 / 中 / 低。考场不做 | 见 3.5.1 |
| **效果尾巴** | 条目末尾那半句效果词 | "……，带动农户增收" |

### 0.3 本文引用的四种答案和卷名

**四种答案**：（1）**真人卷**——备考包收集的真实考生答卷，附考试总分；本文写"90 分卷"就是其中一份总分 90 的答卷。（2）**机构参考答案**——培训机构公布的参考答案（2020 县级卷有两家，本文说"两家"就指这两份）。风格固定，短板也固定（见 9.3）。（3）**定稿**——备考包作者按本方法写的答案，收在《04_答案本》。（4）**材料原文**——四者冲突时以它为准。另外，"盲做"= 电子老师不看任何答案先做的一稿；本文说"盲做时……"，都是指它那一稿出的错。

**卷名怎么读**：广东省考申论每年出两套卷——面向省直、市直岗位的一套和面向县、镇岗位的一套。2023 年以前叫"县级卷 / 乡镇卷"，2025 年起叫"省市卷 / 县镇卷"；2024 和 2026 年本文有时按公布顺序简称"一卷（= 省市 / 县级）、二卷（= 县镇 / 乡镇）"，2024 另有"三卷"（行政执法类岗位）。"选调卷"是选调生考试，题型相同，2024 年起才有申论（2021–2023 只有客观题）。

**三题卷和五题卷**：2024 年起省市卷、县镇卷都是三题卷（两道小题 + 一篇作文，分值 20 / 30 / 50）；2023 年以前的乡镇卷是五题卷（四道小题 + 一篇短作文或提纲，各题分值不等）。

**字数口径**：本文和《04_答案本》里的字数全部程序核数、含标点和序号，直接等于占的格子数。带"约"的字数只在 06 历史目录里出现，不拿来对。

## 1. 阅卷是怎么给分的（所有规矩的来源）

先讲机制，因为后面每一条规矩都得能从这里推出来；推不出来的都只是样本。

**先声明一句**：阅卷的真实采分清单没人见过。下面说的机制，是从十二套机构参考答案和 55 份带真分数的卷子反推出来的，和公务员考试的通行阅卷办法一致。

**小题是踩点给分。** 出题人从材料里划出若干"采分点"，通常四到六个，每个是材料里的一句话或一个词组。阅卷人手里拿着这张清单，在你的答案里找：找到一个给一个的分。他一份卷子只看几十秒，看的不是文采，是"有没有这个词"。

由此推出三件事：

1. **采分点是材料的压缩，所以答案也应该是材料的压缩。** 用材料自己的词，覆盖材料里的每个单位。你自己造的漂亮词，清单上没有。
2. **清单里一条是一条。** 你把两条合成一条，阅卷人可能只给一条的分；你多写一条不在清单上的，通常不扣分，只是浪费格子。所以：细分不吃亏，合并一定吃亏；漏一条丢两分，多一条最多浪费十几个字。
3. **格子是硬约束。** 超出格子的字写不下，写在格子外的不算。

**作文是分档给分。** 阅卷人先看两样东西定档：有没有落在题干那句判断上（立意），分论点清不清楚（结构）。定了档，再按论证和语言在档内上下浮动几分。所以观点句落在题干的判断上，比多举两个例子值钱。

**两个人独立评，分差超过阈值才请第三人。** 同一份答案在两个阅卷人手里差两三分是常态：2024 二卷七份真人卷里六份结构几乎一样、挤在 82–83.5（另一份按镇写的 88）；2026 一卷四份 80 分卷结构各异。所以对答案时，两分以内的差别不下结论。

**一句人话总结**：阅卷人是在你的答案里"找词"，不是在"读文章"。你要做的是让他一眼找到清单上的词，并且不要让他找不到。

## 2. 四条原理（背下来，每条一句检验）

四条之外没有第五条。后面所有程序和信号，都是这四条在不同材料上的样子。

### 2.1 覆盖：材料里沿着题干这条轴互不重复的单位，有几个写几个

- **说人话**：题干问"做法"，材料里有几件不同的事，你就写几条。多少的标准是"互不重复的事"。
- **检验**：数一遍材料里的单位，答案的条数应该等于它，或者比它更细。
- 【例】2025 省市卷第二题，材料 5 六个人发言，说了六件互不重复的问题。机构参考答案压成三个问题三条对策；真人卷里写六个问题六条对策、五问五策的是 82 和 82.5，写四问四策泛话的是 80 和 80.5。（问题 + 对策题的程序见第 4 章。）
- **常见违反**：为了标签整齐把两件不同的事合成一条——2024 一卷"产业集聚低"和"硕博培养少"合成"人才和产业集聚不足"，合了就错，因为两件事的对策分属两个部门。

### 2.2 保真：用材料自己的词

- **说人话**：材料里的低频专有名（"气调保鲜移动集装箱""揭榜领题""股贷债保"）、排比、总结句、判断句，原样搬；主语和平台名用原名；"最、首位、入选、全覆盖"这种判断词，每个都能指回材料原句。
- **检验**：标签词可以来自词库；标签后面的内容里，凡带地名、机构名、产品名、平台名的名词必须能指回材料。只核这类专有名，不核"机制、平台"这种通用词。
- 【例】2026 省市卷第二题，一份 80 分卷写"推广 A 园区绿电直连经验"。材料里 A 园区做的是"风光储一体化"，绿电直连是 B 园区想做还没做成的——张冠李戴。
- **常见违反**：加码（材料说"多个海湾入选"，写成"Z 市海湾入选"）、自补（材料没说的"专班""基金"）、把材料里的意象当标签（"让企业把腰杆子挺起来"不是标签，"支持企业做主角"才是）。

### 2.3 对齐：按题干的轴和材料自己的组织方式分组、起名

- **说人话**：题干问什么（做法 / 问题 / 作用 / 特点），你的每一条就是什么；材料怎么分的，你就怎么分。材料常见三种分法：总述给的分量（"五个振兴"）、段落分法（一段一件事）、人物分法（一个人一件事）。标签和内容读起来要是同一种东西：做法题的标签是动作，特点题的标签是判断。
- **检验**：把标签和内容用冒号连起来读，内容应该读成标签的一个例子；分组用的是材料里已有的分类。
- 【例】2023 乡镇卷"人才在乡村振兴中的作用"：总括材料把乡村振兴拆成发展、建设、治理，参考答案按领域分五条（治理 / 产业 / 文化 / 增收 / 生态）。2023 县级卷"青年人才对制造业的作用"：对象没有官方分量，材料按人物类型排，就按主体分（企业家 / 技能人才 / 研发人才 / 专业服务人才）。同是"作用"题，一个按领域一个按主体，依据都是材料自己的组织方式。
- **常见违反**：材料明明平铺五个方面，你套一个二级结构（"理念绿"下面套四项）——2026 一卷（省市卷）一份总分 77 的真人卷，第一题就是这么丢的。

### 2.4 预算：格子是硬约束，按格子写，写完数格子

- **说人话**：先算目标行数（3.4），行数不够先砍例子和数字——它们是每条的最外一层。写完一定要数，不要估：头脑估算普遍偏少 15% 到 30%。
- **检验**：写完数格子。
- 【例】2026 卷答题卡：第一题 220 格、第二题 320 格、作文 1220 格（省市）或 1120 格（县镇），每行 25 格。
- **常见违反**：作文写到 1100 多字（2026 一卷 80 分卷，作文最强、总分最低）；第二题写到 337 字、320 字（2026 二卷两份卷子，都超了 300）。

### 2.5 方法的边界（原文"边界"一节）

**方法负责**：找全单位、不丢词、分组和起名有依据、对策有手段有工具、作文落点和结构、格子。

**方法之外，要靠你自己攒**：词汇（第 10 章，背）、速度（第 9 章，限时）、一眼看全材料（3.0 顶上写词 + 3.0.5 两遍读）、作文的语言和深一层（解比喻、机制句、把做法说成规律——靠阅读和理解力）、时政和政策积累（作文里材料外那一句"联系实际"从这来）、阅卷的真实清单、阅卷噪声 ±2、示范和你的执行之间的差距（只有你做了才知道）、手写卷面心理体力、没练过的题型（原因 / 影响 / 应用文只有一句话）。

## 3. 小题程序：四问一表

每道小题，在草稿纸上回答四个问题，答完再动笔。四问填完就是骨架，骨架上写整句。

### 3.0 开考前五分钟（先做，再看第一题）

| 步 | 做什么 | 时间 |
|---|---|---|
| 1 | 翻到答题卡，记下三题的格子数 | 30 秒 |
| 2 | 每份材料只看第一段第一句和末段最后一句，在材料顶上写一个词（"理论 / 家底 / 绿色工厂 / 零碳园区问题 / 生态治理 / 绿美点 / 全运会"） | 每份 20 秒，八份约 3 分钟 |
| 3 | 每道题指定了哪份材料，写在题干旁；作文用全部 | 30 秒 |
| 4 | 找分量（3.2 的第①把钥匙）：只在材料 1 和第 2 步顶上写了"讲话"的材料的第一句里找题目对象的官方分量（五个振兴 / 生态美产业强文化兴百姓富 / 管理和服务 / 强县促镇带村），找到圈出来，找不到写"无" | 30 秒 |

第 5 分钟到，不论做到哪一步，翻到第一题。日记体、走访体材料的标日期，等做到那道题时再做。作文要用的材料在作文时段读（8.2），开考只看首尾句。

【补】**跨篇的限制**：小题一题一材料。只有两种情况翻别的材料：优势题找别篇材料里的有利条件（优势 = 有利条件，见 5.5；压成最后一条），对策题找手段（同套卷子别的材料里的正面做法算一档手段）。别的题不跨篇——那是电子老师"一次装下八份"的做法，人做不来也没时间。翻别的材料时只翻顶上那个词和本题同域的那一份，限 1 分钟，找不到就进二档。

### 3.0.5 一题之内的动作顺序（原文《人话版》七步，压成一张表）

以一道 20 分钟的小题为例，30 分钟的题按比例放大。

| 步 | 分钟 | 手上做什么 | 对应四问 |
|---|---|---|---|
| 审题 | 1 | 题干上圈四样：中心词、主体和身份、字数和要求词、引号里的每一个词。字数换成行数写在题干旁 | 一问、四问 |
| 扫段 | 1 | 数段。段旁写三个字母之一：背 / 数 / 评（背景、数据、评论）。做法、问题、启示题读的时候跳过这三种段；作用、成效题的数据段和评论段不跳，效果词就住在里面；人物后面的一两句评论不算"评"段，划波浪线标"名" | 二问 |
| 第一遍读 | 6 | 按一问定下的单位圈词（做法圈动词 + 名词，问题圈名词 + 坏词，作用圈效果词，特点圈名词 + 判断）。每段读完，段旁写一个字母（给这段的点编号 A、B、C……）加两三个字的缩写，如"B·冷链仓"。总结句、目的句、需求句、人物后的评论句划波浪线标"名"——标签住在这些句子里。材料给的结构性总结句标"总"，优势 / 特点题里用"最、核心、宝贵"强调的标"单"。一段的篇幅是别的段两倍以上，记"这点多给半行"，其他念头不起。第 7 分钟到还没读完 → 余下各段只读首尾句、照常写字母，直接搭骨架 | 一问 |
| 搭骨架 | 2 | 草稿纸一行一个点：那个字母、标签位置空着、后面缩写。名字最后填 | 二问 |
| 第二遍 | 2 | **在骨架上做，看骨架不看材料**：归堆、定父子、起名、分行数 | 二问、三问、四问 |
| 写 | 7 | 序号 + 标签 + 句号 + 几个短句。每写完一点看一眼行数 | — |
| 检查 | 1 | 按固定顺序：每点有动词 / 坏词吗 → 标签 8 字内吗 → 哪个点其实是另一个点的儿子 → 材料低频词在不在 → 行数数了吗 → "最 / 首位 / 入选 / 全覆盖"每个指回材料原句了吗 | 核对 |

两遍读法的意思：第一遍在材料上圈，第二遍在骨架上做。第二遍不回材料，是为了不被材料的篇幅带着走。

### 3.1 第一问：单位是什么？

题干的中心词决定你要找的"单位"，单位决定圈什么、标签长什么样。

| 题干中心词 | 单位 | 读材料时圈什么 | 标签形式 | 每条的形状 |
|---|---|---|---|---|
| 做法 / 举措 / 经验 / 建议 / 密码 | **动作** | 动词 + 名词，主语是题目指定的主体 | 动宾 4–8 字 | 标签 + 两三个动作短语（+ 一个效果尾巴） |
| 问题 / 短板 / 困难 | **状态** | 名词 + 坏词（不足、脱节、滞后、不畅） | 名词 + 坏词 | 类名 + 一两个表现词 |
| 作用 / 意义 / 成效 | **效果** | 效果词（拓宽、提升、增收、转正、后继有人） | 领域词或主体 + 作用 | 标签 + 动作串 + 效果词（效果词一个不少） |
| 优势 / 特点 / 表现 / 体现在哪些方面 | **判断** | 名词 + 判断（同源、相近、任务急） | 名词 + 判断，越短越好 | 标签 + 事实 + 半句意义 |
| 启示 | **动作 + 认识** | 别人做对的、做错的、直接对"我"说的 | 动宾 | 标签 + 认识句（抄原话）+ 做法句 |

**一问里还要做的几件小事**：

- 【补】**轴过滤**：题干的限定语划出一条轴，轴外的单位不圈。判法：那句话里含题干中心词或它的同义词（"科技赋能"→科技 / 数字 / 智能 / 信息化）→ 在轴上；一个都不含 → 轴外，不写，也不算"拿不准"。2025 县镇卷第二题"科技赋能农业存在的问题"，竹林"收益低、农户不愿投入管理"是真问题，但一个科技词都不沾，不收。审题时先看材料有没有给中心词下定义：2022 县级卷材料末段自己定义了"软联通"是"制度、规则衔接"，修桥修路就不在轴上。
- 【补】**题干引号里的词逐个抄下来**，写完答案逐个打勾。2023 县级卷第一题"追求质量、打造品牌"，材料重心在品牌，"质量"的动作散在质量奖、众陶联那几段里，盲做时被砍了——引号里的词就是清单上的词。
- 【补】**要求词决定形状**：

| 题干要求词 | 做 |
|---|---|
| "具体明确" | 对策写到工具级（第 4 章） |
| "理解深刻""认识深刻" | 每条带一句认识句，抄材料原话 |
| "观点鲜明" | 开头一句总观点，不超过一行（25 字内），用材料习语拼 |
| 只有"概括""简述" | 直接"一是" |

- 【补】**讲话体材料圈"要"字句**：领导讲话里的举措都是"要……"，"希望专家弘扬科学家精神"是期望，"华为美的比亚迪"是家底，都不是举措。
- **效果单位的四个位置**（作用题、成效题专用）：例子后面的结果句（"远销 80 国"→拓宽市场）、群众的反应（"讲给孙子听"→自发传播）、反面评论反过来（"没有信息化要耗费大量人力物力"→节约人力物力）、数据句反过来（"完备产业链供应链工业体系背后是产业工人队伍"→支撑完备体系）。四个位置都扫一遍，效果词一个不少。作用题的例子不能像概括题那样整个砍掉：砍人名和数字，留效果词。

**人名、数字、故事、情绪不是单位**，读到跳过。数字怎么处理，按单位类型分：

| 题型 | 数字 | 【为什么】 |
|---|---|---|
| 做法 / 问题 / 启示 | 换成程度词（"近九成""大幅"） | 数字是这些单位的第三层，换程度词保住"程度"这个意思又省格子 |
| 成效 / 作用 | 每条至多留一个，只留结果句里的（"转正""第一"优先于百分比）【待验证：两家参考答案都不留，定稿留一个当保险】 | 最结论性的那个数字可能就是清单上的效果表述 |
| 优势 / 特点 / 体现在哪些方面 | 数字本身是条件的（"5000 万元""不足 3 公里"）保留；数字只是结果的（"订单增长 20%""产值 11 亿"）砍 | 条件数字去掉判断就空了；结果数字不是判断 |

整题数字总数不超过条数。

### 3.2 第二问：用谁的分组？

分组决定条数和标签的种类。四把钥匙按顺序判，每步用一个能数出来的信号，符合就停：

| 序 | 信号（能数出来的） | 分组钥匙 | 条数 |
|---|---|---|---|
| ① | 总述材料、领导讲话或题干给了对象的分量 | **按分量分**，标签用分量词 | = 分量数 |
| ② | 材料里有过渡句划方面："不是……而是""还体现在""延伸至""另一方面"，数出两句以上 | **按过渡句分**，平铺，同型标签 | = 过渡句划出的方面数 |
| ③ | 段首出现人名、地名、日期、发言人（座谈、走访、日记） | **按"谁做的 × 哪一环"归** | = 互不重复的事的数量 |
| ④ | 以上都没有 | **一段一堆** | = 段数；两段主语和宾语相同减一，一段里出现两个主体或"一方面……另一方面"加一 |

（钥匙①②③④对应第 7 章信号表的 1、3、2 号；④没有信号号。）

"谁做的 × 哪一环"的操作：给每件事贴两个标记——做事的主体是谁（银行 / 财政 / 农户），做的是流程里的哪一步（种 / 加工 / 卖 / 融资）。两个标记都相同的才是同一件事。

**条数的规矩**：下限是材料里互不重复的事，上限没有——拆得更细不吃亏（2025 县镇卷八问九策 90 分、2021 县级卷理解题九条 90 分；2025 县镇卷第一题压成三条的只有 81.5；2023 县级卷第一题合成三条的 84.5 也只是那套的次高分）。预算不够就把每条写短，条数保持。

**去重、合并、定父子（这是二问里最容易打架的地方，分三层说）**：

1. **去重**：同一件事说了两遍只写一次。判据：两处的主语名词和宾语名词都相同（"科研—产业脱节"三个人各说一遍）→ 同一件事；名词有一个不同（"评价体系" / "收益比例"）→ 两件事。只比名词，不比形容词和程度词。去重不算合并。
2. **合并**：默认不合。只有**材料自己用一句话罩住的两件事**才能合成一条，你自己觉得像的不能合。两种合法依据：材料的思路句罩住了两段（2025 县镇卷第一题，第 8 段"不能只卖鲜果，要提附加值"罩住加工和文旅两段，塞进"延长产业链"一条，两件事的词都写；同题真人卷 4 到 6 条都有 88 分以上）；材料自己的命名把两件事放在同一个域（2022 县级卷"职称和职业资格业务一站式服务平台"这个全名把它和"职业资格互认"放在同一制度域）【待验证：1 个样本】。题型例外见 5.3（作用题同一主体层的两种人合一条）、5.7（启示题品质相同的人物合一条）、6.2（作文分量多于段数时按环节合并）。
3. **定父子**：父 = 能当总标签把几条都罩住的那一条，兄弟 = 并列的一条。能装下所有兄弟的才是父；装不下的就是兄弟，哪怕它那段写了一整页。例：2025 省市卷第一题，材料里"银行提供全生命周期金融服务"写了一整段，但它和"财政投入"是并列的两件事，参考答案单列；定稿的早期版本把它塞进"健全多元投入体系"下面，就错了。没有父就平铺（2026 一卷套二级的那份 77）。

**什么时候必须分开**：主体不同（银行做的和财政做的）、类别不同（产业集聚低和硕博培养少）、对策不同（招商和培养是两个部门的事）。

**"拿不准"只剩一种情形**：轴上、能指回材料原话、但不确定和别的条重不重复——单独一条，放最后。

【补】**已做的动作改写成要点**：材料按当事人一天的动作走的对策题（2022 乡镇卷寒潮），"环"就是他做的每件事，做完的写成"要做"，动词换成镇能做的：组织、指导、协助、申请。

### 3.3 第三问：名字从哪来？

按顺序找，找到就用：

| 材料里有 | 名字 |
|---|---|
| 结构性总结句——材料自己把几条串起来的那句（"以文兴村，农文旅一体化，游养买一条龙"） | 抄成答案第一句 |
| 感叹句、口号式评价（"整个镇年轻了""理念融入企业基因"） | 不当总句；感叹句压成效果词写进条目；评价性总括看余量（下面说） |
| 目的句、需求句、评论句（"为了……""迫切需要……""教授说……"） | 抄成标签（"迫切需要商标品牌公共服务"→"提供品牌公共服务"） |
| 分量词（第二问找到的） | 用分量词 |
| 都没有 | 五个动词（增强、健全、优化、构建、推动）+ 段里反复出现的名词 |

【为什么】兜底名这么配：反复出现的名词就是那一段的采分名词，标签里带上它就一定被找到；五个动词是参考答案的高频类名动词，阅卷人一看就知道这是标签不是内容。

标签 4–8 字，词性和内容一致。【为什么】阅卷人靠标签定位清单上的类名，短于 4 字不成类名，长于 8 字就是在标签里写内容、和后面重复占格子。

材料给的长名（"党支部+公司+基地+农户"）放在标签后面的第一句，不当标签。材料给的是意象（"市场是孵化器加速器放大器"），标签自己起短的（"发挥超大市场优势"），意象放进内容。

【补】**两种总句分开**：材料自己把几条串起来的结构性总结句，往往就是参考答案的第一句，是清单上的一条，必抄。对全文的评价性总括（"绿色低碳理念融入企业基因"）不是单位，清单上没有——2026 两套卷子五份高分卷都没写。规矩：预算算完，目标行数减去（条数 × 每条行数）还余一行以上才写它，否则不写，别为它砍材料词。题干要求"观点鲜明"的总观点句不受这条管——它是采分点，先占半行进预算再分条；余量规矩只管题干没要求的评价性总括。

### 3.4 第四问：预算怎么分？

**目标字数 = 题干限字 × 0.9（不超过 200 字的题 × 0.95）；目标行数 = 目标字数 ÷ 25；每条行数 = 目标行数 ÷ 条数**，写在骨架旁边。格子比限字多出的那 20 格是标点和涂改的缓冲，不进预算。查表见 8.1。

【为什么】"每条一行半"是常见情形算出来的：200 字题目标 7 行半，除以常见的五个采分点约一行半——一行放标签和类名词，半行放具体名，三层天然没位置。八九条的题就是一行一条，不要背"一行半"。一段的篇幅是别的段两倍以上才算长，那一条多给半行，从三层最多的那条扣，条数不动。

每条的三层：标签 + 一层（材料的类名词）+ 二层（材料的具体名）+ 三层（例子、数字）。行数紧，先砍三层，再砍最长那条的最后一个分句，条数保持。做法题里的应用例子（"多乘员车道""人脸识别"）预算紧时先砍；作用题的效果词不砍。

【为什么】砍的顺序：三层不在采分清单上，砍了不丢分——成效题的结果词本身就是采分词，所以那里例外；砍最长条的尾巴最多损失一个二层词；砍一条是丢清单上的一条，永远排最后。

**写完数格子。** 不估。

### 3.5 动笔前的核对

考场上翻回材料逐个核对做不完，所以核对不是单独一步，而是拆进读和写里：

**第一遍读的时候**：圈到①带"推广 / 借鉴 X 经验"的、②数字 + 名词的、③"最 / 首位 / 入选 / 全覆盖"这类判断词的，当场多看一眼、段旁标"核"——① X 那段里的动词是什么；② 数字后面跟的是哪个名词；③ 判断词的主语是谁。第二遍不翻材料，只把段号抄到骨架旁。

**动笔前十秒（算在"写"的时间里）**：主语核对（每条动作是不是题目指定的主体做的——正例：材料写荔农收到预警去浇水，题目主体是县，就写成县的动作"平台预警、指导荔农精准浇灌"；对策动词是不是这个身份能做的）+ 引号词打勾。

#### 3.5.1 预登记（练题时做，考场不做）

每题写答案前先在草稿上写三条"没把握的"：哪个点不确定算不算、哪个名字是自己造的、哪两个点不确定该不该合，各标把握（高 / 中 / 低）。对答案时预登记命中一半以上，说明你知道自己在哪不稳——这比分数更值钱。考场上对应的动作只有一个：反推出来的对策（材料没明说、你从它写的错误做法反过来推出的，见 4.2 第二步二档）在骨架旁标一个"反"字，带"反"的排在材料明说的后面。

### 3.7 【例】把四问走一遍：2026 省市卷第一题

**题干**：请根据材料 3，谈谈"绿色工厂"的"绿"体现在哪些方面。不超过 200 字。答题卡 220 格。

**一问**：中心词"体现在哪些方面"→ 单位是**判断**（什么怎么样）。和 2022 乡镇卷"小林村的美体现在哪些方面"同型。主体是 H 电子；县里派"首席服务官"、设示范点是县的动作，不是工厂的"绿"，不圈。

**二问**：钥匙①没有分量；钥匙②有——材料 3 三句过渡句："我们不是简单种树，而是让生态成为生产中的好伙伴"（从环境转到能源）、"绿色低碳的理念，还体现在办公管理的细微处"、"H 电子还将绿色低碳理念延伸至原材料领域"。三句过渡句划出环境 / 能源 / 办公 / 供应链四块；产品那一段夹在能源和办公之间，没有过渡句但自成一段、说的是另一件事，按钥匙④加一条。厂区环境 / 能源 / 产品 / 办公 / 供应链，**五条**。"理念融入基因"是评价性总括不是方面；"订单增长 20%、产值 11 亿"是结果不是方面。

**三问**：材料没给方面名，用题干的字起五个同型标签：厂区生态绿 / 能源清洁绿 / 产品设计绿 / 办公管理绿 / 供应链绿。

**四问**：200 × 0.95 ÷ 25 ≈ 7.6 行，五条各一行半。结果类数字（91 万千瓦时、2 克、20%、11 亿）砍，条件类的"5000 多株"留一个。评价性总括句：7.6 − 7.5 = 0.1 行，按规矩不写；原定稿写了，是因为它每条都压得短、总共 193 字装得下——两种都行，别为它砍材料词就是了。

**骨架**：
```
① 厂区生态绿   5000多株树 / 乡土阔叶树种 / 灌木花草 / 垂直绿墙 / 吸碳降温
② 能源清洁绿   屋顶光伏 / 自用余电上网 / 减碳
③ 产品设计绿   纳米涂层替代喷胶 / 可拆解维修 / 配件循环利用 / 减重减碳
④ 办公管理绿   不提供一次性用品 / 无纸化办公
⑤ 供应链绿    供应商提供环保数据 / 回收包材线圈 / 降本增效
```

**答案（193 字）**：绿色低碳理念融入企业基因。一是厂区生态绿。种植5000多株乡土阔叶树和灌木花草，建垂直绿墙，吸收二氧化碳、降温美化。二是能源清洁绿。屋顶铺设光伏板，绿电满足自用并输送电网，减少碳排放。三是产品设计绿。研发纳米涂层替代喷胶，耳机可拆解维修、配件循环利用，减重减碳。四是办公管理绿。不用一次性用品，全流程无纸化办公。五是供应链绿。要求供应商提供物料环保数据，鼓励回收利用包材线圈，节能降本。

顺手做一次保真核对的示范：第一条"5000多株乡土阔叶树和灌木花草"，材料原文是"种有5000多株树木，除了广泛种植优质乡土阔叶树种外，还通过巧妙搭配灌木和花草"——5000 多株说的是树。考场上这种出入不会扣分，原答案不用动；但"数字跟着哪个名词走"正是保真核对时眼睛该盯的地方。

**对照真人卷**：十一份卷子人人五条，差别只在三种毛病：写残（一条只有标签或只有一个短语）、写空（用"绿色景观"替换"乡土阔叶树、垂直绿墙"——两份 84.5 分卷就是这样，没扣多少）、套二级（77 分卷）。一份 86.5 分卷（县镇卷同题）写了七条，多了"思想绿""政策绿"，没吃亏。**你从这里学到的**：这种题的分组几乎不区分，具体名和不写残才是你的保险。

### 3.8 【例】按分量分：2023 乡镇卷第一题

**题干**：概括人才在北山镇乡村振兴中发挥的作用。不超过 200 字。

**一问**：效果单位；"人才让乡村得到了什么"。题干只要求"概括"、没写"观点鲜明"，所以开头不写总观点句，直接"一、"起。

**二问**：钥匙①命中——对象"乡村振兴"有官方分量，总括材料把它拆成乡村发展、建设、治理。按分量分：改善基层治理 / 发展农村产业 / 传承乡村文化 / 促进村民增收 / 改善农村生态，五条。七个人物（村支书、企业家、返乡人才、非遗传承人、工作队……）各自的效果归进领域。盲做时按主体分了五条，参考答案按领域分，两套一比（2023 县级卷按主体、这套按领域），判据定下来：**对象有分量按分量，没分量、材料按主体排才按主体**。

**三问**：领域词做动宾标签，主体写进条目里当例证。

**四问**：7 行半，五条各一行半；人名一个不写，"党支部+公司+基地+农户"按 3.3 应放标签后第一句，这题预算紧，压成材料自己的短称"联农带农模式"。

**答案（191 字）**：一、改善基层治理。村支书调解纠纷、处置突发事件、帮解难题；企业家热心公益。二、发展农村产业。预制菜加工带动产业，返乡人才电商拓销路、实现农消对接，养殖打响品牌、带动旅游。三、传承乡村文化。非遗传承人精研根雕、带徒传艺，把根雕文化做活。四、促进村民增收。工作队帮根雕开拓城市市场提升售价，引进项目资金，推行联农带农模式。五、改善农村生态。治理垃圾污水，提升村容村貌，驻点提供技术咨询。

## 4. 问题 + 对策题：附加程序

问题侧按第 3 章走（单位 = 状态）。对策侧多四步。这是广东卷第二题的固定题型（2024–2026 六套全是），分值 30，必须练熟。

### 4.1 问题侧：类名 + 表现词

问题写成"名词 + 坏词"是类名，类名后面要跟一两个表现词。"缺乏人才"四个字一条的（2026 一卷 80 分、81.5 分），低于写"缺运营管理和复合型技术人才""补贴远远不够"的（84.5 分）。表现词从材料来：人工剥皮、林道不畅、跑多部门填多表等多日、铺水泥不知违法、坡陡野兽多。典型表现词清单见 10.3。

总括性的问题先写，小毛病跟在后面当展开。材料里的建议句记到对策栏，不进问题栏；从规划句反推的问题（"正在筹备协会"→缺协会）放尾巴【待验证：1 个样本】。

### 4.2 对策侧四步

**第一步 反转**：对策的类名 = 问题的类名反过来（脱节→对接，不足→强化，滞后→推动落地，不畅→畅通）。同一个类名，在问题栏出现一次（"审批不畅"），在对策栏反转后再出现一次（"畅通审批"）——阅卷人扫一眼就能把每条对策对回它针对的那条问题，"针对性"这个分是这么拿的。反转只负责起名，名字后面必须接手段，否则就是镜像（4.3 第一个坑）。

**第二步 手段**：逐条操作。对每一条问题：
1. **一档，材料明说的**：在座谈、评论、当事人的话里找含"要 / 可以 / 建议 / 应当 / 探索"的句子，找到就抄进这条对策；同一套卷子别的材料里的正面做法也算（2024 二卷 J 镇经费缺口，手段来自材料 8 的"社会资金流向乡村"和材料 6 的"集体经济强起来"）。找不到算一档为空。
2. **二档，材料反推的**：一档为空、或一档给的工具数少于这条需要的数（题干有"具体明确"时两个，否则一个），找这条问题对应的"以前怎么做错的 / 没人愿意 / 还在摸索 / 错过黄金时间 / 跑多部门"句，反过来写成手段——"没人愿意"反推成激励或培训（试种补贴、电商技能培训），"错过黄金时间"反推成绿色通道、先抢救后补手续，"跑多部门填多表"反推成简化审批。反推的对策在骨架旁标"反"。
3. **三档，标准手段**：一二档都为空，才从 10.5 词库挑一个工具（培训、平台、机制、专项资金），每条问题最多挑一个。

够数就停，进下一条。

【为什么】清单上的词只可能来自材料：一档命中率最高；二档能对回材料，阅卷人看得到针对性；三档不在任何一份清单上，只换"有手段"这个形式分——所以每条至多一个，而 4.3 的"自补"就是三档用在了一档之前。

【补】反推的把握怎么判：反推的对策对着材料明说的问题 → 把握高；对着"形势"（没有一条明说的问题和它对应）→ 把握低，放最后。2021 乡镇卷火情题五条对策全靠反推，四条对着明说的问题，第五条对着形势。

**第三步 具体度**：手段一律写到工具——无人机巡山、古树数字档案、发传单办讲座、一网通办、以老带新、联合高校定向培养、先抢救后补手续、专项资金。题干写了"具体明确"时这是采分点，每条写两个工具；没写时也不吃亏，每条至少一个；预算紧先砍第二个工具，不砍到零。

【为什么】对策题的采分点是材料里的具体办法，题干写"具体明确"等于宣布清单是工具级的；"加强宣传""运用科技手段"这种动词级的话在清单上没有对应词。2026 县镇卷两份收录了第二题的 90 分卷，对策全是工具级。

**第四步 对应与身份**：每条对策都要对得回某个问题；对策可以比问题多（一个问题里材料给了两种不同工具时拆两条——2026 县镇卷 90 分卷把"专家指导""文旅致富"各单列），不能比问题少。每条的动词是这个身份能做的：镇——组织、协调、申请；市发改局——制定、明确、完善、培育；科技局——推动、督促、搭建；调研组——建议市里做。材料里有几户、几个案例，每户每案例各有一条。汇报、报告题的排法按 4.4 判；按类型写时，每个镇的专有名在对应类型的那条里露一次。

【为什么】身份是题干给的轴，轴外的动作阅卷人不算对本题的对策（小麦"明确处罚标准"、镇里"人工增雨"）；材料里每户每案例是出题人埋的一个点，漏一户等于漏一条（2020 乡镇参考答案漏了老刘家）。

### 4.3 七个常见坑（真分数验证过的扣分点）

| 坑 | 长什么样 | 出处 |
|---|---|---|
| 镜像 | "未出台实施办法 / 督促出台实施办法" | 2025 省市参考答案 |
| 自补 | 座谈会、专班、集采、基金——材料里一个都没有 | 2026 一卷 77 分卷九条对策；2026 二卷 81 分卷"台风季修剪树冠""一表通" |
| 张冠李戴 | "推广 A 园区绿电直连经验"（A 园区做的是风光储） | 2026 一卷 80 分卷 |
| 越权 | 小麦"明确处罚标准"、镇里"人工增雨" | 2023 乡镇、2021 乡镇参考答案 |

### 4.4 汇报、调研报告、发言提纲的格式

【为什么】格式写不写看题干：题干只要"内容"，格式不在清单上，称呼落款占格子不换分；题干要"提纲 / 报告"，格式本身是一个采分项。

- "拟写报告中'存在问题'和'对策建议'两部分"：只写两个小标题"存在问题：""对策建议："，各占一段；小标题后面直接接"一是……二是……"，各条之间不换行（换行空的格子也算字数）。样子见 4.5。
- "草拟向领导汇报的主要内容"：只要内容，不要标题称呼落款；开场白（"总体已取得阶段性成果"）套 3.3 的余量规矩：余一行以上才写。
- 【补】**按镇写还是按类型写**：数一下材料涉及几个镇 / 村、每镇几件事——镇数不超过五个、各镇的事互不重复（一镇两件也算，E 镇就是两件）→ 按镇写（2024 二卷 88 分卷就是按镇写，也省 36 个字）；镇数超过五个，或同一问题在两个以上镇出现 → 按类型写。两种都在高分段。
- **发言提纲**：标题 → 开头一句总述 → 主体分条 → 结尾一句（用材料里领导的总结句）。每条 = 标签 + 一句做法 + 半句例证。提纲是条目不是稿子，不寒暄不展开。材料按村走就按村写，每村下面分做法（2023 乡镇卷第五题，参考答案和 84.5 分卷都按村）。

### 4.5 【例】走一遍：2026 县镇卷第二题（古树名木）

**题干**：假如你是调研组成员，根据材料 7 梳理 S 市古树名木保护遇到的问题，并提出对策建议。要求对策"具体明确"。不超过 300 字，答题卡 320 格。

**一问**：状态 + 对策；身份"调研组成员"，对策是建议市里做的事。

**二问**：钥匙③命中——材料按走访点排（景区 / 江心岛 / 乡镇 / 深山的护林员）+ 座谈四人插评 → 按"谁 × 哪一环"归。互不重复的事：保护性破坏 / 抢救不及时 / 群众意识薄弱 / 深山巡护困难，**四条**。座谈四人：教授点出第一条的问题（"保护性破坏、好心办坏事"，只点问题没给办法），主任对第二、四条给了办法，局长和组长对第三条给了办法。材料的形状就是四问四策。

**三问**：问题名用材料词——"保护性破坏"是教授的原话，"错过抢救黄金时间"压成"抢救不及时"。对策名反转：科学保护 / 快速抢救 / 普法激励 / 科技巡护。

**四问**：300 × 0.9 ÷ 25 ≈ 11 行；问题 5 行，对策 6 行。"130 株""跑几个部门填几张表"压成"跑多部门、填多表、等多日"。

**附加程序**：
- 一档：主任"单靠政府不够、探索灵活救治""借助科技手段动态监管"；局长"条例已明确处罚、让群众知法守法"；组长"按条例表彰奖励、挖掘古树文化结合旅游让群众靠护树致富"。教授那条一档为空。
- 二档（标"反"）：错过黄金时间 → 专项资金、简化审批、先抢救后补手续；铺水泥不知违法 → 发传单办讲座讲条例；滑倒野猪 → 护林员安全保障；围栏铺砖填洞 → 制定技术规范、专家指导。
- 三档：不需要。
- 工具级：技术规范、专项资金、先抢救后补手续、传单讲座、表彰奖励、古树文旅、无人机、数字档案。
- 身份：制定、请、设立、简化、引入、宣传、落实、挖掘、运用、保障——都是建议市里做的。

**答案（295 字）**：
问题：一是保护性破坏，景区古树修豪华围栏、铺地砖、填树洞。二是抢救不及时，受损古树需雇专业团队，经费审批跑多部门、填多表、等多日，错过黄金期。三是群众意识薄弱，村民铺水泥盖古树根不知违法，护树积极性不高。四是深山巡护困难，古树散落深山，坡陡野兽多、巡山危险。
对策：一是科学保护，制定保护技术规范，请专家指导，纠正围栏铺砖填洞等做法。二是快速抢救，设立抢救专项资金，简化审批，必要时先抢救后补手续，引入社会力量和专业队伍。三是普法激励，发传单、办讲座宣传条例让群众知法守法，落实表彰奖励，挖掘古树文化发展文旅让群众护树致富。四是科技巡护，用无人机巡山，建古树数字档案动态监管，保障护林员安全。

295 字顶到了限字，按 3.4 的口径考场上应压到 280 左右：问题侧"跑多部门、填多表、等多日"可压成"审批繁琐"，对策侧"引入社会力量和专业队伍"可删。示范保留全文是为了把工具都摆出来。

**对照真人卷，以及怎么"权衡"**：两份收录了第二题的 90 分卷问题四条（写得极短，"保护性破坏案例增多"八个字一条），对策六条：简化资金申请流程、设专项资金、必要时允许先抢救再申请 / 建立古树保护队伍 / 派传单开讲座、表彰奖励 / 无人机、数字档案动态监管 / 专家指导 / 古树文旅致富。它们把"专家指导"和"文旅致富"各单列成一条，我合在第一、三条里，工具都在。"先抢救后补手续"是从材料反推的，两份 90 分卷都写了，反推被验证。

**注意权衡**：90 分是总分，不是说它第二题每一条都得了分。它问题侧只写八个字一条，我保留了表现词；它没写"护林员安全"，我写了。这两处没有真分数能判断谁对，按原理（覆盖、保真）保留。真人卷校准的是**形状**——条数、工具级、每条对得回问题——不是逐点的标准答案。

## 5. 分题型速查

每型只写和通用流程不一样的地方。练某个题型前读它那一小节。

### 5.1 概括做法 / 举措 / 经验
找"谁做了什么"，主语是题目指定的主体。目的句、效果句用来起名或当尾巴。三个并列的四字短语、引号里的词整体抄（"凝练科研问题、吸聚创新资源、兑现创新价值"）；"质量就是生命、效率就是生命"后面的动作"提质增效"必写。讲话体圈"要"字句。

### 5.2 概括问题 / 短板
"名词 + 坏词"，类名后面跟表现词。对话里随口一句抱怨算问题证据（"果园信号不好"）【待验证：1 个样本】。副作用句（"经费打了水漂"）留在展开里当表现词。

### 5.3 作用 / 意义 / 重要性
每条 = 标签 + 动作串 + 效果词。对象有官方分量用领域标签，没有、材料按主体排用主体标签。例子留动作去人名数字，效果词一个不少（四个位置见 3.1）。人物后面的评论句当标签。同一主体层的两种人（企业家和职业经理人）合一条分号隔开（合并例外，见 3.2）。题干要"观点鲜明"→ 开头一句总观点，不超过一行（25 字内），用材料习语拼（"源头活水"）；题干只要"概括"→ 直接"一是"。

### 5.4 成效 / 效果
标签"名词 + 变好的动词"（复苏、回稳、减轻、提速）。结果词（转正、第一、量质齐升）一定写；数字每条至多一个【待验证：两家参考答案都不留】。材料里的做法当主语、结果当谓语（"减免社保惠及 29 万家"——这就是数据句反过来）。同一材料里两件事（商事秒批、知识产权保护）各一条。市场主体增长并进经济复苏【待验证：1 个样本】。

### 5.5 优势 / 有利条件 / 特点 / 体现在哪些方面
"名词 + 判断"，标签越短越像特点（任务急 / 任务重 / 挑战多 / 责任大 / 风险高）。材料自己的总述句当第一条（"文化同源、血脉相通，是重要基础"）。做过的事（联合申遗、合作办展）当"已有基础"的证据写进条目。当事人自己总结的"最难的三点"直接成特点，个人经历跳过【待验证：1 个样本】。别篇材料里的条件压成最后一条写短【待验证：1 个样本】。材料用"最、核心、宝贵、关键"强调的元素单列一条（孙中山）【待验证：1 个样本】。每条 = 标签 + 事实 + 半句意义。

### 5.6 理解题（"密码 / 秘诀 / 关键"）
第一句解比喻（"密码"是 G 市加强科技创新的一系列做法）——【为什么】题干"理解"含一个解释采分点。再分条，分条同做法题。写成效的段落也算一条（无人工厂效率提升 = 企业应用创新这个做法）【待验证：1 个样本】。【补】格子允许时，材料里每个有独立事实的句子都能成一条（90 分卷九条）；格子不允许时按段合并，合到每条还剩两个短语为止。

### 5.7 启示
每条 = 标签 + 认识句（抄原话）+ 做法句。会议对话一个发言人的话题一条；别人被指出的错反过来写成做法；直接对"我"说的那句单独一条（"提高思想觉悟，安全重于泰山"）【待验证：参考答案和 84.5 分卷都没写，按原理保留】；一个难题多问"为什么会出现"（挖掘机难请是因为全县同时复耕 → 增强预见性）【待验证：1 个样本】；多个人物一人一条，品质当标签，**做法收全**（盲做按品质跨人写，丢了一半做法），末尾一句深一层，品质相同的合一条（合并例外，见 3.2）。【补】同一件事里的态度和方法合一条，标签写成"深入一线、担当奉献"这种并列。写完检查身份：每条都是"我"能做的。

### 5.8 推广经验要把握的方面
【补】单位是"做对的环节 + 踩过的坑"。材料里的反面经验（"以前没认识到意义、不重视、效果不好"）自己是一条，不只是反推对策的来源。2023 乡镇卷积分制题，参考答案漏了"提高认识"这条，84.5 分卷写了。

### 5.9 发言提纲 / 汇报
见 4.4。

### 5.10 原因 / 影响 / 应用文（方法只有一句话）
原因往上游找，影响往下游找。应用文 = 同一套找点 + 格式框。没练过，考到按四问走。

### 5.11 【例】把分题型规矩落到题上（五道）

前面 3.7、3.8、4.5、4.6 走了判断题、按分量的作用题、问题对策题、条数题。这里再走五道不同形状的，每道只写"这题和通用流程不一样的那一步"和答案，看完你应该能说出"这题的钥匙在哪"。

#### 例一 · 作用题的效果词四位置：2023 县级卷第二题

**题干**：分析说明青年人才对推动制造业高质量发展的重要作用。要求观点鲜明。不超过 300 字。

**钥匙**：效果单位。对象"制造业高质量发展"没有现成的官方分量，材料 7 按人物类型排（企业家→职业经理人→工匠技能人才→研究生海归→律师），所以按主体分四条，企业家和职业经理人同属经营层合一条。题干要"观点鲜明"，开头一句总观点。

**这题的关键动作——把四个位置的效果词全挖出来**：

```
例子后面的结果   远销80多国→拓宽市场 / 行业领军→提升行业地位 / 呆账降到极低→降低风险 / 研发工装设备→摆脱进口依赖 / 新材料投入试用→成果应用 / 20余项PCT专利→产出专利
人物后面的评论句  周评：国际视野、把握技术趋势、引领作用 / 刘：当家的重要基础、后继有人 / 专家：制造业当家离不开知识产权管理、法律、设计服务
群众反应        这题没有
数据句反过来    技能人才1800万青年占大部分→有力支撑 / "完备产业链供应链工业体系背后是产业工人队伍"→支撑完备体系 / 数十万青年研发人才→高科技企业数、发明专利全国首位
```

盲做时把例子当概括题整个砍掉，效果词跟着丢了四五个（拓宽市场、完备体系、成果应用、提升地位）。**作用题的例子不能整个砍：砍人名和数字，留效果词。** 一份 81.5 分卷五条全是描述、没有一个效果词，这就是它第二题的失分。

**答案（280 字）**：青年人才是制造业高质量发展的源头活水和生力军。一是青年企业家引领发展。以企业家精神和国际视野把握行业技术趋势，实现核心技术自主可控、拓宽国际市场；主导数字化管理改革，打造年轻化专业化团队，提升效益。二是青年技能人才夯实产业基础。自主研发工装设备摆脱进口依赖，投身技能报国，壮大高素质产业工人队伍，支撑完备的产业链和工业体系。三是青年研发人才驱动创新。依托联合培养基地和海归团队破解技术难题、推动成果应用，产出专利，支撑高科技企业数量和发明专利量全国首位。四是青年专业服务人才改善经营。以法律、知识产权、设计等服务规范企业流程、降低风险，助推企业成长为行业龙头。

**学到什么**：标签是"主体 + 作用"（青年企业家引领发展），作用词从人物后面的评论句来；每条至少两个效果词；总观点句不超过一行，用材料习语拼。

#### 例二 · 启示题：2023 乡镇卷第四题

**题干**：假如你是小麦，此次会议对做好应急管理工作有什么启示。要求认识深刻。不超过 300 字。

**钥匙**：单位是"动作 + 认识"。会议对话按发言走（钥匙③），一个发言人的话题一条：预案（小曾、张主任）/ 处置速度（小潘、余副主任）/ 思想觉悟（詹副镇长对小麦）/ 隐患排查（张主任）/ 依法监管（张主任）/ 群防群治（小潘、詹副镇长），六条。"认识深刻"→每条带一句认识句，抄原话：安全重于泰山 / 每慢一分钟就多十分危害 / 把隐患扼杀在萌芽 / 法律法规是"武器"。

**反推与身份**：小曾预案疏漏、缺经验 → 反推成"请有经验的同事参与、逐级审核补漏"；邻镇"处分了不少人" → 参考答案反推成"明确处罚标准"，不收——处罚标准不是小麦这个身份能定的。詹副镇长直接对小麦说的那句"提高思想觉悟"单独一条【待验证：参考答案和 84.5 分卷都没写】。

**答案（274 字）**：一是提高思想觉悟。安全重于泰山，保障群众生命财产安全是重中之重，工作多杂也要随时待命。二是编好应急预案。预案是处置依据，群众转移路线、人员安置、物资保障要考虑周全，多向有经验的同事请教、逐级审核补漏。三是快速响应处置。每慢一分钟就多十分危害，接报后要快出动、快处置。四是坚持预防为主。经常进村入户走企业排查整治隐患，重点时段开展消防检查，把隐患扼杀在萌芽。五是依法严格监管。用好安全生产法律法规这个"武器"，对不重视安全的企业依法责令限期整改、停产停业。六是发动群众参与。多宣传多动员，引导党员、群众、企业、社会组织参与排查防治，合力筑牢安全防线。

**学到什么**：启示 = 标签 + 认识句（原话）+ 做法句；别人被指出的错反过来写成做法；写完检查每条都是"我"能做的。

#### 例三 · 汇报题的两种排法：2024 二卷第二题

**题干**：假如你是调研组员，根据材料 5 草拟向市领导汇报的主要内容。不超过 300 字。

**钥匙**：材料 5 按镇排（E 镇两段 / F 镇 / G 镇三段 / H、I 镇 / J 镇），每个镇正好一件不同的事，E 镇两件 → 六件互不重复的事。参考答案把 G 镇规划和 H、I 镇古建筑合成一条——一个是规划制度，一个是资源闲置，对策完全不同，不合。手段一档里有两条来自同一套卷子别的材料：J 镇经费缺口 → 材料 8"社会资金流向乡村"、材料 6"集体经济强起来"。"汇报主要内容"只要内容，不要标题称呼落款。

**按类型写（296 字）**：
存在问题：一是圩镇秩序差，占道经营、乱搭乱建，整治后反弹，缺长效管理。二是镇公共配套弱，学校、图书馆、医院不如县城。三是产业园经营困难，龙头企业受困，其他主体小、抗风险弱。四是村庄规划滞后，制约土地、道路、产业布局，缺规划资金和指导。五是古建筑等文化资源闲置失修，未开发利用。六是薄弱镇村建设经费缺口大。
对策建议：一是建立圩镇整治长效机制，常态化巡查，清理违建。二是补齐镇级教育、文化、医疗配套。三是帮扶困难龙头企业，培育壮大经营主体，增强带动能力。四是安排规划专项资金，指导镇村修编规划。五是摸底修缮古建筑，引入文化公司运营，打造特色景点。六是加大专项资金倾斜，引入社会资本，发展集体经济。

**按镇写（260 字）**：
存在问题及对策建议：一是E镇。问题：占道经营、乱搭乱建，整治后反弹；学校医院配套不如县城，职工不愿住镇。建议：建立长效机制常态化巡查，清理违建；补齐教育医疗文化配套。二是F镇。问题：产业园龙头企业受困，其他主体小、抗风险弱。建议：帮扶龙头渡难关，培育壮大主体。三是G镇。问题：村庄规划十多年未更新，制约布局，缺规划资金和指导。建议：安排规划专项资金，指导修编规划。四是H、I镇。问题：古建筑失修闲置。建议：摸底修缮，引入文化公司运营，打造景点。五是J镇。问题：经费缺口大。建议：专项资金倾斜，引入社会资本，发展集体经济。

**学到什么**：内容一样，排法不同。88 分卷按镇写，其余六份按类型写，两种都在高分段。判定只看两件事：镇数不超过五个、各镇的事互不重复 → 按镇写；同一问题跨镇重复 → 按类型写。

#### 例四 · 优势题：2022 县级卷第二题

**题干**：分析说明三地推进文化交流合作、共建人文湾区的优势。要求分析透彻。不超过 300 字。

**钥匙**：单位是判断（"优势"= 有利条件），圈"名词 + 判断"：同源、相近、丰富、雄厚。广东做过的事（首倡游径、办戏曲节、联合申遗）不是优势，是"已有合作基础"的证据，写进条目里。材料 4 按内容分（钥匙④）：总述同源 / 地理 / 遗产游径 / 孙中山 / 粤剧醒狮 / 文博 / 产业。第一条抄材料自己的总述句"文化同源、血脉相通"；孙中山单列——材料用"宝贵而核心的共同财富"单独强调它【待验证：1 个样本】；非遗和文博都是"已经在合作"的事实，合一条。"分析透彻"→每条带半句意义。

**答案（265 字）**：一是文化同源。三地自古同属百越之地，以岭南文化和珠江文化为主流，语言文化根基相通。二是地域相近。山水相连，交通便利，港澳民众往来频繁，文化合作有天然地理优势。三是遗产丰富可串联。广州遗产、岐澳古道、改革开放遗迹、澳门世遗、香港文物径可连成文化遗产游径。四是伟人渊源深厚。孙中山在中山、澳门、香港、广州的足迹连成一体，是三地共同财富。五是交流合作密切。粤剧由三地联合申报人类非遗，銮舆堂穗港共有、会员频繁往来，醒狮各地皆有；文博界联合追回外销画、合作办展。六是文化产业雄厚。已成大湾区新兴支柱产业，文交会活跃，文化上市公司形成板块。

**学到什么**：优势题标签越短越像特点（文化同源 / 地域相近）；条件数字在这种题里保留，但这题的产值数字是结果不是条件，压成"支柱产业"就够。

## 6. 作文程序：五问

### 6.1 第一问：落在哪？（立意）

题干的判断句里圈出 **A（要拆的）和 B（每段落到的）**。"绿色发展是高质量发展的底色"：A = 绿色发展，B = 高质量发展。"乡村振兴关键在产业振兴"：A = 产业振兴，B = 乡村全面振兴。

**标题含 A**；落点用近目标或上层目标都行（2025 省市卷最高的两份标题落在上层目标"高质量发展"而不是近目标"新质生产力"，没吃亏）；B 在开头末句、每段观点句和结尾出现；题干有口号句就带上（"站在新起点，迈向新征程"）。B 再往上的目标（中国式现代化）只放开头结尾。

【补】**标题落点不是变量，观点句落点才是。** 别在标题上花时间。

### 6.2 第二问：拆哪边？（结构）

**材料在拆哪边，你就拆哪边**：

- 材料给的是 A 的做法（广东怎么创新 / 怎么绿色发展 / 怎么做制造业）→ 按 A 拆；题干引语里 A 的每个分量都要有一段或一句（2024 一卷习语把"科技自立自强"拆成创新驱动 / 核心技术 / 企业主体 / 人才高地，企业转化那段不能没有）。
- 材料给的是 B 需要什么（产业给乡村带来富、才、美、文）→ 按 B 拆；B 的官方分解每个词都出现（五个振兴全覆盖，段数不够两两合并）。
- 问题类材料出现在作文材料里 → 取反成一句"要……"放进对应段，或取反成一整段（2024 二卷材料 5 镇街问题 → 促镇段三组"要"）。
- 讲镇的材料配给讲镇的段，讲村的配给讲村的段。每一层用讲那一层的材料。
- 【补】材料骨架多于段数时按环节合并，不按篇幅合并（2024 一卷六个"地"：转化地、金融地、改革地都是转化环节 → 合一段）。2025 省市卷最高分 85+ 三段（科技 / 产业含绿色 / 体制），绿色并进产业也行。
- 段落不能互相重叠：一段和三段都写生态的那份是 80 分。

**两大段还是四段，按这条链判**：
1. 题干有两个落点（"关系长远发展和民生福祉"）且材料没给分量 → 两大段各落一个。
2. 材料给了分量 → 按分量分段（三到五段），每段观点句末尾带落点（"……是长远发展的最大本钱"）。
3. 两者都有 → 按分量分段，前半段落点一、后半段落点二（照 6.7）。
4. 作文开始时距交卷不到 50 分钟 → 把分量两两合并成两大段。

2026 二卷三份 90 分卷两大段、87 分卷四段，都行；段数不是变量，观点句落点才是。

### 6.3 第三问：每段怎么长？（段落）

**行数从哪来**：作文分档先看立意和结构，阅卷人定档时读的就是开头和各段观点句，所以开头必须在 6 行内把落点亮出来；档内论证分饱和得快而格子不饱和（例子最多的 83 分卷没有更高），所以证据三个够；结尾是落点最后一次露面，所以结尾 4 行、时间不够先写它。

**每段**：观点句 → 道理句 → 三个名词化证据（数字至多一个）→ 收束回 B。

- **观点句**优先用材料各面开头的判断句。2026 一卷两份 84.5 分卷直接拿材料 4、6、7、8 的判断句当分论点："绿色发展作为一种生产方式的变革已成为新增长点""生态环境是人类生存与发展的根基""推动绿色发展是满足人民需要的必然要求""绿色低碳是城市发展的未来"。自己的对仗句保留时，这几句当道理句。
- **名词化证据**：不把材料里的例子当故事讲，压成"地名 / 主体 + 一个动宾短语"，一句话并列三个，只留一个数字。例："F 市打造南溪河西江文旅带，A 市南岭保护区守住生态明珠，省内多个海湾入选美丽海湾——全省森林面积已达 1.4 亿亩。"
- **证据到量即止**。例子少但主题句全用材料的也能 90（2021）；例子堆得最多的 83 没有更高（2024 二卷）。省下的字给观点句和收束句的语言。
- **开头 6 行**：引语 → 解题干的比喻或口号（"底色是画布上最先铺就、决定基调的那一层颜色"）→ 一句靶子或家底（至多一个数字）→ 预告几件事（两个落点都点）。开头有靶子有预告的都在高分段【待验证：2 份样本，2023 县级 86.5、2024 二卷 88】。【补】解释题干的比喻或概念，开头两句解完，**不成段**——2025 一卷 80.5 分卷用一整段讲"创新与新质生产力的关系"当分论点，多了一段理论、少了一段材料。
- **结尾 4 行**：材料原句或意象 → 各段一个短语 → 上层目标。
- **策论文**：动词一律"要"；开头抄材料短板句当靶子；每段三个"要"各带一个材料专有名。题干含"经验"：观点句写成规律句，收束"经验是：……"，实效仍做证据。

### 6.4 第四问：材料用够了吗？（保真）

【为什么】作文材料是出题人的论据清单，每份对应一个预设的论证方向，档内分看"结合材料"，材料外的例子不在阅卷人能核的范围里。

- **每份材料至少露一次脸**。材料没用完的 78.5（2023）；材料 8 缺席的 80（2026 一卷）。
- **材料外的例子只用来补一句"联系实际"**，主体证据全用材料。材料外例子替代材料的 81.5、82（2025 二卷四段全是陈村花卉、饶平薄饼、英德茶旅、博罗）。一句材料外的道理句（引费孝通）不碍事（86.5）。
- **案例核对在写段落表时做**：每个案例的地名、人名、做法三样对上（番薯节是 K 镇，不是南紫村——2024 二卷参考答案串错了）。
- **核判断词**："最 / 首位 / 入选 / 全覆盖"每个指回原句，翻回那一页，不凭记忆。
- 排比整抄：货币补偿、物业安置、土地空间置换；土地变资源、资源变股本、农民变股民；因地制宜、分类施策、循序渐进、久久为功。

### 6.5 第五问：格子够吗？（预算）

800–1000 写 36–38 行，1000 左右写 40–42 行；每写完一段看一次表、数一次行。**触发点**：距交卷 12 分钟还有两段以上没写 → 立即跳到结尾写 4 行，再回头补最后一段；距交卷 5 分钟没写结尾 → 无论写到哪，停下写结尾（2025 一卷 82 分卷打铃没写完结尾）。

全文见《04_答案本》2026 县镇卷。

**对照真人卷**：三份 90 分卷都按题干两个落点分两大段（其中一份多一个总结段），分论点逐字重复"长远发展 / 民生福祉"；一份 89.5 分卷证据是"口袋公园""生态廊道"这种材料外的泛例，没扣多少——**落点和语言比例子值钱**；一份 82.5 分卷材料用得最满、第二题写超了，反而不高。一份 90 分卷的作者自述"意识流""超一行"，仍然 90。你从这里学到的：把两个落点写进开头末句、每句观点句（各点一个）和结尾，这件事做到了，作文就在高档；标题带上不吃亏但不是变量；例子是锦上添花。

### 6.8 句子模板（先填模板再润色）

- **观点句**："A，是 B 的 X"（生态美，是长远发展的最大本钱）；"以 X、以 Y，Z"（以质量立身、以品牌塑魂，擦亮金字招牌）；"推动 X，筑牢 B 的 Y"。
- **道理句**：材料判断句 + "……才……"（底子厚了，发展才有后劲）。
- **证据句**："A 县……；B 市……；C 镇……"，三个名词化的名字，数字至多一个。
- **收束句**："经验是：……" / "……才落到实处" / "X 通了，Y 才……" / "含 X 量越高，含 Y 量越足"。
- **开头**：引语一句 → 解题干比喻或口号一句 → 家底或靶子一句 → 点明几件事。
- **结尾**：材料原句或意象一句 → 四个方面各一个短语 → 上层目标（走在前列 / 中国式现代化 / 和谐共生）。

## 8. 时间、字数、考场应急

### 8.1 格子换算表（基数是题干限字，格子只是缓冲）

答题卡每行 25 格，标点占格，序号占格。

| 题干限字 | 答题卡格子（2026 实测） | 目标字数 | 目标行数 |
|---|---|---|---|
| ≤200 | 220 | 180–190 | 7–7 行半 |
| ≤300 | 320 | 270–285 | 11 行 |
| ≤400 | （未实测，估 420） | 360–380 | 14 行半–15 行 |
| 800–1000 | 1120 | 900–950 | 36–38 行 |
| 1000 左右 | 1220 | 1000–1050 | 40–42 行 |

每条写到分给它的行数就收尾（五条题约一行半，八九条题一行）。每写完一点看一眼行数；作文每写完一段数一次。

### 8.2 考场时间表（120 分钟）

**三题卷**：0–5 分钟按 3.0 做；第一题 20；第二题 30；作文 55（读材料 9：每份 1 分钟出头，只读各面开头的判断句和带地名主体的例子句，段旁标"判 / 例"；定分论点 4；开头 4；每段 7（四段；两大段各 14）；结尾 4；检查 2；余 4 分钟机动）；总机动 10。一题之内怎么切见 3.0.5。

**五题卷**：分值定行数定时间——15 分题 15 分钟，20 分题 22 分钟，30 分题 35 分钟，40 分作文 45 分钟；开考 5 分钟同三题卷；各题相加后剩下的是机动。五题卷每题只读题干指定的那份材料，作文才读全部。

### 8.3 五件必做（背下来）

1. **字数按格子数。** 数出来的才算数，头脑估算偏少 15–30%（十四套定稿校对时六篇作文全超）。
2. **草稿只写骨架。** 每点一个 4–8 字标签加几个两三字的缩写，整句只在答题卡上写一遍。【为什么】草稿上的整句阅卷人看不到，写两遍只花时间；骨架就是四问表，整句按预算写一遍。
3. **超了就砍最长那一条的末尾。** 顺序：数字和例子 → 最长那一点的最后一个分句（作用题的效果词除外）。每个点都留着。写少了，往最短的点里补一个材料原词。
4. **拿不准就选保险的那边。** 拿不准算不算一个点（轴上、能指回原话、不确定重不重复）→ 单独一条放最后。拿不准该不该合 → 分开。拿不准例子留不留 → 压成词留着。
5. **条数跟材料走，可以更细，不能更粗。** 去重不算合并。

### 8.4 出状况了怎么办

| 状况 | 做 |
|---|---|
| 写超了 | 小题砍最长那条的最后一个分句，作文砍最后一个证据；一条横线划掉 |
| 想不出名字 | 看段首段尾抄总结句；没有就五个动词加反复出现的名词；三十秒到，先写"一、"空四格写内容，最后回来填 |
| 材料读不完 | 大作文只读每份材料的第一段、最后一段和顶上那个词，中间段写到哪段翻哪段 |
| 拿不准算不算一个点 | 写，放最后 |
| 拿不准该不该合 | 分开 |
| 拿不准主体是谁 | 分开写 |
| 作文时间不够 | 距交卷 12 分钟还有两段没写 → 先写结尾 4 行再补；距交卷 5 分钟没写结尾 → 停下写结尾 |
| 发现前面写错了一个点 | 在后面把正确的关键词带上，前面的字留着 |

## 9. 怎么练、怎么对答案

### 9.1 预登记

定义和做法见 3.5.1。对答案时先对它。

### 9.2 对答案的顺序

先对条数（覆盖），再对词（保真），再对分组和标签（对齐），最后对格子（预算）。

差异分四类记：漏点多点 / 层级 / 名字 / 例子取舍。**名字和例子的差异不改方法。**

| 看到 | 做 |
|---|---|
| 漏点、多点 | 回一问看圈法 |
| 层级不同（我合了它分了 / 我分了它合了） | 回 3.2 的去重、合并、定父子三层判据 |
| 名字不同 | 记样本，规则不动 |
| 例子取舍不同 | 两家一致才动 |
| 改一条规则 | 写一句对下一题的预测，落空两次就撤回 |

### 9.3 参考答案怎么用、真人卷怎么用

**机构参考答案**（十二套的固定风格）：学它的标签短（它常写 4–6 字，你按 3.3 的 4–8 字控制即可）、效果尾巴、每条对策指回问题、一人一条、分组；自己保留标签里的具体名、例名、问题侧表现词、材料办法、作文证据、字数、案例核对。它的固定短板：低频词丢、类别合并、自补挤掉材料办法、作文论据薄、案例串错。**两家答案一致处才改，不一致处按本方法。** 机构答案是参考不是标准。

【补】**真人卷（审核后重写的口径）**：

1. **真人卷的分数是总分，不是每道题、每一点的分。** 一份 90 分卷的第二题不一定每条都得了分；一份 80 分卷的第二题可能是满分、丢在作文。所以真人卷**不能当逐点的标准答案**，只能校准**形状**——条数区间、标签形式、对策是不是工具级、作文几段落点在哪。
2. **合集里 13–14 份卷子只记录了部分题目，约 18 份作文只有提纲。** 只有一题或两题的卷子，它的总分不能归因到那一题上。用它的时候只看"这题长什么样"，不说"这题值多少分"。
3. **三份以上高分卷同向、且低分卷做法相反，才改规则；两分以内的差别当阅卷浮动。** 一份高分卷的做法只算样本。
4. **真人卷和材料冲突时，信材料。** 真人卷写"孤岛现象"、写"故意破坏"，回材料看是不是那个意思，不是它得了高分就对。
5. **真人卷和机构答案冲突时，看形状信真人卷。** 条数、工具级、作文按题干落点拆，这几件事真人卷说得算。
6. 定稿在这 55 份里的位置：十四套第一题与最高分卷同形；第二题与各套最高分卷同形；作文结构与最高分卷同型或等价，证据多于它们。

**怎么读一份真人卷**（原文《SOP 之外》第 6 节）：同题先读最高分和最低分两份，再读中间的。每份记录四样，做成表：①条数和标签（每题几条、标签几个字、什么形式：动宾 / 名词判断 / 主体加作用 / ××绿）；②对策形状（每条对得回问题吗、工具级还是动词级、自补几处）；③作文结构（几段、分论点是不是题干落点或材料判断句、每段几个材料名几个数字、开头有没有靶子、结尾几行）；④字数（实际几行、和上限差多少）。高低分的差别先按本方法的规矩解释；解释得通，那条规矩记一个真分数证据；解释不通，记成待解释项，攒三个同类再改规则。

| 行数控制 | 每次练题都在真答题卡（25 格）上写，写完数格 | 小题不超上限、不少于八成；作文误差 ±30 字内 |
| 效果词 | 拿 2021 县级、2022 乡镇、2023 县级三套专练，先划出所有效果词再答 | 四个位置的效果词一个不漏 |
| 对策写到工具 | 每条对策写完问"用什么工具做"，写不出工具的重写 | 每条对策至少一个可执行的工具名 |
| 作文观点句 | 每份材料先划出它第一段的判断句，再决定分论点 | 四个观点句里至少三个能指回材料判断句 |
| 案例核对 | 作文写完，每个案例的地名、人名、做法回材料点一遍 | 零串错 |
| 预登记 | 每套题写答案前先写三条"没把握的" | 对答案时预登记命中一半以上 |
| 限时 | 三题卷 120 分钟整套做；先做题型专练再做整套 | 120 分钟内写完并有 10 分钟检查 |

**从第一阶段起，在一个固定文件里记"方法写了但我没做到"**：哪一步在考场上实际做不了、来不及、忘了。盲测之后它才是改方法的依据。

### 9.5 盲测（方法能不能落地，只有这个算数）

四步：
1. 掐 120 分钟，在 25 格答题卡上盲做，不看任何答案。每题写完记下用时和实际行数。
2. 做完不改，先写三条预登记。
3. 把答案、用时、预登记发电子老师；电子老师**先盲做一份，再看你的**（顺序反了三方对就没意义）。
4. 三方对：你的、电子老师的、合集里的高分卷（如果有）。差异按四类分，另外单列一类——**"方法写了但我没做到"**。

**看什么**：不看你的分数，看第五类。那一类才是方法要改的地方——改成人能做的动作，或者删掉。

### 9.6 选调卷的第 0 步

选调 2024 年起才有申论（2021–2023 只有客观题），没有官方公布，题目和答案都是考生回忆拼出来的，两家拼的可能不是同一份。做题前：把题干里的专有词（"下乡返乡兴乡""G 市""金树林"）回材料里找，找得到才开始做，找不到就换材料版本。对答案前：把答案里的专有名回题目文件的材料找，找不到的那部分不作数。2024 选调题目文件的材料 3、4 就是拼错的——换大鹏版（带完整材料，题干和材料对得上），重做在《03_选调》对照文件第 3 节。除此之外，选调卷的卷面和题干措辞与省考相同，评分标准同源（第一题五个类别、第二题一问一策带表现词工具级、第三题按分量分段，三样和省考高分卷形状一致），四问五问不用改。

## 11. 考场一页纸（背这个）

**开考五分钟**：数格子 → 每份材料首尾句、顶上一个词 → 题干对材料 → 找分量（第 5 分钟到就翻第一题）。

**小题四问**

| 问 | 答什么 |
|---|---|
| 一问 单位 | 做法→动作；问题→状态；作用成效→效果；优势特点→判断；启示→动作+认识 |
| 一问 圈法 | 题干限定语划轴，轴外不圈；讲话体圈"要"字句；效果词扫四个位置；要求词看形状（具体明确→工具，认识深刻→认识句，观点鲜明→总句） |
| 二问 钥匙 | 有分量→按分量；有过渡句→按过渡句；段首有人地时→谁做的×哪一环；都没有→一段一堆。按序判，符合就停 |
| 二问 条数 | = 互不重复的事，可细不可粗。去重：名词都相同才是同一件事；合并：只有材料一句话罩住的才合；定父子：装得下所有兄弟的才是父，没有父就平铺 |
| 三问 名字 | 结构性总结句→抄成第一句；目的句需求句评论句→标签；分量词；都没有→五个动词+反复出现的名词。4–8 字，词性和内容一致 |
| 四问 算 | 限字×0.9（200 字题 0.95）÷25=行数；每条=行数÷条数 |
| 四问 砍 | 三层先砍，再砍最长条的末句，条数不动；写完数格子 |
| 三个核对 | 主语是不是题目指定的主体；专有名、数字、判断词在骨架上标了段号核过；引号词都出现了 |

**问题+对策加四步**：类名反转 → 手段三档逐条走（材料明说 > 反推标"反" > 词库工具至多一个）→ 一律写到工具 → 每条对策对得回某个问题（可多不可少）、每户每案例有对应、动词是身份能做的。问题侧带表现词。七个坑：镜像、自补、张冠李戴、越权、误读现状、自然风险当管理问题、问题重复。

**作文五问**：落在哪（题干判断句里圈出 A = 要拆的、B = 每段落到的，如"绿色发展是高质量发展的底色"A = 绿色发展、B = 高质量发展；标题含 A；B 在开头末句、每句观点句和结尾出现；两个落点时两大段各落一个，或按分量分段每句观点句点明自己属于哪一个）→ 拆哪边（材料拆哪边你拆哪边，官方分量全出现，段落不重叠）→ 每段怎么长（观点句优先用材料判断句，道理一句，三个证据、数字至多一个，收束回 B；开头六行有靶子有预告，解比喻两句不成段）→ 材料用够了吗（每份露脸，案例核对，判断词核对，材料外例子只补一句）→ 格子够吗（每段数一次；距交卷 12 分钟还有两段没写先写结尾四行）。

**五件必做**：字数按格子数；草稿只写骨架；超了砍最长条的末尾不砍点；拿不准选保险的一边；条数跟材料走，去重不算合并。
